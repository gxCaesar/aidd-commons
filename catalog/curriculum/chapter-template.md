# AIDD Commons chapter template

Use this template for a substantive lesson or worked case. It is a chapter
contract, not a claim that every v0.1 introduction already has a full lab.

## Prerequisites

- Name the concepts, data access, software, and experimental context assumed.

## Goals

- State the decision the learner will be able to make and the evidence required.

## Scientific assumptions

- Identify causal, assay, structural, distributional, and translational assumptions.

## Data contract

- Name the producer, version, entities, labels, exclusions, unit of inference,
  split, permitted use, and unresolved licence/access fields.

## Cheap baseline

- Define the strongest appropriate low-complexity baseline and freeze selection
  choices before reading test outcomes.

## Frontier methods

- Describe the mechanism, added assumptions, required assets, and what is not
  established by a public repository or paper page alone.

## Lab or worked case

- Link an executable lab when available. Otherwise use a bounded worked case
  with inputs, expected intermediate artifacts, and no fabricated result.

## Evaluation traps

- List likely leakage routes, split mismatches, unpaired comparisons, and the
  difference between repeated runs and independent biological units.

## Failure modes

- State the failure gate, the cheapest diagnostic, and when experimental
  feedback overrides an in-silico score.

## Openness and licensing

- Separate inference code, training code, weights, architecture, data recipe,
  training data, and evaluation code. Keep unknown fields unverified.

## Source list

- Cite primary papers, official projects, datasets, standards, and exact
  licence/asset pages adjacent to the claim they support.

## Last reviewed

- Record an ISO date and the scope of the review.
