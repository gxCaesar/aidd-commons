## The specificity topic gained a runnable task, and a reading found a third defect — 2026-10-23

The topic that asks a reader to select for an intended target and against the
unintended ones had a reading lesson and no runnable task, and the independent
reading of 2026-10-22 refused to raise it for that reason. It now has a
laboratory, a lesson that teaches the distinction, and a guide that runs the
counting, in English and in Chinese.

**The laboratory.** `labs/specificity_margin_audit/` counts the partners each
protein is measured with in the cached affinity archive. Of 7085 rows it
reads, 2544 carry a parsed measurement, and 2487 of those have both protein
labels, which resolve to 102 distinct unordered pairs and 171 distinct protein
labels. The median distinct-partner count is 1, the interquartile range runs
from 1 to 1, and 154 proteins are measured against exactly one partner. Only
9 counted pairs have more than one observed partner on both sides, and those
are the only pairs in which the table can show a margin at all. A protein
measured with one partner is not selective, and the table says nothing about
an alternative it was never measured against.

**The thirty-seventh reading raised the topic and found a real defect.** It
scored the topic assessed on public data, with 19 completed commands and no
path outside the sandbox. It also found that the laboratory's inspection
command read the package version from the repository's `pyproject.toml`, and
neither a published export nor a reading sandbox carries that file, so the
command failed in both places. The reviewer worked around it by running the
analysis directly and reproduced every frozen census field, so the material
was sound and the command was not. The version now comes from the installed
distribution, with the declared value as the fallback, and the command was
then run in a tree with no `pyproject.toml` and it passes.

**Two readings that had been run but not merged were merged.** The
thirty-fifth and thirty-sixth batches re-read twenty-eight topics. Twenty-six
of them came back unchanged. One gained a real-data run basis, and one lost
depth: the thirty-fifth reading found that the runnable profile check
validates the local PaperQA configuration and not a tool's input and output
contract, so no runnable task tests that topic, and the self record was
lowered from `executable` to `worked`. That is a topic the project had
credited as runnable for a year, and the record follows the reading.

**The isolation checker was wrong twice more, and was fixed.** It reported a
path under the sandbox as an escape, and it read the `/` of a relative path
join inside a quoted script as the start of an absolute path. Both were
false positives, and a third of the same class was already recorded in the
review file as a known false positive that was never fixed. The checker now
accepts the sandbox's own path, reads a relative join as relative, and
distinguishes a relative name from a home or absolute path to the same name.
It carries a self-test of nineteen cases, each rule exercised in both
directions, and the fixed checker reports zero problems across all
thirty-four event files.

Executable stayed at 66, because the specificity topic's raise and the tool

## Two laboratories that join what exists and read back what a rule sees — 2026-10-23

Two new laboratories carry topics that had a lesson and no runnable task, and
four more 2026 methods entered the catalogue.

**A laboratory that joins the endpoint families that can be joined.** The
multi-endpoint integration laboratory reads the measured response potency, the
intrinsic clearance and the CYP inhibition this repository already holds, and
joins them by parent molecule and by nothing else. Of 7,908 compounds, 58
carry two families and none carries three, while 1,062 carry only exposure,
6,780 only interaction and 8 only efficacy. There is no measured toxicity
snapshot here, so that family is reported as unmeasured rather than filled
in, and the laboratory states that a microsome clearance per gram of protein
cannot be divided by a hepatocyte clearance per million cells to claim a fold
change. It also refuses a composite score, and a known-bad test performs one
and confirms the refusal.

**A laboratory that reads a selection rule back on its own data.** The
oracle-exploitation laboratory fits a model on the training part of the
committed FreeSolv scaffold split, ranks the training molecules by the model's
own prediction, and compares what it predicted with what was measured. The gap
reaches 8.06 kcal/mol on one selected molecule, while a random selection from
the same pool stays within 1.03. The batch it proposes for independent
evaluation comes from the held-out part of the split, with a verification
target and an interval for each member, and the laboratory states that this
is a bounded retrospective proposal and not an independent evaluation.

**Four more 2026 methods, and what the first-party files showed.** AQAffinity
is a structure-free affinity head on the OpenFold3 trunk whose repository is
gated, and the record could not read the model card or the files, so every
openness dimension except the access level and the licence is unverified.
Nesso-1 is a coarse-grained co-folding model whose README states no training
data at all and whose accelerated kernels are CUDA 12 only. ByteFF is a
data-driven force field whose repository is archived and no longer maintained
and which publishes no checkpoint, offering a hosted API trial instead.
ByteFF2 is the maintained successor, with published weights, a named training
corpus, an Apache grant on the code and a different grant on the weights, and
a route that is a build rather than an install.

**A laboratory that reads what the catalogue states about a construct.** The
construct statement laboratory audits this project's own records across the
four fields the topic names, modality, construct type, expression system and
intended function. Of the 46 records that name a biologic modality, 46 state
the modality, 4 state the construct type, and none states an expression
system or an intended function, so 42 of them state a modality alone. A
modality is not a construct, and the laboratory's boundary says exactly that.

**Two more 2026 methods, and the first record for the active-learning track.**
ALF is a framework for scientific active learning that separates the roles of
a loop: the candidate dataset, the surrogate, the acquisition function, the
search function, the oracle, the design task and the state logger. The
active-learning track of this curriculum had five lessons and, until this
record, no record for an active-learning tool. The Mobley Lab notebooks are a
published procedure for multiobjective optimisation over multi-target
binding, and their README carries no licence statement, no data statement and
no runnable command, so the record carries all three absences.

**A re-reading of eleven topics that had never been read again, and one of
them went down.** Twenty-one topics were still on the first reading of
2026-09-11, and the forty-third batch re-read eleven of them. Ten came back
unchanged. The regression-formulation topic came back **lower**: the record
claimed `executable` on the strength of a laboratory that runs a train-mean,
a fingerprint Ridge and a Random Forest, and the reading found that the
exercise supplies the learned regression coefficients but no neural or
learned-representation regression baseline, so the claim of a runnable

`assessed` and says so. Two more run bases were corrected in the same
direction, the provenance-versioning and small-molecule-representation

authored molecules rather than on measured data.

**The re-readings finished, and they mostly confirmed rather than raised.**
Forty-three topics had been read once, on 2026-09-11, and never again. The
forty-third and forty-fourth batches re-read all of them. Twenty came back
unchanged, one came back lower, and none came back higher. That is a

**What is left, and what each one needs.** Eighteen topics still sit at

The eighteen are: a therapeutic decision context, a target-product profile a

**Ten benchmarks that a reader could not get hold of, and now can.** Ten

**A foundation model for ADMET representations.** NVIDIA's Contrastive KERMT
entered the catalogue: 70.6 million parameters, pretrained without labels on
a joint objective of SMILES reconstruction, in-batch contrastive
discrimination and chemistry-specific self-supervision, over about 11.1 million
unique canonical SMILES from a ZINC15 and ChEMBL base pool with three further
sets added, deduplicated and scaffold-balanced. Its code is Apache 2.0 and
its weights are under the NVIDIA Open Model License. The record carries the
model card's own limits, that it is a backbone to be fine-tuned rather than
a predictor, that the pretraining has no testing set and the card reports no
benchmark, and that its predictions are statistical estimates rather than
substitutes for measurement in safety-critical decisions.

## The explanation pointed at the wrong atoms — 2026-09-11

`t07-interpretability-sar` asks for model explanations and analogue evidence to
form testable SAR hypotheses **without claiming causal atom effects**. The last
clause is the whole topic, and on real activity data it cannot be checked, because
the cause is exactly what the model was trying to learn.

So the set was constructed to make it checkable. **The dataset stores a rule, not
labels.** A molecule is active if and only if it contains a carboxylic acid, and
labels are recomputed from that rule every time. A test asserts the file has no
label field at all, so no label can drift away from its cause. A second
substructure, an unsubstituted furan, is perfectly correlated with the cause in
training and has no causal role.

The construction was prototyped and rejected once before the lab was designed
around it. A first version left both analogues on the correct side of the
threshold, which would have made the lesson an assertion rather than a
demonstration. The fix was not a bigger effect but a sharper mechanism: **make
the confounder structurally uniform and the true cause structurally varied.** The
furan then appears in an identical environment in every active, so its bits
repeat, while the acid appears in a different environment each time and its
credit spreads across many distinct bits. **Uniformity, not importance,
concentrates weight.**

What the run shows, with the largest training error at 0.0549 so the model
plainly fits:

**The confounder outscores the true cause on 7 of 8 active molecules**, and every
active assigns positive credit to atoms that cause nothing.

**The matched pair is ranked backwards.** `CCCc1ccoc1` has no cause at all and
scores +0.4908. `OC(=O)CCc1ccccc1` is genuinely active and scores +0.4607. The
model separates two molecules of opposite true activity by 0.0300 and puts them
in the wrong order, calling the active one inactive at a threshold declared
before fitting. Two controls, both signals present and neither present, land at
+0.9671 and -0.0086, which is what makes the first pair readable rather than
noise.

The lab then states the distinction the topic asks for. An explanation licenses a
**hypothesis**, because it reports which features the model used, and that is a
fact about the model. Turning it into a claim about which atoms cause activity
needs an analogue that breaks the correlation, and that is an experiment rather
than a re-reading of the same fit. On real data the comparison performed here is
unavailable, and the analogue is the only route left.

One reproducibility decision is recorded rather than hidden. The exact
predictions depend on the fingerprint implementation, observed with RDKit
2025.09.6 and NumPy 2.4.6. **The checks assert the qualitative relationships**,
inverted ranking, credit share, fit quality, **rather than the decimals**, so a
library update changes the printed numbers without silently invalidating the
lesson. The lab page quotes the observed values and names the versions beside
them.

Fourteen checks, thirteen tests, five of them known-bad edits including one that
adds a training molecule breaking the correlation, which removes the whole
demonstration and must be rejected.

Measured effect: `executable` rises from 39 to 40 and the queue falls from 13 rows
to 12. Four of the seven rows judged reachable remain.

retrospective on the same target, under one frozen protocol, one feature set, and

## The band where you cannot decide — 2026-09-11

`t07-property-decision-use` asks for calibrated evidence to be converted into
thresholds, trade-offs, experiment choices and explicit abstention. The FreeSolv
lab had already produced the evidence: split-conformal intervals built for a
nominal coverage of 0.9, calibrated on validation, reported per split and model
alongside the point metrics. Nothing needed to be fitted.

**A point prediction always yields a decision, because a number is always on one
side of a threshold. An interval does not.** The frozen rule therefore has three
branches, and the abstention band is two conformal radii wide.

Three relationships in the committed numbers carry the lesson, and all three were
already sitting in the artifact unread.

**Only one of four combinations reaches the coverage it was built for.** Scaffold
random forest covers 0.90625. The other three fall short, and random ridge misses
by 0.1656 — it covers 0.734375 against a nominal 0.9.

**The narrowest band is the least trustworthy one.** Random ridge has the
narrowest band of the four at 3.1653 kcal/mol and the largest shortfall. The
combination that actually covers has the widest, at 6.0130. Sorted by band width
the shortfall falls monotonically, without exception, and a check locks that
ordering.

**More trustworthy intervals decide less.** On the declared grid the abstention
counts run 7, 11, 11, 13 as the band widens, so the combination reaching nominal
coverage abstains the most. That is the trade-off the topic names, and it is the
opposite of what a threshold applied to a point estimate suggests.

A fourth finding is about model selection. The rule declares both criteria before
the numbers are read: lowest error for the point criterion, coverage closest to
nominal for the interval criterion. **They disagree on both splits and in the
same direction** — lowest error picks ridge, coverage picks random forest. Same
direction on both splits means it is not a split artefact, and a check requires
that.

The lab states what it cannot compute rather than leaving it to be noticed: **how
many real compounds fall inside the band.** The completed lab committed aggregate
metrics and split membership, not per-compound test predictions, so the band can
be measured on the prediction axis but not populated. The grid counts are
arithmetic over a declared range and are not a yield. This is the same admitted
record gap that the counterevidence dossier inventories as a class, now appearing
in a second lab.

Two smaller things worth recording. A known-bad edit setting every radius to zero
did **not** fail the abstention check, because a grid point sitting exactly on the
threshold abstains at any radius. The check was requiring a non-empty band, which
is nearly untestable; it now requires a band wider than a single grid point, and
the mutation fires. And the date rolled over mid-session: three evidence entries
dated 2026-09-11 tripped the validator against a record dated 2026-09-10, which is
the gate working. The record date was bumped and four tests that pin a frozen
validator date were advanced with it.

Measured effect: `executable` rises from 36 to 37 and the queue falls from 14 rows
to 13. **The comparison against external providers is unchanged in kind**: this is
a lower bound against lower bounds, ten providers still carry upper bounds of 93,
and the audit reports the claim as not established.

## Comparison-set protocol

The first frozen comparison set will contain at least 12 systems and cover four
provider classes:

1. end-to-end curricula or textbooks;
2. executable tutorial and notebook collections;
3. benchmark, dataset, and evaluation hubs;
4. specialist reference systems for chemistry, biology, structure, synthesis,
   or scientific computing.

Candidate discovery will use dated searches in English and Chinese, backward
links from established collections, and direct suggestions from compared
projects. A candidate is included when it has a stable public identity and
material relevant to at least one AIDD Commons topic. Inactive and access-gated
systems remain eligible because excluding them would bias the comparison toward
the project's preferred openness model.

Each system record will distinguish:

- what was directly opened and reviewed;
- what was discovered but could not be opened;
- what requires registration, payment, or institutional access;
- which version or review date the observation describes;
- how corrections can be submitted to the upstream project.

## Coverage taxonomy

The 18 charter tracks are the top level, not the unit of comparison. Each track
will be decomposed into stable topic units. For example, “QSAR and molecular
properties” separates endpoint definition, chemical standardisation,
representations, regression, classification, splitting, calibration,
applicability domain, interpretability, and decision use. This prevents one
broad page from counting as equivalent to a sequence of tested lessons.

Every system–topic cell receives one pedagogical-depth state:

| State        | Meaning                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------------- |
| `absent`     | No coverage was found in the reviewed material. This is an observation, not proof of global absence. |
| `mentioned`  | The topic is named or linked without enough explanation to teach it.                                 |
| `explained`  | Concepts, assumptions, or workflow are explained substantively.                                      |
| `worked`     | A concrete worked case, derivation, or code walkthrough is supplied.                                 |
| `executable` | Learners can run a defined task with inputs and expected outputs.                                    |
| `assessed`   | The system supplies an exercise, rubric, verification target, or capstone that tests learning.       |
| `unverified` | Available evidence is insufficient to assign another state.                                          |

Depth is ordinal, but the audit will not sum these states into an arbitrary
weighted score. A system can therefore be broad but shallow, narrow but
executable, or strong in evidence while weak in accessibility without those
differences being hidden in one number.

The audit also records independent dimensions:

- audience and prerequisite level;
- small molecules, proteins, antibodies, nucleic acids, cells, and multimodal
  therapeutic scope;
- code, data, weights, solution, and content access;
- licence and commercial-use status when directly supported;
- English, Chinese, and other maintained language routes;
- keyboard, contrast, screen-reader, and low-compute accessibility evidence;
- maintenance date, release cadence, and correction mechanism;
- scientific caveats, evaluation traps, and explicit failure material.

## Evidence and uncertainty rules

Every positive state from `mentioned` through `assessed` requires at least one
adjacent evidence item with an official URL, source title, observed scope,
review date, and optional version. The audit stores short paraphrases, not
copied lessons or long quotations.

`absent` means “not found in the declared reviewed surfaces.” It must include
the surfaces and search date. It must never be converted into a statement that
the provider has no such material anywhere.

Inaccessible or ambiguous surfaces remain `unverified`. Summary tables will
report a lower bound using only directly supported cells and an upper bound
that includes unresolved cells. A comparative claim is not robust when changing
an unresolved cell could reverse it.

Sparse records must declare `coverage_default: unverified`. The matrix
generator materializes that explicit default for every omitted provider–topic
pair. A missing direct observation without this default is an export error; it
must never be converted to `absent`.

```text
tests/comparisons/                    known-good and known-bad contracts
```

The web view will show evidence and uncertainty next to each cell. It will
support filtering by track, topic, provider class, depth, access, language, and
last-review date. It will not publish a leaderboard-style overall score.

## Frozen depth-tranche selection rule

After v0.2a is reviewed, candidate deep lessons and labs are ranked using only
information declared before implementation:

1. the topic is part of the charter's core target-to-candidate scope;
2. AIDD Commons is below `worked` or `executable` depth for that topic;
3. at least one comparison system demonstrates that substantive treatment is
   feasible, or the audit identifies a defensible field-wide gap;
4. public inputs, labels, licences, entities, and independent units coexist;
5. a strong cheap baseline and an independent validation route can be stated;
6. the smallest protocol-valid implementation is CPU-first;
7. the content does not require operationally harmful biological or chemical
   instructions.

The first three candidates that pass all seven conditions form v0.2b. Ties are
resolved by broader prerequisite value across the 18 tracks, then by lower
maintenance burden. Model novelty and visual appeal are not tie-breakers.

## Claim-promotion gate

The project may describe itself as “the world's most comprehensive open AIDD
learning system” only when all of the following are observed:

1. the comparison set contains at least 12 eligible systems across all four
   provider classes;
2. the topic taxonomy covers all 18 charter tracks and has been published before
   scoring;
3. every positive comparison cell and every positive AIDD Commons cell has
   direct evidence;
4. AIDD Commons has no charter track below `explained` depth;
5. its lower-bound count of topics at `explained` or deeper exceeds every
   comparator's upper-bound count under the same taxonomy;
6. the result remains true after submitted corrections are incorporated or a
   public 30-day correction window closes.

“Most detailed” is a separate claim. It additionally requires at least 12 of
the 18 tracks to contain a tested executable lab or assessed capstone and the
lower-bound comparison to lead at `worked` or deeper. If either gate fails, the
project reports the measured result and keeps the existing “building toward”
language.

## v0.2a completion criteria

- At least 12 comparison systems are validated.
- Every one of the 18 tracks is decomposed into auditable topic units.
- Every non-absent cell has adjacent, opened-source evidence.
- Unknown and inaccessible material remains visibly `unverified`.
- Deterministic JSON and CSV projections are generated from canonical YAML.
- A public matrix and gap view work on desktop, mobile, and keyboard navigation.
- Known-bad fixtures prove that unsupported depth, missing review dates, broken
  topic relations, and invented licence claims are rejected.
- The generated gap report selects v0.2b candidates using the frozen rule and
  records when fewer than three candidates pass.
- The curated public-release builder includes the public audit artifacts and
  excludes search notes, internal plans, and execution traces.

## Non-goals

Version 0.2a will not add accounts, a server-side database, model leaderboards,
GPU training, copied third-party course material, or an automated claim that a
topic is absent. It will not select the v0.2b labs before the audit output is
available.
