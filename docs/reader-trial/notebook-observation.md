Outcome choices: `completed without help`, `completed with help`, `stopped`,
`skipped`, `not observed` / 独立完成、帮助后完成、停止、跳过、未观察。
Browser-only execution and retention are `not observed`, not failures.
Use only the rows relevant to the chosen session. For PaperQA, record whether
the answer/source comparison preceded the review notes; do not count an answer
copied from those notes as an unassisted explanation. The organizer's
[PaperQA answer notes](../READER_TRIAL.md#optional-paperqa-source-inspection-session--added-2026-09-10)
are separate from the participant sheet. No live model run is part of this trial.
Record elapsed time only if measured; distinguish active work, installation and
waiting. An account restriction is a setup condition, not a scientific error.

only after the initial attempt. Do not combine these dimensions into a single
