# Stable mechanisms and dated frontier readings

Editorial protocol adopted 2026-09-09. This defines a maintenance practice, not
an installed scheduled service or authorization for automatic publishing.

Core chapters explain mechanisms useful across releases. Dated reading modules
describe a particular source, task and artifact state. A model name or repository
does not become a completed course or a SOTA ranking.

## Review rhythm

- Weekly: collect candidate changes from primary papers and official projects.
- Monthly: open load-bearing sources and prepare an editorially reviewed update,
  retaining unresolved access and reproduction limitations.
- Quarterly: inspect gaps, obsolete interfaces and changed methods; decide whether
  a stable mechanism belongs in a core or specialist unit.
- On concrete corrections, withdrawals or important interface changes: correct the
  affected claim promptly with scope and date, preserving earlier result identity.

Automation may collect links, not auto-publish scientific conclusions. Source
access, scientific assessment and release are separate activities. No recurring
task or public deployment is configured by this document.

## Six questions per reading

1. What task and input/output contract does the source define?
2. What do representation, objective, training and inference do?
3. What is the strongest relevant comparison under the matched protocol?
4. Which entities, splits, metrics and resources support the result?
5. Which code, data, weights and recipe were inspected; what was actually run?
6. Which failure or scope boundary prevents a broader conclusion?

Open each load-bearing source. Snippets and titles are leads, not verified claims.
If an article is unreadable, identify that limitation and rely only on what the
accessible official source establishes. Inference availability is not a released
training recipe.

## First reading tranche

Bilingual chapters cover structure versus affinity; autoregressive, diffusion,
latent and flow mechanisms; context-conditioned perturbation prediction; and
retrieval, typed tools and feedback. Source dates and qualifiers live in the
pages. Constructed worked cases are not new model comparisons, and these readings
do not settle the “most comprehensive” aim.

Preserve the 93-topic, 13-system historical comparison. New textbook units map to
historical topics without revising that snapshot. A new comparison requires new
item-level evidence, retaining unknowns and separating resources from taught depth.
