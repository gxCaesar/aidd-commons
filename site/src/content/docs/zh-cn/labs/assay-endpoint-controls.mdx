## 这个实验要问什么

药物发现表格里只有一个效力数值，到此为止。它背后的测定携带的信息更多。它命名被测量的终点，
它说明记录下来的关系是等式还是界限，它记录曲线有多少重复，它命名平板的对照制度，它写下
施加到原始读数上的归一化方程。冻结协议就这些记录声明了一个问题。

> 对于一组已声明的已归档 PubChem BioAssay 剂量反应测定，每个测定究竟包含什么，
> 每个测定自身的对照记录允许得出哪些结论？

协议声明了六个测定，实验把它们在 PubChem BioAssay 档案中逐一打开。它从档案本身读出终点、
关系、重复结构、对照制度与归一化方程，然后问那个决定读者可以得出什么结论的问题。
每个测定是否携带了它自己协议所声称的对照记录？

有两条规则决定后面每一个数字。等式是测量值，而界限是删失值，它陈述数值的一侧而不是数值本身，
因此两者不能写成同一种东西。对照记录才是固定标尺的东西，所以一个协议从未命名任何对照的测定，
所允许的结论远少于一个命名了两个对照并写下方程的测定。

这是对已发表测量值的描述性读取。不拟合任何模型，不做任何预测，这里也不是对化合物价值的
比较。

## 运行之前

**模式：在一个已归档、经过字节校验的快照上，对一次确定性描述过程做独立复现。** 第一条命令
需要网络访问，其余不需要。下载命令每次运行都会对照冻结协议重新校验每一个已声明的字节长度，
因此在缓存完整时再次运行不会下载任何东西。

```bash
.venv/bin/python labs/assay_endpoint_controls/run_lab.py download
.venv/bin/python labs/assay_endpoint_controls/inspect_assay_endpoint_controls.py show
.venv/bin/python labs/assay_endpoint_controls/inspect_assay_endpoint_controls.py check
```

需要 Python 3.11 以及 NumPy、SciPy 和 RDKit，项目固定环境用 `uv sync --group dev` 安装。
下载命令把归档记录写入 `.cache/assay_endpoint_controls/`，除此之外不写任何东西。`show` 打印
读数，`check` 重算各项不变量，并在某项被违反时以非零状态退出。两者都只用 CPU，缓存就绪后
不再需要网络访问。

已提交的 summary 是作者的运行结果，用 Python 3.11.15、numpy 2.4.6、scipy 1.17.1 和
rdkit 2025.09.6 于 2026-10-21 计算。它保存计数、分布和一组固定命名的示例，而不是原始行。
同一目录下的一个脚本会从缓存就地重新生成该 summary，因此它会覆盖已冻结的产物，
所以它被有意排除在阅读路线之外。

## 数据是什么

数据源是 US National Library of Medicine 公开 FTP 站点上的 PubChem BioAssay 档案。
每个已声明的测定贡献一个逐测定结果 CSV 和一个逐测定描述 XML。档案于 2026-10-21 读取。

访问方式很重要，因为容器大而成员小。这些文件中的每一个都是装有各一千个测定标识符的分段
容器 zip 中的单个 gzip 成员。读取器用 HTTP 字节范围请求定位容器的中央目录，只读取已声明的
成员，因此装着测定 1277 的那个 1313522439 字节容器从不被完整下载。六个测定合计缓存 407461
字节。

冻结协议记录容器 URL、容器内的成员路径、容器的字节长度、成员的压缩与未压缩字节长度，以及
档案记录的成员 CRC-32。每次运行都会在读取任何内容之前重新校验归档字节长度，因此缓存是快照
而不是移动目标。如果上游档案发生变化，校验会失败，而不是悄悄测量另一个文件。

分组单位是一个测定内的 PubChem 化合物标识符。实体标识符是 `PUBCHEM_CID`，结构是归档中内联的
`PUBCHEM_EXT_DATASOURCE_SMILES`。一行被准入的条件是：它是数据行而不是 PubChem CSV 格式放在
表头之后的逐列元数据行之一，化合物标识符存在且为正整数，结构可解析为至少含一个原子的分子，
活性结论存在且非空，至少一个已声明的终点列持有有限数值，该行的逐浓度列命名了至少五个不同
浓度，并且该化合物在一个测定中只出现一次。

该规则按设计排除三类内容。逐列元数据行描述的是列而不是测量。化合物标识符、结构或活性结论
缺失的行无法被定位。同一个测定中出现两次的化合物没有自己的记录，因为档案没有说明这两行中
哪一行是该化合物的记录。

六个已声明测定如下。

- 439，S1P3 Agonist Dose-Response Potency Assay
- 464，Cell Proliferation & Viability (Cytotoxicity) Dose Response Assay 60K MLSMR
- 519，Dose Response Assay for Formylpeptide Receptor (FPR) Ligands and Dose Response Counter-Screen Assay for Formylpeptide-Like-1 (FPRL1) Ligands
- 548，Dose-response biochemical assay for inhibitors of protein kinase A (PKA) activity
- 691，Zebrafish Lipid Metabolism Assay - Dose-Response Confirmation.
- 1277，Dose response cell-based screening assay for antagonists of neuropeptide Y receptor Y1 (NPY-Y1)

PubChem 是 US National Library of Medicine 的一项资源。NCBI 的总政策页面是复用条款的机构
参照。本实验没有阅读专门针对已归档 BioAssay 记录的条款声明，因此那些条款保持 unverified，
而不是在这里断言。

## 读数是什么

廉价基线排在最前，它构成实验的前半部分。在已声明的测定中共有 1529 个准入终点值，分布在
五个终点标签上，另有 1257 个准入行，每行恰好带一个关系限定符。置信分数分布、每个测定的准入
数值计数与重复结构，全部在查看任何曲线之前计算完成。

后半部分读取每个测定自身的记录。对每个已声明测定，实验打印归档终点及其方向、准入前后的行数、
该测定内部的关系混合、归档协议声明的重复结构、协议声明的对照制度、它命名的参考孔，以及
档案用自己的话写下的归一化方程。

方程随后在它自己的参考孔上运行。它产生的两个数值必须相差 100 个单位，并且较低的那个必须
位于零，方程才能被称为零到一百的响应标尺。归档的逐浓度数值随后必须落在方程所跨的范围内，
并按 25.0 点的带宽放宽，且至少达到已声明的 0.95 比例。哪里没有通过，档案自己的方程就不描述
档案自己的标尺，实验会照实说明。

曲线检查随后重算归档方程产生的结果。容差固定为 5.0 点，检查对开发侧与留出侧分别报告有多少
曲线落在容差内、有多少落在三倍因子内，以及中位数、第 90 百分位与最坏的绝对偏差。比较的参照是档案自己
记录的终点值，每个测定的拟合模式都会被说明。

化合物划分是稳定性检查，而不是评估。它按种子 20261021 与化合物标识符的确定性奇偶性划分
化合物，因此同一化合物总是落在同一半，它让读者确认在化合物被不同地划分时廉价基线不会移动。
协议明确声明本实验不含预测模型、不含训练测试评估、不含留出打分。

## 数字是什么

读出混合对每一个准入终点值计数。

| 终点标签 | 准入终点值 | 1529 中的比例 |
| -------- | ---------: | ------------: |
| AC50      |        706 |   0.46174     |
| IC50      |        429 |   0.280576    |
| Ki        |        272 |   0.177894    |
| EC50      |         69 |   0.045128    |
| MIC       |         53 |   0.034663    |
| 合计      |      1529 |               |

关系混合对每一个准入行计数一个限定符。

| 关系限定符 | 准入行数 | 1257 中的比例 |
| ---------- | -------: | ------------: |
| 等式       |      832 |   0.661893    |
| 大于界限   |      406 |   0.322991    |
| 小于界限   |        4 |   0.003182    |
| 未声明限定符 |    15 |   0.011933    |
| 合计       |     1257 |               |

这两个混合的分母不同，而差异本身有信息量。读出混合到达 1529，是因为测定 519 在它的 272 个
准入行上各记录两个终点列，即 IC50 与 Ki。关系混合到达 1257，是因为一个限定符附着在行上
而不是附着在终点值上。两个总数因此相差的正是测定 519 的准入行数。

置信分数在 0.002386634844868735 的准入行上达到最大值 100，在 0.3206046141607001 的准入行上
为 0，中位数为 23，最小值为 0。置信分数是归档记录的一个字段，因此这里把它读作该记录的属性，
而不是底层实验的属性。

化合物划分把 644 个化合物放在开发侧，613 个放在留出侧。在两半上重算时，每个测定的关系混合
都保持同样的形状。测定 439 的置信分数中位数在开发侧为 51.5，在留出侧为 36；测定 548 的对应
数值从 36 变为 36.5，所以一个测定的描述会随其中恰好被测试的化合物集合略有移动。

六个测定的对照记录各不相同。

| 测定 | 归档终点 | 准入行数 | 该测定内的关系混合 | 对照制度 | 命名的参考孔数 | 方程所描述的标尺 |
| ---- | -------- | -------: | ----------------- | -------- | -------------: | ---------------- |
| 439  | EC50 in uM，激活 |     69 | = 55，&gt; 14 | 单一阳性参考 |            1 | 零到一百 |
| 464  | AC50 in uM，抑制 |    706 | = 591，&gt; 115 | 单一阳性参考 |            1 | 零到一百 |
| 519  | IC50 与 Ki in uM，抑制 |    272 | = 94，&gt; 178 | 阳性与阴性参考 |            2 | 零到一百 |
| 548  | IC50 in uM，抑制 |     94 | = 64，&gt; 30 | 阳性与阴性参考 |            2 | 平移 |
| 691  | MIC in uM，分类 |     53 | &gt; 38，未声明 15 | 未声明 |            0 | 未声明 |
| 1277 | IC50 in uM，抑制 |     63 | &lt; 4，= 28，> 31 | 阳性与阴性参考 |            2 | 零到一百 |

方程审计把携带标尺的测定与不携带标尺的测定分开。

| 测定 | 归档数值，最小到最大 | 高于 100 的值 | 低于 0 的值 | 落在方程所描述范围内的比例 | 方程是否复现归档标尺 |
| ---- | -------------------- | -----------: | ---------: | --------------------------: | ------------------ |
| 439  | -1.82 到 201.34      |            4 |        282 |  0.9985507246376811 | 是 |
| 464  | -16.3 到 101.2       |           81 |       3116 |                  1.0 | 是 |
| 519  | 0 到 100             |            0 |          0 |                  1.0 | 是 |
| 548  | -5.5 到 111.3        |            5 |         33 |  0.7620064034151548 | 否 |
| 691  | 不适用               |            0 |          0 |               不适用 | 不适用 |
| 1277 | -6.2 到 410.7        |           14 |        146 |  0.9841269841269841 | 是 |

测定 548 是关键案例。它的归档协议命名了阳性对照和阴性对照，也写下了归一化，但它写下的方程
把阳性参考放在 0，把阴性参考放在 -100。只有 0.7620064034151548 的归档值落在该方程所描述的
范围内，所以这个方程并不描述归档数值所处的标尺。测定 691 的问题正相反。它的归档协议没有
命名任何对照、空白或载体，因此没有任何东西设定其标尺的两端，方程根本无法运行。

曲线检查在化合物划分的每一半上分别报告归档方程产生的结果。测定 439、464 与 548 从归档
参数重算，测定 519 与 1277 从归档点重拟合。测定 691 是分类读出，因此检查不适用，两半都
没有报告曲线。

| ---- | -----------: | -----------: | ------------------: | ------------------: | ----------------: |
| 439  |           22 |          33 |  0.5452848516799145 |  0.8272727272727273 |  0.803030303030303 |
| 464  |          308 |         283 |  2.180002812003138 |  0.7996747967479675 |  0.8012048192771084 |
| 519  |           54 |          40 |  2.6723002766804966 |  0.6536082474226804 |  0.6218487394957983 |
| 548  |           31 |          33 |  2.1225744518693093 |  0.7142857142857143 |  0.7181818181818181 |
| 691  |            0 |           0 |           不适用 |           不适用 |         不适用 |

比例分别是 0.6666666666666666 与 0.5384615384615384。测定 464 的留出侧给出的中位绝对
log10 误差为 0.006541582591169153，落在三倍因子内的比例为 1.0。

## 这不能说明什么

冻结协议按设计排除五件事，而这份排除清单就是本节的机器可读形式。

- 不含预测模型、不含训练测试评估、不含留出打分。一个报告准确率的描述性实验，报告的将是它自己代码的数字。
- 原始仪器信号。归档的逐测定 CSV 携带的是存方自己归一化之后的响应，因此对照归一化所消耗的原始信号不在档案中，归一化方程是在参考孔上而非在真实平板上运行的。
- 脂溶性、Delaney、BBBP、Tox21 与 HIV 数据集。它们不携带测定、对照、浓度或序列，因此不能支持任何关于测定终点的陈述。
- 任何两个不同测定之间的效力比较。两个具有不同对照记录的测定不共享标尺。
- 任何关于体内、临床或药代动力学后果的陈述。这里声明的每个测定都是体外或基于细胞的测量。

对读数本身还有三条限制。六个测定不是档案的样本，所以这里没有任何数字估计 PubChem BioAssay
整体上关系限定符、置信分数或对照制度如何分布。准入值是已声明准入规则保留下来的结果，
改动规则的读者会得到另一个队列。缺失的对照记录被报告为关于档案的事实，而不是实验在
没有对照的情况下完成的证据，因为档案记录的就是它记录的东西。

曲线检查是对档案内部一致性和档案自身归一化方程的检查。它在固定容差下把重算出的曲线与
档案自己记录的终点值比较。它不是对底层实验的评估，也无法侦测档案在读数和记录终点上
一致犯下的错误。

## 独立练习

用读数产生的数字回答下面三个问题。

1. 准入行中有多少个带等式，有多少个带界限，丢掉限定符会对大于界限和小于界限分别造成
   什么后果？
2. 六个测定中有三个同时声明了阳性参考与阴性参考。说出它们，说出那个归档方程无法复现
   其归档数值所在标尺的测定，并给出显示这一点的数字。
3. 对归档协议没有命名任何对照、空白或载体的那个测定，写出一句它自身记录允许的陈述，
   以及一句它不允许的陈述。

<details data-worked-answer>
<summary>参考答案</summary>

<p>1257 个准入行各自带一个关系限定符。其中 832 个是等式，406 个是大于界限，4 个是小于界限，15 个没有
15 个没有任何限定符，因此界限几乎占掉准入行的三分之一。大于界限说明真实值大于写出的数字，
所以丢掉限定符
就是把边界当作测量值报告，让化合物显得比档案所述更强。小于界限说明真实值更小，所以丢掉限定符
会让化合物显得比档案所述更弱。建立在这类数字上的排序会同时继承两种错误。</p>

<p>测定 519、548 与 1277 声明了阳性参考与阴性参考。测定 439 与 464 声明了单一阳性参考，
测定 691 什么都没声明。测定 548 是那个归档方程无法复现归档标尺的测定。它的方程把阳性参考
放在 0，把阴性参考放在 -100，只有 0.7620064034151548 的归档值落在该方程所描述的范围内，
而测定 519 是 1.0，测定 1277 是 0.9841269841269841。</p>

<p>测定 691 允许的是关于某个化合物在已声明浓度上的陈述，使用档案自己的措辞，并包含它所报告
阈值的边界。档案把化合物 135415497 记为 INACTIVE，并把它的 MIC 报告为大于 100.0 微摩尔。
它不允许的是按效力给化合物排名、声称任何浓度上的响应为 0 百分比或 100 百分比，以及把它的
阈值与标尺由具名对照确定的测定的阈值相比较。</p>

</details>
