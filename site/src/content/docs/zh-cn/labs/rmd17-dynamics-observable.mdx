## 运行之前

**模式：在一条已存在的真实从头算轨迹上，对一次确定性计算做独立复现。** 没有运行任何新的
分子模拟，也没有制备任何结构。本命令读取的两个文件是本仓库另一处已经用过的
rMD17 开发角色体系（乙醇、丙二醛），那里问的是完全不同的问题：能量预测。本命令对同样的
文件问一个不同的问题，且不触碰那里的划分、所选惩罚项，或已锁定的苯与尿嘧啶评估。

```bash
python labs/rmd17_system_state/run_lab.py download-development   # 若尚未下载
python labs/rmd17_system_state/inspect_dynamics.py show
python labs/rmd17_system_state/inspect_dynamics.py check
```

需要 Python 3.11 或更新版本以及 NumPy。只有一次性下载需要联网，来源是本实验协议已声明的、
带版本号且 CC0 授权的 Figshare 发行版。

## 这里的"轨迹"指什么

rMD17 为每个分子存储了一次真实从头算分子动力学运行的 100,000 帧，每帧带有分子的笛卡尔坐标、
能量，以及一个 `old_indices` 值，记录该帧在**原始**轨迹中的位置。文件本身的数组顺序与模拟
时间无关。这份冻结协议沿用了姊妹能量回归实验为自己的选帧规则已经写明的同一惯例：对
`old_indices` 做稳定的升序排序。只有排序之后，"前 1,000 帧"才真正对应模拟早期的时间。

## 一个观测量，问一个问题

这里的观测量是质量加权的回转半径 `Rg`，逐帧从坐标和每个原子的标准原子质量计算得到。它回答
的问题是：此刻分子在空间上有多"展开"。本实验声明的问题是：能否从这条轨迹估计出一个平衡值，
以及需要多少帧才能做到。

## 关于不确定性，两种出错方式

一条轨迹的各帧不是独立样本；时间上相邻的帧彼此相似。像朴素标准误那样把它们当作独立样本，
会低估估计值真实的不确定性。把按时间顺序排好的序列切成等长的连续区块，再计算区块均值的
标准误，是教科书式的修正。

以下数值于 2026-09-11 在一台 Apple arm64 机器上、用 Python 3.11.15 与 NumPy 2.4.6 计算：

| 体系   | Rg 均值（Å） | 朴素 SEM（Å） | 100 个区块时的区块 SEM（Å） | 比值 |
| ------ | -----------: | ------------: | --------------------------: | ---: |
| 乙醇   |       1.2130 |      0.000087 |                    0.000288 | 3.30 |
| 丙二醛 |       1.6947 |      0.000235 |                    0.001472 | 6.26 |

按这个度量，丙二醛各帧之间的相关性比乙醇更强。这个比值落在哪一边，是轨迹本身的性质，不是
一条必然成立的数学事实。它在 `show` 里作为一个观测结果被报告；`check` 命令断言的是另一条
永远成立的性质：把所有帧按等长区块加回去求和，必须精确还原直接算出的轨迹均值。

区块数量的选择本身也会改变区块 SEM。乙醇在 10 个区块（每块 10,000 帧）时的区块 SEM 是
0.000289 Å；在 1,000 个区块（每块 100 帧）时是 0.000158 Å，从同一条轨迹算出来却只有前者
的大约一半。一个经过修正的不确定性估计，里面仍然藏着一个待声明的选择。

## 需要多少轨迹才够

对按时间顺序排好的前 `k` 帧求累计均值，与完整 100,000 帧的均值相比：

| 已纳入帧数 | 乙醇，与完整轨迹的差（Å） | 丙二醛，差值（Å） |
| ---------: | ------------------------: | ----------------: |
|        100 |                  +0.00198 |          −0.02528 |
|      1,000 |                  +0.00254 |          −0.00743 |
|     10,000 |                  +0.00054 |          −0.00946 |
|    100,000 |                  +0.00000 |          +0.00000 |

乙醇在 10,000 帧时看起来已经收敛，且远在自身不确定性估计的尺度之内。丙二醛并没有：在
10,000 帧时，累计估计值与最终值仍相差约四到九个自身的区块 SEM（具体倍数取决于区块大小的
选择）。轨迹的百分之十并不会自动足够，而且一个分子上够用的帧数，不会自动迁移到另一个分子上。

## 这没有展示什么

这里每个分子只有一条从头算轨迹，所以这里的任何内容都不涉及独立重复运行之间的一致性。这里
只有一个理论层级，所以这里的任何内容都不涉及力场敏感性。没有运行任何新的模拟。回转半径是
一个标量；它不能刻画完整的构象集合，而对一个九原子分子而言，它本身的动态范围就很有限。以上
任何数字都不是结合亲和力、自由能，或对本仓库未直接加载的任何体系的主张。

## 独立练习

一位同事报告说"回转半径在 1,000 帧内收敛"，用的是一个新的、未命名的分子，且只引用了一个
`k = 1,000` 时的累计均值，说它与最终报告值精确到小数点后三位一致。

1. 说出一个本实验自己的收敛表格总会与累计均值一起报告、但这条主张里缺失的量。
2. 丙二醛在 `k = 10,000` 时的累计均值与最终值精确到小数点后两位一致（1.69 对 1.69），但
   同时仍与最终值相差四到九个区块 SEM（取决于区块大小）。这说明"小数位数一致"作为收敛判据
   有什么问题？

<details data-worked-answer>
<summary>参考答案</summary>

缺失的量是同一个检查点上的分块平均标准误，或某种同样考虑相关性的不确定性，而不是朴素的
那种。没有它，"精确到小数点后三位一致"就无法与"恰好在估计值自身不确定性都分辨不出的尺度上
碰巧一致"区分开来。小数位数一致说的是显示精度，不是论证本身真实的不确定性；丙二醛自己的
数字就显示了一个在三位有效数字下会被四舍五入掉、但在轨迹自身区块 SEM 的尺度上仍然很大的
差值。一个收敛主张需要在同一个检查点、在一个已声明的区块大小下，把不确定性估计一起写出来。

</details>
