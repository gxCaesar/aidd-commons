## 准备与学习目标

本实验属于 `t13-sequence-structure-function-objective`，对应[构建体身份与目标课程](/learn/biologics-design/construct-identity-and-objectives/)。它要回答每项目标是否有公共记录承载相应层面的证据，以及那条记录是什么。完成实验后，你应能指出相应记录、解释其适用范围，并说明为什么不能用另一项目标的证据填补空白单元格。了解登录号、沉积结构和表格记录即可开始。这里可返回[英文原文](/labs/objective-ladder/)。

运行模式是按冻结协议重新独立计算。读取使用项目 Python 环境和 CPU。首次下载需要网络，后续步骤读取缓存，不需要加速器。协议在读取记录之前固定受检实体、目标、来源路径和坐标审计容差。

## 各项目标的证据

### 序列恢复

结构档案的比对记录标明沉积聚合物区域及其 UniProtKB 参考序列。实验只在该比对覆盖的区域逐位比较序列。匹配比例不描述比对范围以外的位置，也不能证明整个登录号的序列均已恢复。

### 折叠

实验沉积结构记录实验所产生状态下的一种构象。模型档案也为每个登录号保存一个预测。预测模型是计算输出，不是折叠的实验观测。两类记录都不能证明该构象适用于其他状态。

### 结构合理性

实验以 2.0 angstrom 的碰撞距离和 0.45 angstrom 的键长容差审计沉积坐标行。只有至少 500 行坐标的条目才接受审计。行数包括受检实体、其他组分、配体和水。几何形状可接受只说明坐标文件内部一致，不能证明文件描绘的折叠正确。

### 结合

只有结构档案本身将结构关联到受检登录号时，SKEMPI 2.0 的行才可提供实测亲和力值。沉积结构中的组分不能替代该测量。沉积条目中也会出现结晶添加剂和离子，因此单凭组分存在不能认定实测亲和力。

### 催化

UniProtKB 登录号可能带有命名反应和目录编号的催化活性注释。注释记录来源所述内容，不是实测速率。注释数量与不同目录编号的数量应分别计数。

### 功能

UniProtKB 登录号可能带有功能注释。注释存在说明来源对功能作了陈述，不等于直接测量序列恢复、折叠、几何形状、结合或催化。

## 空白单元格

DHFR 的结合单元格因 `no-affinity-record` 而为空。亲和力档案没有任何一行命名该目标的结构，声明结构 1BOZ 也没有结合组分。ESR1 同样没有实测亲和力记录，尽管 11SD 带有 A1DAI。ABCD1 也没有实测亲和力记录，尽管 6C0V 带有 ATP 和 MG。这些组分都不能把空白单元格变成测量。TP53 和 ESR1 的催化单元格因 `no-catalysis-annotation` 而为空，它们的登录号既没有催化活性注释，也没有酶目录编号。空白单元格描述的是对指定来源的这次读取，并不能证明其他地方不存在此类证据。

## 演算解释与独立练习

ESR1 的审计包含 3845 行坐标，但只有 93 行属于受检实体。按照预先声明的阈值，0 次碰撞描述的是整个受审计条目，包括条目中的其他材料。不能据此单独认定文件描绘的折叠正确。

练习。一份报告把 6C0V 中的 ATP 组分视为 ABCD1 有实测结合值的证据。指出填补结合单元格实际需要什么记录，并说明目前该单元格的状态。

## 重新计算结果

下载步骤一次性收集协议声明的公共记录，并在读取亲和力快照前校验其字节长度。再次运行时会复用缓存。检查器先展示各项目标的记录或缺失原因，再把重新读取的结果与已提交摘要比对。导出步骤在成功读取后写入并覆盖现有摘要。最后一条命令检查实验协议和分析。亲和力快照保存在缓存的 `skempi` 子目录。请从仓库根目录依次运行以下命令。

```bash
.venv/bin/python labs/objective_ladder/run_lab.py download
.venv/bin/python labs/objective_ladder/inspect_objective_ladder.py show
.venv/bin/python labs/objective_ladder/inspect_objective_ladder.py check
.venv/bin/python labs/objective_ladder/export_summary.py
.venv/bin/python -m pytest labs/tests/objective_ladder -q
```

公开的 LiteFold 镜像大小为 6148969 字节，包含 7085 行。每次运行均校验字节长度。下载首次需要网络，其余命令读取本地缓存。

## 材料无法证明的内容

这是对指定日期的公共记录的读取，不是预测或评分练习。实验不预测或评分任何数值，也不对受检实体排名。一项目标有记录不能替代另一项目标的证据。尚未观察到读者学习结果，因此可运行的测试不能证明学习成效。这次读取描述的是 2026-10-22 可用的记录，不保证以后查询档案时得到相同内容。
