## 准备与学习目标

请先阅读[检索、工具与反馈](/learn/scientific-agents/retrieval-tools-feedback/)。本实验审核项目自身的实验室返回记录。你将按 6 项已声明的约束检查返回记录，找出每次拒绝对应的字段，并区分自我描述完整的产物与经过验证的测量。了解 JSON 会有所帮助。[英文原版](/labs/tool-contract-audit/)是本指南的规范版本。

本实验采用冻结协议下的全新独立计算模式，读取本地已提交的返回记录。使用项目的 Python 3.11 环境和 CPU。无需网络、下载或加速器。`download` 命令只验证本地材料，不写入文件。检查命令也不写入文件。导出程序仅在检查通过后覆盖精简摘要。

## 返回记录契约

每个计数单位是一份实验室返回记录。本审核纳入所有具有已提交返回记录的实验室，但不纳入本审核自身。它的返回记录正是审核写出的文件，因此冻结协议将其排除在输入集合之外。协议还规定了配套文件。检查器为每份记录返回全部失败字段。字段缺失与字段存在但值为空或无效会得到不同的原因。实验室特有的结果字段可以保留。

| 契约部分 | 声明的规则 |
| --- | --- |
| Schema | `schema_version`、`protocol_id`、`computed_on`、`software`、`environment`、`side_effects`、`outcome_status` 和 `scientific_meaning` 必须存在并符合声明的类型。前 4 项是所有已观察返回记录共有的字段。其余字段使完整的返回契约明确可查。 |
| Version | 非空的 `schema_version` 与 `protocol_id` 标识有版本的产物。缺少任一字段时，不能把返回记录视为有版本的产物。 |
| Environment | 必须有 `software.python`、非空的 `environment.requires` 与 `environment.unavailable`，且 `environment.can_attest_external_execution` 必须为 false。返回记录不能证明进程实际在哪个环境运行。 |
| Side effects | `side_effects.allowed_writes` 必须是仓库相对路径列表。空列表声明不允许写入，使该声明可以用独立轨迹核查。 |
| Error states | `outcome_status` 只能是 `complete`、`no_result` 或 `halt`。`no_result` 不许可可用结果，`halt` 还要求停止。源实验室没有统一的顶层错误字段，因此不能把状态缺失当成成功。 |
| Scientific meaning | `scientific_meaning.licenses` 与 `scientific_meaning.does_not_license` 必须是非空文本。本审核另行计数已有的明确限制字段，不把它们当作完整的意义说明。 |

## 独立检查

在 `show` 中比较 `applicability_domain_audit` 与 `assay_endpoint_controls`。前者声明了 `does_not_do` 限制，后者没有检索范围内的限制字段。两者仍因缺少 E、S、R 和 M 而不满足完整契约。明确限制很有用，但不能代替执行状态或写入声明。

## 材料的限制

本实验审核契约，不审核测量。通过的返回记录仅说明产物能够自我描述。审核不能证明实验室测量结果真实、工具在记录所称的环境中运行，或读者能够仅凭返回记录复现结果。环境声明或允许写入列表不是独立的进程轨迹。判定结果不构成实验室排名，也不衡量其科学质量。尚未观测到读者学习成效。
