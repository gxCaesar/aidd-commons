## 运行之前

**模式：对已提交文件做可运行的检查。** 下面的命令只读取本仓库中已经保存的 JSON，
不发起网络请求、不下载任何东西、不导入第三方包、也不训练任何模型。它不复现实验，
而是回答一个更靠前的问题：这份数据到底是关于什么的数据，哪些行从一开始就没被允许进入。

大多数被报出来的模型误差之所以不可比，是因为它们背后的契约不同。一个数字只有在你能说清
它由哪个测定产生、建模的是哪个量、拟合开始前排除了哪些行之后，才有意义。

```bash
python labs/chembl_egfr/inspect_contract.py show
```

## 1. 筛选单元是测定，不是靶点

第一段列出两个测定：`CHEMBL5736995` 为主要测定，`CHEMBL3705421` 为复现测定。
两者都是结合测定，置信分数都是 9，BAO 格式相同，各自来自不同的文献。

它们是两个单元，不是一份"关于 EGFR"的数据集。把它们分开正是要点所在：在第一个测定上拟合的
模型，之后要被追问它能否迁移到第二个。输出同时写明这个选择排除了什么 —— 排除了该版本中
其余全部 EGFR 测定，因此也排除了任何关于 EGFR 活性的一般性主张。

迁移问题在这里有答案，而且是否定的。Morgan Ridge 在主要测定上取得最低误差
0.41833032711934154，随后在复现测定上取得最高误差 3.1316760122202343，
高于 descriptor Ridge 的 0.57926487123557 和训练均值的 0.898379755056597。
只在主要测定上选表示，选中的恰好是在第二个测定上败得最惨的那一个。

## 2. 终点是一个决定，不是一列数据

第二段显示：被测量的量是 IC50，只接受严格等号关系，只接受纳摩尔单位，建模目标是由它们
导出的 `pchembl_value`。同一母体上的重复测量按中位数归并，一致性容差为 0.011。

其中每一条都是一次排除。Ki 与 Kd 的行从不进入。非纳摩尔单位的行从不进入。所有大于号与
小于号的测量都从不进入，而这些删失行恰好集中在弱活性一端。在这份契约下训练出的模型，预测的
是"在某一种测定格式下可被测出的化合物的效价摘要"，它并不预测一个化合物是否有活性。

## 3. 进入的行，与没能进入的行

第三段追踪行数。主要测定读入 975 行，因结构缺失排除 9 行，保留 966 行。这 966 行描述
902 个母体分子，其中 57 个带有重复测量。复现测定读入 173 行，无排除，保留 173 行，
对应 170 个母体。没有任何母体同时出现在两个测定中。

独立单元是 ChEMBL 母体分子，不是行，也不是盐。盐与其母体是同一个单元，因此不可能被分到
划分的两侧。这段算术被打印出来是为了让分母保持可见：一个不带"进入了多少"的产率或误差率，
是无法核对的。

## 4. 核对产物之间是否仍然自洽

```bash
python labs/chembl_egfr/inspect_contract.py check
```

它会在协议、开发摘要、锁定摘要与执行修订之间重算九项关系，确认：四份产物声明同一个协议；
两个测定的准入算术都能闭合；每个被选中的 alpha 都属于冻结网格；保存下来的验证网格在协议
自己的规则（验证误差最小、并列时取较小 alpha）下能复算出被记录的 alpha；锁定运行沿用了这些
alpha 而没有重新选择；两次运行报告相同的 Python、NumPy 与 RDKit 版本；常数基线报告的是
未定义的秩相关而不是零。

这些确认的是**内部一致性**。它不是科学有效性的检查，也无法告诉你这个终点是不是值得建模的
那一个。一份契约完全可以自洽，同时回答着一个没有人问过的问题。

## 5. 修订是用来做什么的

命令最后给出的是一条说明，而不是一次失败。冻结协议至今仍把它的锁定评估记为 `not_run`，
而锁定摘要写着 `completed`。协议**没有**被改写成与结果一致。一份单独的修订记录了这次变化，
写明它只取代执行措辞，并禁止任何新的选择自由度。

改写协议会更省事，也会得到一套更整齐的文件。但它同时会销毁这样一份证据：执行规则在协议
签发之后发生过改动，以及改动发生在什么时候。

## 独立练习

一位同事报告说，在"同一份 ChEMBL EGFR 数据"上取得了 0.30 的平均绝对误差，优于此处记录的
0.41833032711934154，并提议改用他们的表示。在比较这两个数字之前，请说出你需要向他们索要
本契约中的哪三个字段，以及每个字段取不同的值会对这次比较造成什么影响。

<details data-worked-answer>
<summary>参考答案 —— 三个字段，三种不同的失效</summary>

**测定。** 如果他们的行来自另一个测定，或来自多个测定的合并，那么两个数字描述的是不同单元，
根本不可比。这是第一个要问的问题，因为这里一旦不同，另外两个就不再相关。合并测定通常还会
压低报出的误差，因为容易的化合物会在多个来源中重复出现。

**接受的关系与单位。** 如果他们接受了删失行，他们的标签分布就包含了本契约丢弃的弱活性一端。
范围更宽通常会抬高误差，因此"范围更宽而误差更低"是更强的结果。反过来，如果他们把范围收得
更窄，更低的误差可能只意味着题目更容易。

**实体单元与归并方式。** 如果他们建模的是行而不是母体分子，同一化合物的重复测量就可能同时
落在划分两侧，报出的误差会偏乐观。这里的中位数归并与母体规则正是为了阻止这种情况，因此这次
比较只有在对方契约也具备它们时才算公平。

完整的回答会注意到：以上三点都无法通过盯着那两个误差值来判定。它们是数据集的属性，不是模型的
属性，而更小的那个数字很可能是更弱的结果。

</details>
