## 学习目标

完成实验后，你应能够：

1. 区分基于验证的模型选择与已完成的评估；
2. 从分子体系状态追溯到归一化成对距离直方图；
3. 解释不同元素组成为何合理地产生不同特征维度；
4. 分别拟合体系内基线，同时从验证证据选择一个共享正则化值；
5. 认识到原始索引排序带来时间相关性挑战，而不保证独立；
6. 说明描述性开发证据为什么不能建立跨体系泛化或 SOTA 结论。

## 来源与数据结构契约

来源是 [Figshare](https://doi.org/10.6084/m9.figshare.12672038.v4) 上的 revised MD17 v4 发布，论文由其[出版 DOI](https://doi.org/10.1088/2632-2153/abba6f)标识。机器可读契约位于 `labs/rmd17_system_state/protocol.json`；公开数值依据分别是已复核的 `labs/rmd17_system_state/development-summary.json` 和 `locked-summary.json`。

本地 NPZ 结构要求核电荷、坐标、能量、力和原始索引字段。教学模型只能用 `nuclear_charges` 和 `coords` 作特征，用 `energies` 作目标。力与历史数组接受结构完整性检查，但不是特征输入或目标。这可防止看似方便的数组悄悄改变科学问题。

## 体系状态变量

每行是某个具名体系的一种分子构型。体系状态由原子身份和坐标组成。这些输入决定存在哪些无序元素对通道，再将每个通道变为按固定原子对数量归一化的距离直方图。一个分子中不存在的通道，不必出现在另一个分子的特征向量中。

因此面板按体系报告布局，而不假装不同组成的分子共享同一列空间。这是表示契约，不是跨分子迁移模型。

## 采样与划分

冻结流程按原始索引稳定排序帧，采样已声明的秩位置，再把该选中顺序的连续部分依次分配给训练、验证和体系内评估。分割时间线与汇总间隔诊断以面板中的数值为准。

原始索引排序保留了顺序线索。分子动力学帧仍具有时间相关性，因此有序划分使依赖挑战可检查，却不会消除时间相关性，也不会把构型变成独立的生物或化学重复。

本实验不使用来源提供的五对 train/test CSV。来源记录将其描述为划分索引文件，但没有说明这些索引代表时间顺序、如何映射到第 4 版 NPZ 行，也没有使其成为独立分子体系单位。不能用它们悄悄替换本实验声明的 `old_indices` 流程。

## 特征与模型契约

特征构造使用按字典序排列的无序元素对、固定距离区间边界、溢出区间和逐通道归一化。同一体系的训练、验证和评估分区必须共享通道布局。跨体系的布局差异符合预期，应检查而不是拒绝。

对每个体系，对照重复输出其训练能量均值。学习模型拟合仅训练集 scaler，对训练能量做中心化，并用冻结 alpha 网格拟合 Ridge。每个开发体系的验证 MAE 向共享选择规则贡献一个标量。共享的是选中的 alpha，而不是拟合出的 scaler 或系数。

## 开发阶段观测

已复核摘要显示，两个开发体系的体系内 Ridge MAE 均低于训练均值对照。这只是开放开发部分的描述性证据。它没有证明表示或模型可迁移到另一分子体系，也没有对冻结教学对照以外的方法排序。

使用面板的指标表、所选 alpha 提示和间隔诊断，不在正文复制数值。保持单一数值依据，有助于审查重新生成的公开摘要。

## 已完成评估与剩余边界

苯和尿嘧啶使用开发阶段选定的 alpha 一起完成评估。它们的 `locked-summary.json` 与历史开发快照分开；后者的 `not_run` 字段仍描述评估前状态。来源文件公开，因此一次性边界是流程约束，不是受限访问声明。

不要用锁定结果选择新 alpha、修改特征映射或替换基线。锁定结果改变证据状态，不开启新的开发循环。已经完成运行的作者工作区拒绝再次预检或评估，应保留该保护。

两个体系内的 Ridge 比较均优于各自训练均值对照，但每个模型都使用了其自身体系的训练帧。这些结果不建立零样本跨体系迁移，也不建立力预测精度。

运行后验证从两个来源文件重算了训练均值指标和目标范围。原始运行没有保存逐帧 Ridge 预测，因此运行后未独立重算 Ridge 分数。公开结果保留这一证据限制。

`uv run python labs/rmd17_system_state/export_locked_summary.py` 仅导出已完成分数，不下载数据，也不拟合模型。

## 练习

1. 查看面板中各体系的通道列表。解释为什么一个通道在某种组成中存在、在另一种组成中不存在，并不说明实现错误。
2. 比较每个开发体系的训练均值和 Ridge 行。哪项结论得到支持？哪项跨体系结论仍超出证据？
3. 阅读汇总的原始索引间隔。描述它们揭示了怎样的有序采样流程，又不能揭示独立性的哪些信息。
4. 提出一个新分子体系。在拟合前，列出需要新冻结来源、划分、特征布局和评估契约的字段。

<details>
<summary>参考答案与评分标准</summary>

1. 通道表示体系中实际出现的无序元素对。组成中没有符合条件的原子对，就没有该通道。合格答案应将电荷向量与原子对计数关联，并检查同一体系各分区的通道布局一致；不强迫无关分子进入未经说明的共享特征空间。
2. Ridge 在两个开发体系和每个单独评估的锁定体系中都有较低 MAE。受支持的结论是相对于已声明对照的体系内改善。得分答案必须说明每个模型在自己的体系上训练，两条相关轨迹不是数百次独立重复，也不是零样本迁移证据。
3. 正且有序的间隔验证原始索引采样约定和选中位置的间隔，但不测量去相关时间，也不保证误差独立。合格答案应区分索引间隔与时间独立性结论。
4. 新契约需要具名且带版本的来源文件、元素身份、坐标与能量单位、允许数组、采样与划分规则、元素对通道布局、模型与冻结 alpha 策略、指标和报告单位。得分答案须在评估该体系前声明这些内容，并在 Ridge 未优于对照时仍保留结果。

</details>

## 局限与失败门槛

- 缺少必需数组、存在非有限值、原子数不一致或分区布局不匹配，都是数据契约失败，不是手工修补结果的理由。
- 原始索引成员非递增或公开摘要格式错误时，应拒绝继续，不得生成汇总诊断。
- 已观测开发比较没有独立的跨体系留出，不要描述为泛化结果。
- 公开摘要排除帧身份、划分成员、逐条预测和 scaler 状态，但包括已完成的汇总指标。若发布材料出现帧级或内部执行材料，应在发布前停止并修复公开边界。
