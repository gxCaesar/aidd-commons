## 准备与学习目标

本实验对应 `t07-applicability-domain`。请先阅读[适用域诊断](/zh-cn/learn/qsar-properties/applicability-domain-diagnostics/)和 [FreeSolv 基线指南](/zh-cn/labs/freesolv-honest-baselines/)。你将计算分子到拟合总体的距离，比较两个距离半区的误差，并说明为何结果只是诊断而不是适用域边界。了解分子描述符和岭回归会有所帮助。

模式是依照冻结协议和本地 FreeSolv 发行文件进行全新独立计算。使用项目的 Python 3.11 环境和 CPU。无需网络、下载或加速器。`check` 与 `show` 不写入文件。导出程序仅在审计通过后覆盖已提交的聚合摘要。

```bash
.venv/bin/python labs/applicability_domain_audit/run_lab.py check
.venv/bin/python labs/applicability_domain_audit/inspect_applicability_domain_audit.py show
.venv/bin/python labs/applicability_domain_audit/inspect_applicability_domain_audit.py check
.venv/bin/python labs/applicability_domain_audit/export_summary.py
.venv/bin/python -m pytest labs/tests/applicability_domain_audit -q
```

## 距离与误差对比

距离表示是本实验选定的五个 RDKit 性质，即 MolWt、MolLogP、TPSA、NumHDonors 和 NumHAcceptors。每项性质的绝对差除以该性质在训练集中的总体标准差，标准差为零时使用 1。五个缩放后的差值取平均，形成每个测试与训练分子对的距离。最小的成对距离就是测试分子到训练集最近邻的距离。岭回归用感知手性的 Morgan 指纹作预测。其 `alpha=1.0`、半径 2 和 2048 位均在计算前固定。

下列中位数和四分位数概括了 128 个到训练集最近邻的距离。距离没有物理单位。最近邻距离最大的测试分子由来源 ID 指明。表中也给出该分子与最远训练分子的比较，以明确这两种不同的成对陈述。

| 距离统计量 | 数值 |

| 第一四分位数 | 0.000205 |
| 中位数 | 0.023539 |
| 第三四分位数 | 0.082516 |

## 材料局限

这次运行中，较大距离半区的误差中位数较高。该对比不能确定可用阈值，也不能估计某个新分子的误差。不同结构的这五个性质可以几乎相同。本审计不拟合更好的模型，也不把选定距离转为化学机制主张。骨架划分在一种操作性骨架定义下检验留出分组。随机划分可能让相关骨架出现在两侧，因此支持的是另一种泛化主张。
