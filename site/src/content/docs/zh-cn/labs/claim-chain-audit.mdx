## 准备与学习目标

本实验对应 `t18-evidence-package-claim-chain`。运行前请阅读[候选药物提名综合练习](/zh-cn/learn/candidate-nomination/capstone-workbook/)。你将依据证据条目解析每个指定链接，区分书面练习与可运行任务，找出最弱链接，并比较项目记录与独立阅读。了解 YAML 会有所帮助，无须训练模型。

## 模式与命令

模式是依据冻结协议和仓库自身已提交的比较记录进行全新独立计算。使用 Python 3.11.15、PyYAML 6.0.3 和 CPU。命令不需要网络、下载或加速器。请在仓库根目录运行。`download`、`show` 和 `check` 不写入文件。导出程序仅在检查通过后覆盖本实验的精简汇总。

```bash
.venv/bin/python labs/claim_chain_audit/run_lab.py download
.venv/bin/python labs/claim_chain_audit/inspect_claim_chain_audit.py show
.venv/bin/python labs/claim_chain_audit/inspect_claim_chain_audit.py check
.venv/bin/python labs/claim_chain_audit/export_summary.py
.venv/bin/python -m pytest labs/tests/claim_chain_audit -q
```

## 最弱链接

一条链的强度取决于最弱链接。检查程序取换算后深度的最小值，指出达到该深度的第一个主题，并统计同一条链中低于最高状态的链接。当前选取的 16 个链接都有标为 `opened` 的证据。证据列表为空，或其中的条目均不为 `opened` 时，链接成为未解决状态，整条链不能报告为受到支持。

## 独立核查

设想第一条链的副本中，机制主题的证据条目不再标为 `opened`。在对构造的测试记录运行 `check` 前，先预测最弱链接和支持状态。该链接变为 `unresolved`，机制主题成为最弱链接，整条链不能报告为受到支持。对剩余深度取平均值会漏掉这项拒绝规则。

## 材料局限

一条链只表明每个指定链接的材料存在，并说明材料陈述了什么。它不能确立关于化合物、靶点或疗法的主张。链的端点仅限于它指定的主题。所选主题并不描述同一个候选物，项目自评的深度标签也不验证其背后材料在科学上正确。检查通过仅表示这些边界得到执行，并不测量读者学习结果。
