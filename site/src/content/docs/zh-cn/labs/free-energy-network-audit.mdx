## 准备与学习目标

本实验为[自由能循环课程](/learn/physics-based-modeling/free-energy-cycles-and-convergence/)提供可运行的网络任务，对应 `t11-free-energy-endpoint-network`。完成后，你应能恢复变换及其重复估计，区分两条炼金路径，闭合预先声明的循环基，并保留超过不确定性阈值的差异。先修知识包括自由能差、有向图和标准误。[英文原版指南](/labs/free-energy-network-audit/)是规范版本。

模式为按冻结协议进行全新独立计算。使用项目的 Python 3.11 环境和 CPU。只有首次下载需要网络。通过验证的来源快照进入缓存后，检查与导出可以离线运行。下载命令写入独立缓存，检查命令不写文件，导出命令仅在验证通过后替换小型汇总。

```bash
.venv/bin/python labs/free_energy_network_audit/run_lab.py download
.venv/bin/python labs/free_energy_network_audit/inspect_free_energy_network_audit.py show
.venv/bin/python labs/free_energy_network_audit/inspect_free_energy_network_audit.py check
.venv/bin/python labs/free_energy_network_audit/export_summary.py
.venv/bin/python -m pytest labs/tests/free_energy_network_audit -q
```

## 端点与不确定性规则

端点是按配体顺序定义的相对结合自由能差。每个映射满足 `DeltaDeltaG_bind(A to B) = DeltaG_complex(A to B) - DeltaG_solvent(A to B)`。复合物边和溶剂边对应不同的化学体系，不能互相替代。本计算不产生绝对结合自由能。

档案将每项变换连接到协议 DAG 和单元结果。每条边有 3 个重复 ID 各异的选中估计。读取器在每个重复中选择记录的最高代数，对 3 个选中值取平均，且不把没有估计值的单元记录纳入平均。每条路径的标准误取重复均值的来源误差传播值与重复间标准误中较大者。复合物和溶剂误差按平方和开方合并。来源提供单元估计的不确定性。这种传播将重复、两条路径和不同的边视为独立。如果存在共同误差，不确定性可能被低估。

实验从配对后的结合边构建确定性的生成森林。每条剩余边沿唯一的树路径形成一个基本循环。只有当循环有符号和的绝对值不超过其边标准误平方和开方的 2 倍时，循环才算闭合。2 倍标准误阈值在读取残差前已写入协议。未闭合循环连同名称和差异保留在结果中。这个循环基不枚举所有简单循环。

## 材料限制

闭合循环只是在既定边选择与不确定性规则下检验内部一致性。它不是对真实值的测量，也不能证明某条边正确、收敛或经过实验验证。未闭合循环揭示这个循环基中的差异，但单凭它不能定位造成差异的边或模拟。本计算不声称得到绝对结合自由能，不比较实验端点，也不按闭合程度给系统排序。尚未观测到读者学习成效。
