## 这个实验要问什么

数据库说一个化合物有一个报告值。这个值是一个数字，但承载它的那一行只是众多行中的一行，
而读者用来描述该化合物证据规模的那个数字，取决于有多少行在一条已声明的规则下存活下来，
以及存活者中有多少其实是同一个实验被数了两次。

本实验声明十五个真实的 ChEMBL 分子标识符，把每一个解析到它所属的母体分子，对这些母体
名下 ChEMBL 归档的每一条活性行应用一条准入规则，然后报告每一条存活测量的检测、文献、
靶点、生物体、检测类型、置信分数和关系符号。这里没有拟合任何模型，没有划分任何划分，
也不预测任何东西。这个计数是描述性的。

已声明的问题在于，一个化合物的证据规模，究竟是数据库返回的行数，还是其下的独立测量数。
对于这组解析出十个母体分子的队列，二者在行数最多的那个化合物上相差两个数量级以上，
而在通过准入的行中，超过一半是删失的界值而不是取值。

## 运行之前

**模式：在一个实时、带版本号的数据库发行版上做独立计算。** 这里没有任何冻结的一次性
评估。协议固定了准入规则、实体规则和分组规则，但 ChEMBL 发行版原则上可能被后续版本
取代，因此下载在抓取任何东西之前会重新核对实时发行版字段。本实验任何地方都没有拟合过
模型。

从仓库根目录开始：

```bash
uv sync --group dev
uv run python labs/decision_unit_scope/run_lab.py download
uv run python labs/decision_unit_scope/inspect_decision_unit_scope.py show
uv run python labs/decision_unit_scope/inspect_decision_unit_scope.py check
```

需要 Python 3.11 或更新版本、NumPy 与 RDKit。只有下载需要联网，读取的是公开的 ChEMBL
REST API。下载把十三件产物写入 `.cache/decision_unit_scope/` 下被 git 忽略的缓存。
一次冷启动发起 41 个 HTTP 请求，在网络上搬运 9,794,036 字节，并在本地留下 11,883,104
字节的缓存，因为每件产物都按本实验自己的确定性序列化方式写出。下载可续传，因此
缓存字节长度仍与协议中冻结值一致的产物会被保留而不再抓取。

`show` 打印实体解析、准入漏斗、逐化合物普查以及具名例子。`check` 重算各项不变量，
任何违规都会以非零码退出，而且它在没有网络、没有缓存的情况下也能运行，因为已提交的
摘要足以支撑摘要层面的不变量。另一个导出步骤会用缓存就地重写已提交的摘要，对同一份
缓存重跑会精确复现该文件。

## 数据是什么

一切都来自一个真实数据库的一个发行版。ChEMBL 37 发布于 2026-05-01，通过 ChEMBL REST
API 读取。实时发行版在每次运行时都被断言，因此后来的发行版会让下载停下，而不是悄悄
改变计数。

终点范围是纳摩尔效力。只有当一行的标准类型是 AC50、EC50、IC50、Kd 或 Ki 之一、
单位是 nM、并且带有关系符号时，它才被计入。关系符号为 "=" 的是点测量。关系符号为
">"、"&lt;"、">=" 或 "&lt;=" 的是界值，而界值永远不与点值合并汇总。没有关系符号的行两者
都不是，被搁置一旁。

本发行版的 ChEMBL 批量产物被有意不用。发行目录提供 5,764,252,857 字节的 SQLite 转储、
2,101,694,224 字节的 MySQL 转储、2,088,889,426 字节的 PostgreSQL 转储和 931,156,420
字节的 SDF，全部测于 2026-10-21。REST API 在一行里同时携带测量、实体、检测、文献、
靶点和关系，因此这些转储会被付了钱却用不上。

## 读数是什么

三条规则把行变成测量，并且按这个顺序生效。

**实体规则。** 推断单位是 ChEMBL 母体分子。每一条活性行同时携带真正被测的形式和该行
所归属的母体实体，计数保留在母体上。若被测形式与其母体不同，该行就是在母体的某种
盐型或混合物上测得的。这样的行被准入而不是被拒绝，因为它是同一个母体实体在不同
制剂上得到的真实测量，并且被单独计数，好让读者看到该化合物有多少证据来自母体结构
之外的东西。十五个已声明分子解析出十个母体，因为其中五个是队列内某个化合物本身的
盐型制剂。

**准入规则。** 每一行都要对照一份已声明的排除理由清单检验，匹配到的第一条理由就是
该行的理由，因此这些理由把输入行恰好划分开。顺序从这一行报告了什么，到 ChEMBL 如何
整理了它，再到这一行如何声明自身的独立性，最后是它的质量标记。

**分组规则。** 两条被准入的点测量在共享一个检测、一篇文献和一个终点类型时，是同一次
测量，因为一次实验在一篇论文中报告一个终点就是一个数字。实验单位去掉终点类型，与
分组单位并列报告。

由此产生的三个计数在任何比较之前都值得分开看待。报告行数是普通查询返回的东西。
不同检测数是中间一步，它丢掉了文献，因此同一篇论文里被录入两次的一次检测只算一次。
研究对象量是独立测量数，即被准入的点测量中不同检测、文献与终点键的个数。

存活下来的东西从来不是一个裸数字。每一条被准入的测量都带着七份语境，对某一个化合物
而言，它们读起来如下。

| 读数字段 | VALPROIC ACID（CHEMBL109）的取值 |
| --- | --- |
| 独立测量 | 27 |
| 不同检测 | 27 |
| 不同文献 | 15 |
| 不同靶点 | 22 |
| 终点类型 | IC50 17，AC50 9，EC50 1 |
| 检测类型 | 结合 20，功能 7 |

| 125 条被准入界值的关系符号 | 全部为 ">" |

有三个发现值得读者留意。

**行数不是测量数。** 丙戊酸在 ChEMBL 37 中有 6,294 条活性行，而在本协议下有 27 次
独立测量，因此本实验自己的输出给出每次测量对应 233.1 行。这些行大多根本不是效力
测量。其中 482 行报告组织严重度评分，364 行报告裸的活性结果，298 行报告 ED50，
128 行报告体重，119 行报告 TD50。在这 6,294 行中，2,349 行报告的东西在已声明的终点
家族之外，3,674 行从未被整理进 ChEMBL 的标准字段，99 行带有数据有效性备注，10 行被
标记为潜在重复，10 行没有关系符号。这留下 152 条被准入的行，其中 125 条是界值，27 条
是点测量。125 条界值全部带 ">" 关系符号，其中 124 条把取值置于 10,000 nM 之上。数行
的读者会把该化合物的证据规模高估两个数量级以上。

**存活的行大多是界值而不是取值。** 全队列中，1,004 条被准入行里有 516 条是删失界值，
488 条是点测量。界值是一次真实测量，也是一个没用的数字，因为它无法与点值平均汇总。
一个唯一存活证据是 IC50 大于 10,000 nM 的化合物，压根没有被证明是强效的。

**盐型不是边缘情况。** 在 488 次被准入的点测量中，71 次是在母体的盐型或混合物形式上
报告的，而不是在母体结构上。DARBUFELONE 是极端的一个。它的 12 次被准入测量中有 5 次
来自 CHEMBL109745，也就是同一化合物的甲磺酸盐，而它 12 次的独立测量计数由母体结构
上的 7 次与该盐型上的 5 次构成。把两条 ChEMBL 记录当成两个化合物的读者，会拿一个
盐去和自己的游离碱比较，并把差异说成分子的性质。已声明的队列包含五对这样的记录，
这正是十五个已声明分子解析为十个推断单位的原因。

队列中有一个化合物根本没有可准入的测量。MINOXIDIL SULFATE（CHEMBL906）在 ChEMBL 37
中有四条活性行，而在本协议下有 0 次被准入的点测量。其中两行从未被整理进 ChEMBL 的
标准字段，一行带有数据有效性备注，一行报告的东西在终点家族之外。ChEMBL 还把它存成
单组分结构，因此它的名字承诺了一个它的记录并不包含的盐。

## 这没有展示什么

测量的计数对效应的大小或质量什么也没说。本实验对这几个化合物中任何一个有多强效、
多具选择性、多安全或多大临床用途都未作陈述，也没有在它们之间做任何比较。

队列是十五个为检验计数规则而挑选的分子。它不是 ChEMBL 的随机样本，在它上面算出的
任何东西都不估计盐型报告、整理或终点覆盖在整个数据库中如何分布。488 次中的 71 次
盐型测量是这十五个分子在 ChEMBL 37 中碰巧是什么样子的计数，不是一个带抽样误差的
比率，因此不报告不确定区间，也不应当报告。

终点范围是一个已声明的纳摩尔效力家族。报告 ED50、GI50、效力、裸活性、抑制、百分比
抑制或血液学计数的行都在它之外，并按此计数，因此这里的测量计数是那个家族内部的
计数，换一个已声明的家族就会改变。

分组单位把同一检测、同一文献、同一终点类型的两行当作一次测量。这是关于什么才算
一次独立实验的判断，换一个判断会给出不同的计数。ChEMBL 自己的模式文档指出，潜在
重复标记为零并不保证一次测量是新颖的或独立的，本实验只统计标记所说的内容，不声称
更多。

本协议报告 ChEMBL 所存储的内容。在 ChEMBL 把某个盐型保留为它自己的母体，或把某个
硫酸盐存成不含硫酸盐的形式的地方，本实验不做纠正。它报告存储的组分数和解析结果，
把纠正留给读者。

## 独立练习

一位同事的幻灯片说，丙戊酸是本队列中表征最充分的化合物之一，有 6,294 条 ChEMBL 活性
记录。第二张幻灯片说，它有 27 次独立的效力测量。

1. 说清楚哪一张幻灯片描述了更大的证据规模，并说出解释这两个数字之间差异的两条规则。
2. 仅用上面的表格，说出丙戊酸的 27 次独立测量是在什么上测得的，并说出读者在把其中
   任意两次当作同一种数字之前需要知道的三份语境。
3. 盐型规则准入子实体行并把它计在母体上。说出如果读者改为把 darbufelone 的两条
   ChEMBL 记录当成两个化合物，他们会比较什么；以及如果只是把子实体行删掉，他们又
   会悄悄丢掉什么。

<details data-worked-answer>
<summary>参考答案</summary>

1. 第一张幻灯片描述的证据规模更大，而且它不是比较时该用的那一个。造成这两个数字
   之间差异的两条规则是准入规则和分组规则，它们在实体规则已经把丙戊酸与丙戊酸钠
   归到同一个母体之后依次生效。准入规则把 6,294 行降到 152 行，移除 2,349 行终点
   家族之外的行、3,674 行从未被整理进 ChEMBL 标准字段的行、99 行带数据有效性备注的
   行、10 个潜在重复和 10 行没有关系符号的行。分组规则随后把这 152 行拆成 125 条界值
   和 27 次点测量，而 27 次点测量在检测、文献与终点这个键下归并为 27 次独立测量，
   因此两条规则合起来解释了全部差距。
2. 这 27 次独立测量分布在 27 个不同检测中，取自 15 篇不同文献，涉及 22 个不同靶点。
   读者在把其中任意两次当作同一种数字之前需要知道的三份语境是化合物被测试针对的
   靶点、检测所用的生物体，以及 ChEMBL 置信分数。第四份是被测的形式，因为 27 次中
   有 2 次在盐型 CHEMBL433 上测得，25 次在母体结构上测得；第五份是关系符号，它把这
   27 个点值与同时被准入的 125 条界值区分开。把"丙戊酸有 27 次测量"理解为 27 个
   可以互换的效力值的读者，在这些计数上的每一条上都是错的。
3. 把两条记录当成两个化合物的读者，会拿在 darbufelone 甲磺酸盐 CHEMBL109745 上得到的
   5 次测量，去和在 darbufelone 母体结构上得到的 7 次测量比较，并把差异读作两个分子
   的性质。它不是，因为这两条记录是同一个化合物的两种制剂，那个差异是一个制剂效应
   被读成了化学效应。改为删掉子实体行，则会把计数从 12 降到 7，并悄悄丢掉该化合物
   的一部分证据，而这正是准入盐型行并把它们单独报告所要防止的损失。

</details>
