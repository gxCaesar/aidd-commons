## 运行之前

**模式：对已提交文件做可运行的检查。** 该命令只读取本仓库中已保存的 JSON，不发起网络请求、
不下载轨迹、不导入第三方包、也不拟合任何模型。冻结的 rMD17 实验早已完成，本页补上的是
在运行它之前（或者取代运行它）读懂其契约的路径。

```bash
python labs/rmd17_system_state/inspect_contract.py show
```

## 1. 观测量，以及不许用来预测它的那些数组

目标是能量数组，单位 kcal/mol。只有两个数组可以成为特征：核电荷与坐标。三个被禁用：力，
以及原始数据集在重算之前记录的能量与力。

这条禁令就是全部的泄漏规则，值得看清它为什么必须被写下来。三个被禁数组**都存在于实验要读的
同一个文件里**，其中两个正是模型被要求预测的那个量在更早阶段的记录。文件格式本身不会阻止你
使用它们。一份只列"允许什么"的契约会把这个问题留着；这一份点名了"禁止什么"，而检查器确认
两份清单从不重叠。

## 2. 一千帧是样本，不是轨迹

每个体系有 100000 帧，实验取其中 1000 帧：按一个写明的秩表达式在等距位置上取样，再按原始
索引排序。这 1000 帧分为 600 训练、200 验证、200 评估。

命令会打印被选中的帧在原始轨迹里究竟相隔多远。乙醇相邻两个被选帧的最小间隔是 404 个位置，
丙二醛是 689。**没有任何两个被选帧是相邻的**，所以这个划分不存在最明显的那种泄漏。

但这不等于独立，而且实验自己写明了这一点，没有留给你去假设：稳定排序不会消除分子动力学的
时间相关性。同一体系内的帧仍是一条轨迹的相关观测，这正是协议**直接禁止**帧池化指标与置信
区间的原因。一份禁用指标清单比一句提醒更有力，因为它在阅读时无法被跳过。

## 3. 不给出范围的误差读不了

每个体系的结果都把 MAE、RMSE 与目标范围一起报出来。一旦比较两个体系，原因就显而易见。

苯的 Ridge 模型 MAE 为 1.6022730996053722，常数模型为 2.2343735356479013，目标范围
16.804794804076664。尿嘧啶的 Ridge MAE 为 3.1238744298947863，常数为 3.720448133704194，
范围 33.140174655098235。苯的误差数值上更小，**但它并不显然是更好的结果**：尿嘧啶的范围大约
宽了一倍，而两个体系中模型相对各自常数的改进占范围的比例是相近的。

单独给出的 MAE 会诱使人做一个该数字支撑不了的跨体系比较。把范围印在它旁边，这个比较才变得
可以回答。

## 4. 核对产物之间是否仍然一致

```bash
python labs/rmd17_system_state/inspect_contract.py check
```

共十四项检查，确认：三份产物声明同一协议；允许与禁用数组互不相交且目标不在特征之列；
每个被禁数组确实存在于源文件中而不是假想的；各划分之和等于被选帧数并与锁定运行一致；
每个特征维度恰好等于通道数乘以每通道分箱数；被选中的 alpha 100.0 属于冻结网格并能在协议
自身规则下从保存的验证网格复算出来；锁定运行沿用它而没有重选；两次运行报告相同的 Python、
NumPy 与 scikit-learn 版本；每条锁定结果都带着它的目标范围；被选帧有序且在原始轨迹中从不相邻。

注意并列规则。本协议在完全并列时取**较大**的 alpha，与
[ChEMBL 契约](/zh-cn/labs/chembl-contract-inspection/)取较小的规则相反。两者没有谁更正确，
关键是**各自都在选择开始之前就已声明**——事后才发明的并列规则是一个自由参数。

## 独立练习

一位读者比较两个锁定体系后得出结论：模型在苯上比在尿嘧啶上表现更好，因为
1.6022730996053722 小于 3.1238744298947863。**只使用该命令打印出的数值**，说明这个结论
错在哪里、一个站得住的版本应该怎么说，以及协议禁止的哪一个量本可以用来定这个案。

<details data-worked-answer>
<summary>参考答案 —— 范围、比例，以及那个被禁的区间</summary>

**错在哪里。** 两个误差是在不同范围上度量的。尿嘧啶的目标范围 33.140174655098235 接近苯的
16.804794804076664 的两倍，因此那里更大的绝对误差本身并不表示拟合更差。跨体系比较原始 MAE
比较的是两个不同的问题。

**站得住的版本。** 让每个模型与共享同一范围的对照相比。苯上 Ridge 误差 1.6022730996053722
对常数 2.2343735356479013；尿嘧啶上 3.1238744298947863 对 3.720448133704194。两者都优于
各自的常数，且改进幅度占范围的比例都不大。可以说的是"模型在每个体系内部都胜过常数"，
而不是"它在某个分子上比另一个更好"。

**那个被禁的量。** 每个误差上的置信区间本可以让你判断两处改进的差异是否超过噪声。协议在这里
禁止置信区间，原因就在上一节：同一体系内的帧是相关的，按独立样本计算出的区间会过窄，
从而让这个差异看起来已经被判定。当区间背后的假设不成立时，**什么都不报才是诚实的选项**。

完整的回答会注意到：禁用指标清单不是这个实验的缺陷，而是采样方式的后果；要解除这条禁令，
需要的是另一种采样设计，而不是另一个公式。
