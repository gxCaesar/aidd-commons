## 准备与学习目标

本实验服务于 `t05-relational-knowledge-graph-representation`。先读[类型化关系与证据](/zh-cn/learn/representations/relational-graph-evidence/)。你将区分节点类型和关系类型，把边追溯到声明它的记录，并检验为什么共享任务或阶段不能确立一条缺失关系。了解 YAML 和有向图会有所帮助。

模式是根据冻结协议和已提交目录做新的独立计算。使用项目的 Python 3.11 环境和 CPU。命令无需网络、下载或加速器。前 3 条命令不写文件。只有全部检查通过后，导出器才覆盖已提交的小型摘要。

```bash
.venv/bin/python labs/relational_graph_audit/run_lab.py check
.venv/bin/python labs/relational_graph_audit/inspect_relational_graph_audit.py show
.venv/bin/python labs/relational_graph_audit/inspect_relational_graph_audit.py check
.venv/bin/python labs/relational_graph_audit/export_summary.py
.venv/bin/python -m pytest labs/tests/relational_graph_audit -q
```

## 来源记录与图谱约定

审计读取于 2026-10-25 重新计算的本地目录快照中已提交的 228 条资源记录。每条记录提供一个类型化节点。`relations` 条目提供一条从声明记录指向目标的有向边。缺失目标、重复 id 或未声明类型会被加载器拒绝。只有声明记录中 `supports` 包含 `relations` 的证据条目，才能为边提供证据。检查器打印证据 id，无证据边会在导出前被检查拒绝。

## 候选配对与孤立节点

当两条记录共享至少 1 个任务或至少 1 个阶段，且任何方向都没有声明关系时，这一无序配对成为候选。审计找到 10100 个候选配对。它不会把这些候选加入 39 条已声明边。`model-opendde`、`model-pocket2mol` 与 `model-targetdiff` 各出现在 158 个候选配对中，是观测到的最高计数。共享元数据使配对值得核查，却不预测两条记录应当相连。

检查器与已提交摘要按类型列出 192 条没有出边声明的记录。`model-rxnflow` 虽然被 `model-cgflow` 指向，也属于其中。这是协议按声明定义的孤立指标，不是图论中度数为 0 的判断。

## 材料的边界

图谱记录这个目录声明了什么，以及条目引用了什么。审计不会独立复核每个链接页面、裁定已声明关系是否真实，也不会推断因果关系。缺失声明不是实验确立的阴性。候选配对不是关系，资源记录之间的路径也不是生物机制。
