## 运行之前

**模式：对已提交文件做可运行的检查。** 该命令读取本仓库已分发的池预算回放与 ChEMBL 开发摘要。
不拟合任何东西、不获取任何化合物、不运行任何实验。

```bash
python labs/screening_transport/inspect_transport.py show
```

一个在两个测定里都输掉的策略，看上去比只在一个测定里输掉的策略被推翻得更彻底。
**这个推断需要两样头条数字从不携带的东西**，本实验把两样都核一遍。

## 1. 不带分母的富集率读不了

回收是按**目标数**计的。两个语境分别持有 **64** 个和 **13** 个目标。

回收到一个目标，在第一个语境里让分数移动 0.015625，在第二个里移动 0.076923；
也就是说更粗的那个语境，其测量步长是另一个的 **4.92 倍**。
同一个报出来的数字，在两处代表的证据量因此完全不同；
而且不把目标数印在旁边，两个都读不了。

下面的一切都用这个单位表达，因为它是唯一能让两个语境可比的单位。

## 2. 基线区间在两处都只有约一个目标宽

五个固定随机实例在一个语境里跨度 0.096154，在另一个里跨度 0.025391。
换算过来分别是 **1.25** 个和 **1.62** 个回收目标。

这么窄的区间描述的是一个小目标集的算术，不是某个总体的变异性。**它撑不起误差棒**——
这与[池预算契约检查](/zh-cn/labs/pool-budget-contract-inspection/)从协议措辞出发得到的结论一致，
只不过这里是从**测量分辨率**出发到达的。

## 3. 听起来最有决定性的结果，证据最薄

在 `CHEMBL3705421` 里，被设计的多样性策略**一个目标都没有回收到**，分数是 0.0。
这听起来是彻底的失败。

而它输给最差的那个随机实例，**只差 0.12 个目标**。

在另一个语境里，它没有拿零分，却输了 1.62 个目标——**是前者的十三倍多**。
**读起来像一场溃败的那个结果，恰恰几乎没有证据支撑**，
因为目标数少的语境会从很小的计数里产生看着很大的分数。
一个只看到那个零的读者，会对"哪个结果更强"得出完全相反的结论。

## 4. 它到底迁移了，还是只是重复了？

```bash
python labs/screening_transport/inspect_transport.py check
```

**让这次重复有价值的是**：两个测定共享 **0** 个母体化合物。
化学空间是不相交的，而不是同一批分子被测了两遍，并有一项检查要求这一点。

**拖住它的是**（取自记录自己的披露，不是推断）：两次回放都是**同一个靶点**上的回顾性回放，
在同一份冻结协议下、用同一套特征、而且惩罚强度是由更早的一个实验告知的。
**在共享协议下的一次重复，测的是策略在第二个化学空间里的表现，不是在第二个世界里的表现。**

共十一项检查，覆盖推导出的分辨率、以目标为单位的跨度、落后幅度、不相交的化学空间、
五个固定实例，以及让两次实际预算都低于名义五分之一的整数取整批大小。

## 5. 它处理不了什么

**脱靶。** 两次回放都是同一个靶点上的测定，因此这里没有任何东西谈得上选择性、
或在非预期位置上的活性。题目定义里点名了脱靶，而这份证据够不着。

**前瞻性跟进。** 两次回放都是对已完成测量的回顾性回放。

命令会把这两条限制打印出来，而不是留给读者去察觉——
这与[性质决策实验](/zh-cn/labs/property-decision-threshold/)明说自己无法填充弃权带
是同一种纪律。

## 独立练习

一位同事报告："我们在两个独立的测定上把我们的多样性选择器与随机做了对比。
两次都输了。我们准备把多样性选择从平台里去掉。"

请说明"独立"这个词在这句话里承担了什么，以及在同意一个平台级决定之前你还需要什么。

<details data-worked-answer>
<summary>参考答案 —— "独立"的两种含义，以及决定的适用范围</summary>

**"独立"同时承担了两个主张。** 在一种含义上，这两个测定确实独立，因为它们不共享化合物；
这在此处为真，也正是让一次重复具有信息量的原因。在另一种含义上，它们应当是关于该选择器的
**独立证据**，而它们不是：同一个靶点、同一份冻结协议、同一套特征、
以及一个在知晓更早实验的情况下选定的惩罚强度。**这句话借用了第一种含义的可信度，
去支撑第二种含义。**

**"两次都输了"藏起了输多少。** 换算成回收目标，一次是 1.62，另一次是 0.12。
后者是**八分之一个目标**，而在那个语境里整条基线跨度也才 1.25 个目标。
两次证据分量差别巨大的失败，被当成"两次"来计数了。

**测量本身可能分辨不出这个效应。** 只有 13 个目标时，最小可观测差异就是 0.077 分。
一个选择器可以在有意义的程度上更好或更差，而这个语境看不见。
**这是关于测定的陈述，不是关于选择器的陈述。**

**"平台"是错的适用范围。** 这份证据覆盖的是一个靶点家族、一份协议、两次回顾性回放。
一个平台级决定要适用于未来的每一个靶点、每一份协议以及前瞻性使用，而这三样都没有被代表。

**你还需要什么。** 一个预期该选择器会有帮助、且目标数足以分辨所声称效应的靶点；
一份不是从被测那一臂继承来的协议；以及一轮前瞻性实验，
因为这两次都是对已经存在的测量的回放。达不到这些，站得住的决定就只是
"在这个靶点上、在这份协议下"——那也正是已完成记录真正支撑的、
以及它自己的 interpretation 所写的。

</details>

## 它不做什么

这条路径不运行筛选、不获取化合物，也不确立任何策略更好。
它读的是两次已完成的回顾性回放，并报告它们能支撑什么、不能支撑什么。
它的权威性恰好等于那些产物的权威性，而它们各自带着自己的协议与复核日期。

回放本身是[池预算实验](/zh-cn/labs/pool-budget-campaign/)，
其协议由[池预算契约检查](/zh-cn/labs/pool-budget-contract-inspection/)读出。
相关论证见[获取、延迟与停止](/zh-cn/learn/active-learning/acquisition-delays-and-stopping/)
与[筛选普遍率与迁移](/zh-cn/learn/dti-screening/screening-prevalence-and-transfer/)。
