## 运行之前

**模式：对已提交文件做可运行的检查。** 两条命令读取一份冻结目标、二十个手工撰写的候选物，
以及已完成的 FreeSolv 实验中那张 642 个分子的划分表。**不运行任何生成模型。**
这里没有任何东西被提议去合成或测量，也没有任何候选物带着预测出来的性质数值。

与本仓库其他离线检查器不同，这个实验需要 RDKit，因为闸门是从结构算出来的，
而不是从记录里读出来的。

```bash
python labs/generation_gate/inspect_gate.py objective
```

## 1. 一个目标只有在能被施加时才算冻结

第一条命令打印五个已声明的部分：靶点语境、期望性质、禁止基团、合成限制、实验决策。
请看每一部分都必须带着什么。

一条期望性质带着**双侧界限**和计算它的函数。一条禁止基团带着 **SMARTS 模式**，而不是一个名字。
合成限制带着计数与元素清单。决策带着问题、测定、批大小、选择规则，以及一条**弃权规则**。

这些字段正是"目标"与"愿望清单"的分界。没有界限的性质拦不住任何东西；
只写在散文里的基团无法被施加；而没有挂上决策的目标说不出一个通过的候选物是**用来干什么的**——
这是三者中最常见的一种，因为一张性质清单感觉上像目标，却什么也没承诺。

检查用能做到的最强方式落实这一点：**当目标通不过这些检查时，筛选根本不会对它运行。**
一个无法被施加的目标，没有可施加的对象。

## 2. 六道闸门，六个分母

```bash
python labs/generation_gate/inspect_gate.py screen
```

闸门按顺序运行——有效性、唯一性、新颖性、期望性质、禁止基团、合成限制——
而且**每道闸门的分母是上一道闸门的幸存者**。漏斗会逐步打印进入数、拦下数与幸存数，
因此任何通过率都无法被平铺着引用。

在这份候选集上，头条数字是 20 个里 18 个有效。而穿过全部已声明闸门的候选物是 20 个里 6 个。
两个都是真的。但只有一个回答了"有多少候选物能往下走"，而那一个通常不是被报出来的那个。

## 3. 新颖性不是一件事

有四个候选物被新颖性闸门拦下。其中两个在参照集的训练划分里，另外两个在留出划分里。

这个区分就是人们所说的"记忆"的全部内容，而它**不是第七道闸门**。
它是同一项检查施加在一个更窄的参照集上。一个复现了自己训练分子的模型，
与一个复现了留出分子的模型，做的是不同的事；
而单独一个新颖性百分比若不在旁边写明参照集，两者都报不出来。

命令会把两个计数都打印出来，并且有一项检查要求这些失败来自不止一个划分，
这样两者永远不会悄悄合并。

## 4. 合成闸门没有确立什么

合成限制是环数、立体中心数和一份禁止元素清单。它们是**在生成之前选定的廉价结构代理**，
而目标里记着 `route_feasibility: not_assessed`。

这正是一条报着"可合成性：87%"的流水线悄悄合上的缺口。
本实验中没有任何一项检查能确立任何候选物可以被做出来，
并且有一项检查确认目标一直这样写着。

```bash
python labs/generation_gate/inspect_gate.py check
```

共十七项检查，覆盖目标的可施加性、参照集规模与其声明所依据的文件是否一致、
每个候选物是否确实被其标签所指的那道闸门拦下、漏斗分母是否逐级相扣，
以及冻结的选择规则是否只从幸存者中填充批次。

## 独立练习

一份报告写道："我们的模型生成了 10,000 个分子。94% 有效，91% 新颖，
87% 通过了我们的可合成性过滤器。我们选出前 50 个去合成。"

请说出从这三个百分比中你**算不出**什么，并说出哪一行额外信息能让你算出最多。

<details data-worked-answer>
<summary>参考答案 —— 缺失的分母，以及该要的那一行</summary>

**你算不出到底有多少分子穿过了全部三道。** 如果三个百分比各自都是对着最初的 10,000 报的，
那么幸存者可能在大约 7,200 到 8,700 之间，取决于失败如何重叠。
如果它们是逐级相扣的，答案就是一个接近 7,400 的确定数字。**报告没有说是哪一种**，
而这是两个不同的主张。逐级相扣通常是本意，平铺则通常是写法。

**你根本读不了那个新颖性数字。** 相对什么新颖？相对训练集、相对参照数据库，
还是相对另外 9,999 个生成分子？每一个都给出不同的数；
而"记忆"这个问题——有多少是被复现出来的训练分子——
无法从一个不写明参照集的新颖率里得到回答。

**你判断不了"可合成"是否有含义。** 结构代理与逆合成路线是两个不同的主张，
而这个词把两者都罩住了。如果它是代理，87% 就是一句关于环数与官能团的陈述，
不是关于任何东西能不能被做出来的陈述。

**你也看不出唯一性做了什么。** 生成的 10,000 个分子不等于 10,000 个不同的分子。
如果去重发生在算百分比之前，分母就不是 10,000；如果不是，
那么有效性这个数字把同一个分子数了很多遍。

**而且"前 50 个"没有说出任何规则。** 按什么排前，何时定的？
一条在看过候选物之后才选定的选择规则，正是整个实验所针对的那种失败。

**该要的那一行。** 不是把百分比重说一遍——要**漏斗：
按施加的先后顺序，每一步进入的数量与幸存的数量。**
它解决了平铺与相扣的歧义，暴露出唯一性的分母，
并让后续每个百分比都可以被重算。如果回答是"这些步骤并没有按固定顺序施加"，
那本身就是答案。

</details>

## 它不做什么

这条路径不运行生成模型、不评估任何模型，也不确立任何候选物是真实的、可制造的或可测量的。
它把一个冻结目标施加到一组构造出来的候选物上，并报告每道闸门移除了什么。
这些候选物是为了触发各道闸门而撰写的，因此这些计数教的是漏斗的结构，
而不是任何生成器的行为。
