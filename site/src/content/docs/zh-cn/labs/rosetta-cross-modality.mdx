## 本实验问的问题

一次基因扰动会留下一个细胞状态，而两种仪器可以在同一时刻各自记录这个状态。L1000 读出
记录 978 个标志转录本探针组，Cell Painting 读出记录 291 个形态学特征。两者施加于同一批
携带同样工程化基因扰动的 A549 肺腺癌细胞，并在扰动后 96 小时读取。把两份读出连接起来，
一个问题就变得可测量。它们对同一次扰动有多一致，以及当测量的板与批次结构被计入时，
这份一致性还能剩下多少？

本实验只回答这个问题就停下。它不提名靶点，不预测表型，也不提供任何可用的模型。它所确定
的东西更窄，却仍然有用。它把两种读出之间的一致性中属于扰动的部分，与属于测量实验本身的
部分分开。

第二部分容易漏掉，因为看不见设计的分析无法看见它。一个用转录组谱预测某次扰动成像谱的
映射，可能因为一个与生物学毫无关系的理由而是对的，即训练侧已经包含了与留出扰动相同的板和
相同的板图。本实验去测量这种可能性，而不是把它假设掉。

## 运行之前

**模式是在两个已发布对象上，对一次冻结的一次性评估做独立复现。** 协议版本是
`cpg0003-rosetta-luad-cross-modality-v1`，已提交的小结在 2026-10-21 由两个缓存对象计算
一次得到。`check` 命令重算整个冻结评估集，若已提交的小结与缓存数据产生的结果不再一致，
就以非零码退出，因此小结与数据之间的漂移是一次失败，而不是一次静默刷新。

```bash
uv run python labs/rosetta_cross_modality/run_lab.py download
uv run python labs/rosetta_cross_modality/inspect_rosetta_cross_modality.py show
uv run python labs/rosetta_cross_modality/inspect_rosetta_cross_modality.py check
uv run python labs/rosetta_cross_modality/export_summary.py
```

需要 Python 3.11.15 与 NumPy 2.4.6，即已提交小结所记录的版本。只有一次性下载两个已发布
对象需要联网，缓存位于被 git 忽略的 `.cache/rosetta_cross_modality/`。每次下载都会按冻结
协议重新核对字节长度，因此在更旧契约下写入的缓存会被重新检查而不是被默默信任，被中断的
下载会从磁盘上已有的字节继续。

导出步骤先写出完整的运行产物，其中携带每一次扰动的个体一致性数值，然后再就地重写那份
精简的已提交小结。若契约或数据被拒绝，它什么都不写。

## 数据与来源

两个对象都来自 Broad Cell Painting Gallery 的同一个研究 `cpg0003-rosetta`，以及它的一个
批次 `LUAD-BBBC041-Caicedo`。转录组对象是 `L1000/replicate_level_l1k.csv.gz`，11,448,797
字节。成像对象是 `CellPainting/replicate_level_cp_normalized_variable_selected.csv.gz`，
15,858,778 字节。合计 27,307,675 字节。每个字节长度都于 2026-10-21 从该桶自身的对象列表
读出，并在每次下载和每次载入时重新核对。

| 读出 | 孔数 | 处理孔 | 对照孔 | 扰动数 | 板数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 转录组 | 4,232 | 4,224 | 8 | 528 | 16 |
| 成像 | 6,144 | 5,824 | 320 | 593 | 16 |

成像的板来自两张板图，它们就是这个批次所在研究中的两个批次。转录组读出没有批次列，
因此它的分组单位是检测板。按扰动标识符连接两份读出后，有 528 个扰动同时带有两种谱。
65 个成像扰动没有转录组对应项，被排除。被准入的扰动中有 509 个只属于一个批次，19 个跨
两个批次。对照孔会被读取、计数并报告，但它们永远不是实体。

画廊还为同一批次发布了全特征成像发行版。本协议不使用它，因为变量筛选版中的每一个成像
特征在每一个孔里都是有限值，所以这组特征不需要自己再有一条筛选规则，而更小的对象也让
本实验留在以 CPU 为主的开销内。本实验不声称它的数值可以迁移到全特征集。

## 读出与终点

一个实体是一次在两种读出中都至少有一个处理孔的基因扰动。它的谱在每种读出中各占一行，
是该扰动在该读出中各重复孔的中位数。因此每个扰动在每种读出中恰好出现一次，同一次扰动的
任何重复都不可能被拆到训练侧和测试侧两侧。

转录组特征是 978 个 Affymetrix 标志探针组，按标志探针的命名规则找出。成像特征是 291 个
Cell Painting 特征，按 `Cells_`、`Nuclei_` 和 `Cytoplasm_` 前缀找出。特征按名字找出，绝不
按位置，所以一个增列或缺列的发行版要么被正确读取，要么被拒绝。

终点是跨模态一致性，测量一个扰动的转录组谱在多大程度上预测它的成像谱。主要指标是对留出
扰动取平均的预测成像谱与实测成像谱之间的 Pearson 相关。次要指标是对折内留出扰动取平均
的、逐成像特征计算的预测值与实测值之间的相关。模型是一个多输出 ridge 映射，其惩罚项由固定
网格上的内层五折交叉验证在每折的训练行上选出。标准化与惩罚项都只在训练行上拟合，因此
没有任何留出行影响自己的映射。

推断单位是一次扰动。分组单位是成像检测板、成像批次和 L1000 检测板。由于每个扰动在每种
读出中都测量于 16 块板中的 8 块上，一块板不可能在单次扰动的层面上被留出，因此分块评估
留出该板上测量的每一个扰动，并在从未在该板上测量的每一个扰动上训练。种子 20261021 固定
了每一个划分和每一次置换。

两个对照处在所有比较之下，而且都很便宜。第一个把每个扰动的成像谱换成同一批次中另一个
扰动的成像谱，这保留了板与批次结构，只破坏配对。第二个抽取与分块评估具有完全相同训练集
和测试集大小、来自同一总体的随机划分，于是性能下降可以被读作设计效应，而不是更小的
训练集。

## 数值

下表以小结读取器打印的四位小数复现已提交的小结。

| 评估 | 扰动级 r | 特征级 r | 折数 | 受测扰动数 |
| --- | ---: | ---: | ---: | ---: |
| 表观（随机五折） | 0.8158 | 0.8256 | 5 | 528 |
| 零假设，批内配对被破坏 | 0.1317 | 0.0033 | 5 | 528 |
| 分批留出（留出整个批次） | 0.6886 | 0.6326 | 2 | 509 |
| 同规模随机，相同大小 | 0.7923 | 0.7877 | 2 | 509 |
| 成像板留出 | 0.6921 | 0.6516 | 16 | 528 |
| 同规模随机，相同大小 | 0.7931 | 0.8014 | 16 | 528 |
| 转录组板留出 | 0.7041 | 0.6694 | 16 | 528 |
| 同规模随机，相同大小 | 0.7972 | 0.8089 | 16 | 528 |

先看表观一致性。在随机划分下，留出扰动的成像谱由它的转录组谱预测出来，扰动级相关为
0.8158，成像特征级相关为 0.8256。这个数字不是设计造出来的。把每个扰动的成像谱换成同一
批次中另一个扰动的成像谱，特征级一致性降到 0.0033，扰动级一致性降到 0.1317。一项不拟合
免模型检验与拟合结果一致，它不拟合任何东西，也不抽取任何划分。转录组相似度排序与成像
相似度排序之间的 Spearman 相关中位数为 0.7449，而在置换配对下同一统计量为 0.0007。

再看设计。板与批次对被测方差的作用很小。成像板占成像特征方差的 2.71%，L1000 板占转录组
特征方差的 1.56%，成像批次占 0.36%。方差占比小不等于对预测影响小，所以在结构被留出的
条件下，一致性被重新测量。留出整个批次使特征级一致性从 0.8256 降到 0.6326，而训练集和测试集大小完全相同、来自
同一总体的随机划分达到 0.7877。因此批次分离的代价为 0.1551 的特征级一致性，而这一部分
无法用更小的训练集解释。留出一块成像检测板的代价为 0.1497，留出一块转录组检测板为
0.1394，用同样的比较得到。存活比是在结构被留出后仍然存活下来的、零假设之上的那部分
一致性的份额，算法是分块后的特征级相关减去零假设，再除以表观的特征级相关减去零假设。
留出一个批次时它是 0.7653，留出一块成像板时是 0.7885，留出一块转录组板时是 0.8101。

这就是教学要点，而且它比特征就是机制要窄。同一次扰动的两种读出之间，四分之三的
一致性在一个模型从未见过该扰动所属批次的评估中存活下来。另外四分之一没有存活，而不看
设计的分析会把全部一致性都报告出来。

表观一致性分布两端具名的例子：

| 扰动 | 扰动级 r |
| --- | ---: |
| `LAP3_WT.o` | 0.9861 |
| `NFE2L2_WT.c` | 0.9846 |
| `NFE2L2_p.T80K` | 0.9838 |
| `MDM2_p.E421Q` | -0.1525 |
| `RBM15B_WT.o` | -0.0802 |
| `NUP88_WT.o` | -0.0117 |

负相关意味着该扰动的转录组谱在成像谱的方向上指错了方向。这六行是想知道一个数字说的是
哪个实体时的起点，而它们不是关于这些基因的证据。

## 这没有展示什么

- 它没有展示扰动特征就是机制。它测量的是两种读出之间的一致性，以及这份一致性在测量设计
  下的存活情况。
- 它没有展示成像读出能对模型在任何真实部署中都从未见过的扰动被预测，因为这里的留出是
  一次已发布实验内部的留出。
- 它没有把批次的干扰效应与批次同质的训练集覆盖了更小的扰动空间这一事实分开。同规模
  对照只隔离出在固定训练集大小下结构分离的代价，仅此而已。
- 它对任何基因、任何病人或任何临床结局都未作任何陈述。位于一致性分布两端的具名扰动
  就是一个分布的两端。
- 本协议固定一个研究的一个批次、一个细胞系、一个时间点与一套工程化编辑。该研究的另外
  四个批次、画廊中的其他研究和 JUMP 试点都在本协议之外，这里的任何东西不经重新测量都
  不能迁移到它们。
- 成像特征集是画廊的变量筛选发行版，共 291 个特征。同一批次的全特征发行版没有被使用，
  本实验也不声称它的数值可以迁移到该发行版。
- 模型是一个 ridge 映射，而不是最先进的跨模态预测器。它的惩罚项在每折训练内部选出，但
  架构并未调优，所以这些数值界定的是这个简单映射的一致性，而不是可达成的一致性。
- 转录组读出只在它 16 块板中的 6 块上带有板匹配的阴性对照，因此不能在悄悄覆盖部分设计
  的前提下为它计算基于对照的基线。协议因此不自行添加任何基线扣除，而按发布的样子使用
  画廊自己的归一化。
- 本实验尚未收集任何读者结果。已提交的小结记录的是流水线计算了什么，而不是是否有人从
  它学到了东西。

## 独立练习

一份幻灯片写道，转录组在特征相关 0.8256 上预测了留出扰动的 Cell Painting 谱，因此扰动
特征就是机制。

1. 说出本实验运行了、而一个不看设计的分析不会运行的两个对照，并说明如果产生一致性的
   是板与批次结构而不是扰动本身，每个对照会显示什么。
2. 留出整个批次使特征级一致性降到 0.6326，而训练集和测试集大小完全相同的随机划分达到
   0.7877。计算这个差值，给它命名，并说明你会把两个数中的哪一个报告为跨模态映射的一致性。
3. 分布中最一致的扰动是 `LAP3_WT.o`，数值为 0.9861，最不一致的是 `MDM2_p.E421Q`，数值为
   -0.1525。这两行对该扰动建立了什么，又没有建立什么？

<details data-worked-answer>
<summary>参考答案</summary>

两个对照是保留板与批次结构、只破坏配对的零假设，以及同规模随机划分。如果产生一致性的
是设计，置换后的零假设就会停在接近表观的 0.8256 处，而不是 0.0033，而一个分块折也会达到
它同规模随机孪生折的数值。免模型的邻域一致性 0.7449 是第三项独立的一致性证据，因为它
不拟合任何东西，也不抽取任何划分，因此无法继承某个划分特有的捷径。它的置换对应值降到
0.0007。

这个差值是 0.7877 - 0.6326 = 0.1551，协议把它称为在固定训练集大小下结构分离的设计代价。
应当报告的是分块后的 0.6326，因为 0.7877 那个同规模随机划分是设计在相同训练数据量下本来
就会产生的数值。

那两行具名结果是一个一致性分布的两端，仅此而已。它们说的是在一个拟合出的映射之下，
这两次扰动的转录组谱与成像谱指向同一方向，而第二次扰动则指向相反方向。它们不是关于
LAP3 或关于 MDM2 的证据，那个负值说明映射在该扰动上指错了方向，而不是说该扰动什么也
没做。

</details>
