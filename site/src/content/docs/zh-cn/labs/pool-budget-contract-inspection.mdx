## 1. 预算是推导出来的，不是挑出来的

名义预算是池的百分之二十，但报出来的比例并不是百分之二十。批大小取池数量除以二十的下取整，
共跑四轮，获取数量等于四个批次。

主要测定中，631 个母体的池给出批大小 31、获取数量 124、实际预算比例 0.196513470681458。
复现测定中，130 的池给出批大小 6、获取数量 24、比例 0.18461538461538463。
**造成两者都不等于名义目标的是整数取整，不是某个设计选择**，而契约把这一点写了出来，
没有直接报那个整数。

检查器会把这些全部重算，包括三个划分之和等于从冻结 ChEMBL 契约继承来的 902 与 170 个母体。
一个预算研究若其划分规模偏离了它声称在复现的那份数据，比较的就是另一个问题上的策略。

## 2. 策略看得到什么，以及种子不是什么

多样性策略是**标签盲**的。契约写明它的选择器不得接收 initial、pool 或 evaluation 标签，
这才使它的选择成为化学性质的函数，而不是答案的函数。

五个随机种子是最常被误读的部分。协议称它们为**固定策略实例，不是独立的测定或样本**。
这句措辞在做实事。在复现测定中，它们的回收 AUC 从 0.009615384615384616 到
0.10576923076923077，同一个"基线"内部相差十一倍。于是很容易想把它们平均一下，
再把跨度当作误差棒报出来。

那样做会主张一件该设计支撑不了的事情，下面的练习要求你说清楚究竟是哪一件。

## 3. 先拟合，再锁定，后评分

预测契约固定的是**次序**而不是公式。每个检查点上，模型只在 initial 母体加上截至该检查点已获取
的母体上拟合，绝不在 evaluation 母体上拟合。所有获取顺序被定稿、所有评估预测向量被锁定，
**都发生在评分器接触任何 evaluation 标签之前**。之后才评分。契约以这样一条规则收尾：
评估结果不得改变任何策略、种子、划分、特征、alpha、批次或任何未来的预测向量。

这个次序在输出里**看得见**，不必只凭信任。每个策略在检查点零报告的误差完全相同，因为那时没有
任何策略获取过东西，它们都在同一个 initial 集上拟合。检查器会确认这一点。
如果这些数字有朝一日不同了，说明有东西向后泄漏进了第零轮。

## 4. 与方法预期相反的那个结果

在两个测定中，多样性策略都低于全部五个随机实例。在复现测定中它在整个预算内**一个目标都没有
回收到**，AUC 为 0.0，而随机实例最高达到 0.10576923076923077。

命令把这个比较作为一句话直接打印出来，而不是留给读者从表里推断，摘要也保留了它。
130 个母体的池、目标数量 13，这是个小问题，诚实的读法是：**这次实验没有显示多样性选择在这里
有效**。它不是"多样性选择从不有效"的证据。

```bash
python labs/pool_budget/inspect_contract.py check
```

## 独立练习

一位同事提议，把复现测定的"随机基线"报成五个种子 AUC 的均值，并把它们从
0.009615384615384616 到 0.10576923076923077 的跨度画成误差棒。请说明这种呈现会主张什么、
协议自身的措辞为何排除了它，以及在考虑任何统计之前，目标数量 13 已经告诉了你关于这个跨度的
什么信息。

<details data-worked-answer>
<summary>参考答案 —— 主张、措辞与分辨率</summary>

**它会主张什么。** 误差棒会诱使读者把这个区间当成关于某个总体的抽样不确定性，进而去问多样性
策略是否落在区间之外。那是一个显著性读法。它等于说：如果重做这个实验，随机基线会落在这个
范围里。

**措辞为何排除了它。** 协议称这些种子为固定策略实例，不是独立的测定或样本。重做实验并不重抽
任何东西：测定、划分、池与目标全部冻结且共享。换一个种子，改变的只是策略在同一个固定池上走哪
一个排列。这个跨度度量的是"那一个选择在这一份数据上影响多大"，**是关于策略的事实，不是关于
总体的不确定性**。

**目标数量告诉你什么。** 回收率是已获取目标数除以目标数量，此处为 13。多回收一个目标，
回收率就变化十三分之一，约 0.077。五个种子观测到的全部跨度大致就是这样一步。
在任何统计论证之前，**测量的分辨率本身就已经解释了这个范围的大部分**——这是看清"由它构造出的
区间描述的是算术而不是证据"的另一种方式。

完整的回答会注意到：像摘要那样逐个报出五个实例，传达的信息完全相同却不附带那个主张；
而面对如此粗的分辨率，正确的应对是扩大目标集，而不是换一个公式。

</details>
