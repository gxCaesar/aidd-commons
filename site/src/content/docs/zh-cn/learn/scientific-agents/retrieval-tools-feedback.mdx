## 学习目标

完成本课后，你应能区分检索语境与参数训练、类型化工具结果与文本承诺、固定管线与自适应计划，
以及工具调用与已完成湿实验。你还应能说明验证器能确立什么、不能确立什么。

## 预备知识与任务边界

先阅读[科学智能体与工具](/zh-cn/learn/scientific-agents/agents-and-tools/)。将工作流状态表示为 `S_t`，
检索证据表示为 `E_t`，行动计划表示为 `a_t`，工具观察表示为 `o_t`。检索步骤将选定证据附加到
当前语境中；它本身不更新模型参数。参数训练则在另一份数据与优化契约下改变参数状态，例如从
`theta` 到 `theta_prime`。

[ReAct 论文](https://arxiv.org/abs/2210.03629) 提出交织的推理轨迹和任务特异行动。其机制引出了
一个有用的状态区分：计划可以使用观察来修订下一步行动，但轨迹仍需有权限边界，并且清楚记录
实际观察到了什么。

## 类型化工具携带不同类型的证据

“我检查了测定”这样的文本陈述不是执行记录。一个类型化接口可以使请求和返回值可检查，例如：

```text
request:  { assay_id: "A17", readout: "marker_M", specimen_id: "S4" }
response: { status: "qc_failed", data_ref: "run-19", control_pass: false }
```

模式不会使响应变成真实的，但会使其含义可测试：哪项测定、哪个样本、哪个读出，以及对照是否通过。
验证器可以检查 JSON 对象是否符合该模式、解析器是否使用已声明文件，或是否存在所需的对照字段。
仅凭这些检查，它无法确立某项生物学主张为真、仪器已校准，或湿实验确实按描述发生。

## 固定管线与自适应计划

固定管线具有预先声明的行动顺序，例如检索、总结、调用读取器和写报告。一个合格的固定管线也可以
包含冻结的安全分支，例如 `if control_pass is false: halt and route to review`。自适应计划使下一步
允许的行动取决于返回状态：`S_(t+1) = update(S_t, o_t)`。自适应不自动代表更好。更新规则必须说明
哪些观察可以改变计划、谁能授权可写行动，以及质量控制失败何时使预期结论失效。

## 推导失败轨迹：工具调用不是结果

这是一个**构造的教学轨迹**，不是已执行的工作流或实验室记录。

| 步骤 | 已记录状态 | 正确的下一步解读 |
| --- | --- | --- |
| 证据 | `E0` 是一条已记录来源和范围的检索来源。 | 它能促成假设，而不是一项新测量。 |
| 计划 | 请求带有阳性对照和阴性对照的 `marker_M` 测定。 | 该计划是提议，而不是实验。 |
| 工具 / 读出 | 上述类型化响应具有 `status: qc_failed` 和 `control_pass: false`。 | 工具返回 QC 失败；没有有效生物学读出。 |
| 修订 | 记录失败、保留未解决假设，并暂停等待有权限的人类审查或有效替代来源。 | 合格的固定脚本和自适应计划都会在这里停止；不要把假设更新为仿佛已测得 `marker_M`。 |

因此，更新的是工作流状态，而不是生物学效应。工具调用可以安排、模拟、解析或拒绝行动。只有在
经授权的实验记录及其对照支持这种解读时，它才成为湿实验的证据。

## 半自主实验室环的范围

原始 [Robin 文章](https://www.nature.com/articles/s41586-026-10652-y) 描述了一个生成假设并分析实验数据的
半自主工作流。在其报告的环中，人类审查候选排序、执行人类生成的实验方案，并提供所得数据以供分析。
因此，它不能成为仅凭智能体轨迹或软件工具调用便宣称自主湿实验执行的依据。

## 独立练习

使用相同的 `E0`、来源、工具、权限边界、预算和 `qc_failed` 响应，比较一个具有冻结分支
`if control_pass is false: halt and route to review` 的合格固定脚本，与到达同一分支的自适应计划。
哪些事实是共享的，哪个输出缺乏支持，这个案例是否证明自适应有价值？随后说明什么真正未预期的
未来证据需要一项测量比较，而不是架构主张。

两种设计共享检索证据、提议测定、类型化调用、失败对照、工具、权限边界和预算。阳性结论在任一
设计中都缺乏支持，因为没有有效读出。两者都应记录确切失败状态、中止的推断，以及新行动之前所需的
有权限审查者或替代证据。这个案例没有显示自适应的测量价值：合格的固定分支同样能处理它。未来比较
需要经授权的留出工作流轨迹，其中包含落在固定脚本已声明分支之外、有效且来源可追溯的观察；来源、
工具、权限、预算、结局和人类审查标准必须在检查前冻结。这里未运行该比较。两份记录均不能说湿实验
已成功完成。

## 失效边界与来源路径

检索可能不完整或范围错误；类型化 I/O 可以格式正确却仍然错误；自适应行为可以传播坏观察；验证器
也可能漏掉其从未被设计来测试的科学前提。保留来源、查询、工具模式、返回状态、行动权限，以及
观察与推断结论之间的区别。
