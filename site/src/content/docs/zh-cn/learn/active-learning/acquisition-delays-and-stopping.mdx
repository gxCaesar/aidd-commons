## 选择的是实验，不只是预测值

先读[实验池与预算](/zh-cn/learn/active-learning/experiment-pools-and-budgets/)、
[多样性、不确定性与反馈](/zh-cn/learn/active-learning/diversity-uncertainty-feedback/)
和[不确定性与决策](/zh-cn/learn/qsar-properties/uncertainty-to-decisions/)。
本章推导简单采集分数，并沿时间线处理延迟反馈。数值均为构造，此处不运行新实验轮次。

纯利用选择预测结局最好的候选。实验选择策略也可为改善后续选择的信息付出成本。
目标可能是发现的最佳可行值、确认命中数、预算内累计效用，或机制信息。这些目标不同，采集函数应对应明确目标。

不确定性采样偏好不确定预测，也可能把全部预算花在不可约噪声或不可测对象上。
多样性采样覆盖不同区域，却可能忽略目标终点。
有用的比较应包含合格固定策略，并匹配初始观测、合格候选池、测量成本和停止规则。
[已有预算实验池练习](/zh-cn/labs/pool-budget-campaign/)提供有限范围参照；其中的回顾性已测池不等于前瞻湿实验。

## 手算期望改进

假设是**最大化**问题，预测分布
`Y(x) ~ Normal(μ(x), σ²(x))`，已知当前最佳值为 `b`。
改进量 `I(x)=max(Y(x)−b,0)`。`σ>0` 时定义 `z=(μ−b)/σ`：

```text
EI(x) = (μ−b) Φ(z) + σ φ(z)
```

`Φ` 和 `φ` 分别是标准正态累积分布函数与密度函数。
预测标准差为零时，EI 为 `max(μ−b,0)`。
[BoTorch acquisition 文档](https://botorch.readthedocs.io/en/stable/acquisition.html)
介绍解析及 Monte Carlo 采集函数与相应假设。
噪声观测和批量选择需要额外处理，不能把最大带噪观测假装成已知潜在最优值。

构造 `b=5`，候选 A 的 `μ=5`、`σ=1`。
此时 `z=0`，第一项为零，`EI(A)=φ(0)=1/√(2π)≈0.3989`。
B 均值相同、`σ=2`，EI 约 0.7979。
C 确定为 5.3，EI 为 0.3。按这一分数，B 高于 A，高于 C。
这不证明 B 的即时成功概率最高，也不证明实验可行；有利分数依赖预测不确定性有意义。

最小化终点应反转改进方向，不能在当前最佳值不变时直接套最大化公式。
上置信界是另一种分数，最大化时常写为 `μ+κσ`，其中 `κ` 无量纲。
若实现写 `sqrt(β)σ`，其探索系数是 `κ=sqrt(β)`，不是 `β`。
混淆方差与标准差也会改变单位和策略。探索设置属于声明的配方。

## 成本、约束与批次属于目标的一部分

简单的即时增益/成本启发式中，A 成本为 1，则 `EI/cost≈0.3989`；B 成本为 4，则约为 0.1995。
此排序偏好 A，与原始 EI 相反。但它是启发式，不是有限时域资源分配的通用解。
极便宜但冗余的候选可能耗尽批次，却不增加信息。
同样，逐候选 EI 之和未必等于相关候选组成批次的期望改进。

可行性可以是硬纳入约束，也可以是明确建模的不确定事件。
模型接受特征向量，不意味着无法合成或无法在现有系统测量的候选已经构成实验。
把改进乘以可行概率，需要关于两者关系的假设；同一分子性质同时驱动二者时，不能默认为独立。
合成失败、测量失败和有效的低活性结果应分开记录。

## 延迟反馈改变策略知道什么

构造如下时间线：

| 时间 | 事件                      | 下一次拟合可用的标签          |
| ---- | ------------------------- | ----------------------------- |
| t0   | 初始观测完成；选择 A 和 B | 仅初始集                      |
| t1   | A 返回有效结果；B 待完成  | 初始集加 A                    |
| t2   | 选择 C；B 仍待完成        | 初始集加 A                    |
| t3   | B 返回有效结果            | 初始集加 A 和 B               |
| t4   | C 未达到测量质量要求      | 有效标签不变；单独记录 C 失败 |

在 t2，B 不是零、阴性或已观测标签。批次感知策略可使用其待完成状态，但不能使用最终值。
回放时在 t2 使用 B 的 t3 标签，就是给策略未来信息。
应分别记录选择时间、结果可用时间与状态。
候选可在标签到达前消耗成本，所以墙钟时间进度与完成标签数量是不同预算轴。

t4 是否重试，应按事先声明的工程与测定规则决定，不能把测量失败转成低生物活性。
若成功或延迟依赖化学性质，已完成标签子集就是被选择的总体。
仅在成功完成结果上评价策略，可能让它避开自己的困难结果后显得更好。
成本核算要纳入尝试和失败。

## 对整个策略停止和评价

比较前声明固定尝试预算、成本上限、时间范围或外部规定的成功标准。
基于近期改进的停止规则，本身就是策略组成。只对表现不佳的基线使用它，会造成不对称比较。
学习曲线看起来平坦，本身不能证明没有有用候选剩余。

回顾性回放仅在规定时间揭示合格标签。
使用共同起始池，并在适当时配对实验轮次；按固定预算差异或预先声明的轮次曲线下面积汇总。
同一固定已测池上的多个随机种子，描述该池上算法的变异，不会产生独立前瞻实验，也不建立其他测定的迁移。

最终评价应与采集调参分离。看完最终回放曲线后选择探索强度、停止 patience 或成本权重，属于开发。
确认性策略比较需要未使用的实验集或明确独立的前瞻评价。
固定策略实际获胜时应保留结果，不确定性选择是一项假设，不是保证的升级。

## 独立练习

1. `μ=b`、`σ=0.5` 时 EI 是多少？`σ=0` 且 `μ=b−1` 时呢？
2. `μ=5`、`σ=2`、`κ=1.5` 时计算上置信界。哪个 `β` 会产生相同的 `sqrt(β)σ` 系数？
3. t2 时回放表已含 B 的最终值，模型可使用吗？C 在 t4 的失败如何进入标签表和成本表？
4. P 尝试 10 次、得到 8 个有效标签；Q 尝试 8 次、得到 8 个有效标签，单次成本相同。预算是否匹配？

<details data-worked-answer>
<summary>答案：使用当时实际可用的信息与预算</summary>

EI 为 `0.5/√(2π)≈0.1995`；方差为零且均值低于当前最佳值时为零。
UCB 为 `5+1.5×2=8`，对应 `β=2.25`。
尽管回顾文件存在 B 的最终值，t2 仍不可用。
C 贡献失败尝试状态和实际成本，不贡献虚构活性标签。
P 与 Q 有效标签数相同，但尝试预算为 10 对 8，应匹配声明的预算轴，或明确分析成本与完成情况的差异。

</details>
