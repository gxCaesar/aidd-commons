## 为明确化学对象预测明确性质

先读[小分子表示](/zh-cn/learn/representations/small-molecule-representations/)
和[回归与分类误差](/zh-cn/learn/qsar-properties/regression-classification-errors/)。
本章把分子身份与 QSAR 的预期用途连接起来。学完应能为科学问题选择划分、手算相似性诊断，并区分预测性 SAR 与因果解释。
示例均为构造，不引入新的实测结果。

化学规范化不是外观清洗。去除反离子、选择互变异构体、指定电荷态或保留立体化学，会改变模型认为什么对象相同。
应根据终点定义规则。中性母体表示可能适合某项比较，却不能保留所有 pH 依赖状态或盐形式特异测量。
[RDKit Cookbook](https://www.rdkit.org/docs/Cookbook.html)提供具体分子对象操作，但存在某个操作，不意味着它保留测定含义。

分别保留提交结构、规范化结构、分组身份和变换原因。在正确层级去重，再划分数据。
声称泛化到新母体化合物时，规范化后变成同一母体的记录不应跨越训练与测试边界。
反过来，也不能因为不感知手性的指纹把两个立体异构体映射到相同特征，就平均它们不同的测量标签。

未明确实际测量组分的混合物，不能靠选择最大片段解决身份。
应说明是否纳入混合物、如何表示组分比例，或为何排除。
重复终点发生冲突时，保留语境及预先规定的汇总或排除规则；选择最方便的值会改变标签。
若来源不足以支持单值，应保留未解决冲突。

## 选择能承载相关变化的表示

描述符提供尺寸、极性等指定摘要；指纹编码子结构或环境；分子图保留连接及选定的原子、键特征；3D 表示增加指定构象，并非完整平衡系综。
每类都有失败方式：描述符可合并不同结构，哈希指纹可碰撞，图可遗漏立体化学或电荷，单构象可误表征依赖环境的性质。
已有[表示检查 notebook](/zh-cn/labs/molecule-representation-inspector/)提供可编辑的无标签练习。

比较候选表示时，保持终点、纳入总体、划分和选择预算相同，仅使用训练与验证数据选择。
大模型若额外使用标签，就不再是仅改变表示的消融。预训练编码器也带来额外数据暴露和拟合历史，应披露差异。
先设置训练均值或适当身份基线，再设置合格的描述符或指纹模型。
[已有 ChEMBL 对比](/zh-cn/labs/chembl-egfr-representation-baselines/)是实测教学参照，不证明某表示对所有测定都获胜。
保留实际结论，不要按模型复杂度推定应有排名。

## 三种划分回答不同问题

构造三个系列，每个系列有两个化合物，分别在两个时期测量：

| 化合物 | 系列 | 测量时间 |
| ------ | ---- | -------- |
| A1     | A    | 早期     |
| A2     | A    | 晚期     |
| B1     | B    | 早期     |
| B2     | B    | 晚期     |
| C1     | C    | 早期     |
| C2     | C    | 晚期     |

按行随机划分可能让近似类似物出现在两侧。它可以对应系列内插值，却不能建立新系列迁移。
留出 C1 和 C2 的分组划分检验指定未见系列。
用 A1/B1/C1 训练、A2/B2/C2 测试的时间划分检验后续测量，但系列仍重叠。
骨架分组是相关化学的一种操作定义，其算法不等于所有药物化学家的系列划分。
[scikit-learn 交叉验证指南](https://scikit-learn.org/stable/modules/cross_validation.html)描述分组和时间分离工具，不替你选择科学问题。

如果问题是未来的新系列，单纯时间划分或系列划分都未必充分。
应指定联合纳入规则，并检查剩多少组。数据只支持一种留出时，不要同时宣称无法实现的多重泛化。
同一化合物重复测量或共享测定来源，也需要遵守声明的分组。所有学习型预处理都应限制在相应训练折内。

## 完整相似性诊断算例

二进制指纹的 Tanimoto 相似性为交集大小除以并集大小。
查询 Q 的位集合是 `[1,2,3]`，训练化合物 A 为 `[2,3,4]`，B 为 `[1,2,3,5]`：

```text
T(Q,A) = 2/4 = 0.50
T(Q,B) = 3/4 = 0.75
最近训练相似性 = 0.75
```

这属于选定指纹的性质，不是化学机制之间的通用距离。
最大相似性 0.75 不能直接译成“预测置信度 75%”。一位变化可伴随很大活性变化；相似结构若来自不同测定，标签解释也可能不同。

适用域诊断询问预期预测是否得到训练总体支持。应一起检查最近邻、描述符范围、系列和测定语境支持。
任何预警阈值都应通过声明的开发流程校准。例如预先声明相似性低于 0.40 则报警，上述 Q 不会触发；通过警报却不保证正确。
查询可在结构上熟悉，在生物语境上陌生。
有测量时报告亚组误差和样本量，不要为少量挑选出的有利邻居虚构置信区间。

## SAR 解释与反事实

在构造的匹配测定中，化合物 M 的 pActivity 为 6.0，类似物 N 为 7.0。
若同一终点定义为 `−log10(activity，以 molar 为单位)`，对应活性是 1 µM 与 0.1 µM。
差一个对数单位，即声明方向上的十倍浓度比。这是**该虚构例子内部**的配对 SAR 对比，不证明修改基团在所有骨架上都单独导致此差异。

匹配分子对缩小了结构差异，但测定变异、溶解性、聚集、结合模式和其他语境仍影响解释。
归因图解释的是选定方法下拟合模型的响应，本身不识别生物机制。
模型反事实还需要结构有效、干预可实现且测量语境相关。
优化归因分数可能产生模型偏好、却位于有效预测适用域之外的对象。

应将解释转成可检验假设：明确局部化学变化、哪个终点应改变、仍有哪些替代解释，以及什么独立测量能区分它们。
在新系列和语境真正支持迁移之前，保持局部主张。

## 看一次解释错过成因

[SAR 归因实验](/zh-cn/labs/sar-attribution/)在生成规则写明于文件中的数据上拟合模型，
因此成因是已知的而不是推断出来的。一个与该成因相关的混杂因子，
在 8 个活跃分子里有 7 个拿走了更大份额的原子功劳，
而打破该相关的那对匹配分子被排成了相反的顺序。**这正是真实活性数据永远不允许你做的那项核对。**

## 独立练习

1. 查询位为 `[1,3,5]`，邻居位为 `[1,2,3,4]`。计算 Tanimoto，它是否等于预测成功概率？
2. 六化合物表中，哪种划分直接留出系列 C？哪种直接分离晚期测量？为什么不同？
3. 不感知手性的表示给两个终点不同的实测立体异构体分配相同特征。仅使用这些特征的确定性预测器能同时正确输出两种标签吗？
4. 模型突出某取代基，并预测改善一个对数单位。在称为已验证的十倍生物改善前，还缺什么？

<details data-worked-answer>
<summary>答案：对齐表示、任务与主张</summary>

交集 2 位、并集 5 位，相似性为 0.40，不是成功概率。
留出 C1/C2 分离系列 C；早期训练、晚期测试分离时间，却共享全部三个系列。
普通确定性预测器对相同输入只能返回相同输出，无法仅从这些特征恢复两个不同标签。
预测变化还需要一致的终点单位、有效且可实现的类似物、匹配测量及适当独立确认。
被突出显示的取代基是模型证据，不是该确认。
