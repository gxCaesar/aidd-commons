## 学习目标与先修知识

请先阅读[化学系列与适用域](/zh-cn/learn/qsar-properties/chemical-series-and-domains/)和[回归与分类误差](/zh-cn/learn/qsar-properties/regression-classification-errors/)。学完应能界定所提适用域覆盖什么，计算到训练集的最近邻距离，并说明一种划分能支持哪种泛化主张。[FreeSolv 诊断实验](/zh-cn/labs/applicability-domain-audit/)提供可运行案例。

适用域是关于拟合预测器在何种预期输入和测量语境下，能满足既定性能准则的主张。它需要声明总体、终点、表示、损失函数和决策程序。到训练数据的距离可能揭示某种表示下的支持稀疏区域。仅凭这个距离，不能确定某个查询的误差是否可接受。

## 距离取决于表示

本实验用 RDKit 计算 MolWt、MolLogP、TPSA、NumHDonors 和 NumHAcceptors。每项性质的测试与训练分子绝对差，除以在训练集测得的总体标准差；标准差为零时改用 1。五项缩放差值取平均。对所有训练分子所得距离取最小值，就是测试分子到训练集最近邻的距离。这条规则是实验的选择，距离没有物理单位。

| 构造的分子对 | 五项缩放性质差值 | 平均距离 |
| --- | --- | ---: |
| 查询分子与训练 A | 1, 0, 0, 0, 0 | 0.2 |
| 查询分子与训练 B | 0, 1, 1, 0, 0 | 0.4 |

在这个构造计算中，A 是最近训练分子。某项性质差值为零，只表示该选定性质缩放后相同，不表示分子或其水合自由能相同。立体化学和其他结构差异可能没有体现在这五个摘要中。若要设预警阈值，还需要针对预期误差代价和总体单独开展开发与评估。

## 骨架留出的误差

本实验采用 Bemis-Murcko 骨架划分，并将每个无环分子指定为独立的规范 SMILES 分组。岭回归只使用训练标签，在感知手性的 Morgan 指纹上拟合，然后在测试标签上测量绝对误差。距离表示与模型指纹有意不同。前者考察选定的全局性质，后者为基线提供预测。

按行随机划分可能让相关骨架出现在两侧，检验的是已知化学附近的插值。骨架划分将其定义的分组隔开，询问模型对训练中未见分组的分子表现如何。单独任何一种划分，都不能证明未来测定、改变的测量语境或某个新分子的性能。报告对比时必须带上划分规则与表示。

## 基于实测计数的算例

已提交的 FreeSolv v0.52 计算包含 642 个实测分子和 382 个不同骨架键。双向划分将来自 254 个键的 514 个分子放入训练集，来自 128 个键的 128 个分子放入测试集。实测水合自由能的中位数是 -3.53 kcal/mol，第一和第三四分位数是 -5.7275 和 -1.215 kcal/mol。

测试分子到训练集最近邻距离的中位数为 0.023539，四分位数为 0.000205 和 0.082516，四分位距为 0.082312。`mobley_9460824` 的最大最近邻距离为 0.43877，其最近训练分子是 `mobley_1849020`。同一测试分子到最远训练分子 `mobley_4587267` 的距离为 3.996323。最后这个距离不是最近邻诊断值。

| 按最近邻距离排序的测试半区 | 分子数 | 绝对误差中位数，kcal/mol |
| --- | ---: | ---: |
| 较小距离 | 64 | 0.586647 |
| 较大距离 | 64 | 0.800081 |

在这个固定岭回归基线上，较大距离半区观察到的误差中位数较高。两个中位数不能建立单调误差曲线或适用域边界。训练集性质缩放和骨架划分属于这个结果的一部分，不是普适的化学常数。

## 独立练习

利用实测表格，计算两个绝对误差中位数之差，并说明每个中位数背后有多少测试分子。一位同事建议把总体距离中位数 0.023539 作为新分子的通过与否边界。说明缺少什么证据。再说明如果对同一总体按行随机划分，主张会怎样改变。

差值为 0.213434 kcal/mol，由 0.800081 减去 0.586647 得到。每个中位数概括 128 个测试分子中的 64 个。距离中位数只把这批测试样本分成两半。它既未对可容忍误差作校准，也未针对新分子作前瞻核查，因此不是通过与否边界。按行随机划分可能让相关骨架出现在两侧。所得误差对比描述的是另一种划分，不能代替骨架留出结果。

## 材料没有展示的内容

本案例不判定新分子是否处在适用域内，不拟合更好的模型，也不优化这五个性质或把它们的距离转成化学机制陈述。它报告一次发行文件、一种骨架分配和一种低成本基线下的实测误差。组间中位数差异是进一步验证的诊断线索，不是逐分子的性能估计。
