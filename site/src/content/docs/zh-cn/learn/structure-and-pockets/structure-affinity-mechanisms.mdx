## 学习目标

完成本课后，你应能说出结构或看似亲和力的数字背后的预测目标，在明确单位的条件下将 IC50
换算为 pIC50，并说明为何联合预测不是因果性的能量学证明。你也应能写出一个输出所能支持的
更窄决策。

## 预备知识与任务边界

先阅读[结构、口袋与共折叠](/zh-cn/learn/structure-and-pockets/cofolding-frontier/)，再阅读
[从对接到自由能微扰](/zh-cn/learn/physics-based-modeling/docking-to-fep/)。前两课将结构假设
与实验决策区分开来，并介绍物理模型终点的边界。这里的任务不是抽象地“预测亲和力”，而是将
指定的分子输入和测定语境映射为一个已声明的输出。

令 `X` 表示蛋白质—配体表示，`E` 表示终点定义，`B` 表示结合者标签。一个系统可能返回以下
任一种输出：

| 输出 | 该输出所命名的问题 | 它本身不能确立的内容 |
| --- | --- | --- |
| 坐标或构象 | 提议的是哪一种几何形状？ | 配体在测定中结合 |
| 构象置信度 | 模型对这一提议几何形状有多大信心？ | 经校准的结合者概率或能量分解 |
| `P(B=1 | X)` | 该输入被预测属于模型结合者类别吗？ | 连续测定终点的数值大小 |
| `y_hat(X, E)` | 针对该命名终点和单位预测什么数值？ | 与所有其他“类似亲和力”测量等价 |

输入或潜变量表示可以包含原子类型、键、残基或配体 token、成对关系和三维位置。成对特征可描述
残基—配体邻近等关系。坐标是输出，随后提出一个与学习表示相容的几何形状。无论采用哪一种表示，
都不会使几何形状成为实测自由能差。

## 训练目标与推理

多输出模型可用如下示意目标训练：
`L = lambda_struct L_struct + lambda_bind L_bind + lambda_aff L_aff`。
这是通用教学目标，不是 Boltz 的精确训练配方。
结构项、二元结合者项和连续终点项可以共享表示，但使用不同标签和损失。推理时，模型可以同时
输出坐标提议、置信度、二元概率和数值终点。共享参数或同时输出，并不能证明改变一个坐标会导致
特定能量变化，也不能使这些输出彼此可互换。

作为具体的命名例子，官方 [Boltz 仓库](https://github.com/jwohlwend/boltz) 区分
`affinity_probability_binary` 和 `affinity_pred_value`。其 README 说明，前者用于结合者与
诱饵的预测，后者是由微摩尔单位 IC50 得到的 `log10(IC50)` 值，用于在优化阶段排序已指定的
结合者。本课不复现其训练，也不宣称已完整发布训练材料；在作出可用性陈述前，应检查当前仓库。

`pIC50` 使用另一种约定：`pIC50 = -log10(IC50 in M)`。对于一个**构造的教学数值**
`IC50 = 50 nM = 5 x 10^-8 M`，`pIC50 = 7.30`。符号和单位很重要。同一个数值在
`log10(IC50 in micromolar)` 约定下为 `-1.30`，因为 `50 nM = 0.05 micromolar`。不要悄然将
其中任一数值与 KD、Ki、EC50 或另一种测定设计下的终点相比较。它们不是亲和力的通用同义词。

## 推导案例：高置信构象不是结合者判定

考虑以下**构造的模型输出**，而不是一项测量：

- 提议构象置信度：`0.92`；
- 结合者概率：`P(B=1 | X) = 0.18`；
- 终点预测：`log10(IC50 in micromolar) = 0.70`。

假设一个筛选规则错误地把所有置信度高于 `0.90` 的构象都标为结合者。它会把该配体判为阳性。
二元头上预先声明为 `0.50` 的结合者阈值则会把它判为阴性。第一条规则是错误的，因为它用几何
置信度来替代结合者决策。数值终点也不允许推翻该决策：它有命名的 IC50 约定，并且仍只是模型预测。

安全的报告是：“模型提出了一个高置信构象，而其结合者头在该输入表示下给出低概率。”它不是
“配体结合”“构象证明亲和力”或“模型识别了因果性的能量机制”。若要作出这些陈述，需要测定、
恰当的结构观察，或已验证的前瞻性方案。

## 独立练习

一份报告给出 `log10(IC50 in micromolar) = -1.00`，并称其为 “pIC50 = -1.00”。更正记法并计算
pIC50。然后说出一个缺失条件，它会使该数字无法与另一条亲和力记录普遍比较。

<details data-worked-answer>
<summary>参考答案</summary>

`log10(IC50 in micromolar) = -1.00` 意味着 `IC50 = 0.1 micromolar = 10^-7 M`。因此
`pIC50 = -log10(10^-7) = 7.00`，而不是 `-1.00`。一个缺失条件可以是测定方案、靶标构建体、
配体状态、温度、竞争底物浓度或终点本身。仅仅匹配“亲和力”这样的词并不足够。

</details>

## 失效边界与来源路径

置信度受输入和模型表示的条件限制。即使构象形式良好，配体制备、靶标状态、测定语境或结合者
标签也可能不匹配。多任务输出可用于一个已声明的决策，但不是它所学项恢复物理因果的证明。
面对能量学问题，应回到[物理模型课程](/zh-cn/learn/physics-based-modeling/docking-to-fep/)，
并陈述体系、终点和验证边界。
