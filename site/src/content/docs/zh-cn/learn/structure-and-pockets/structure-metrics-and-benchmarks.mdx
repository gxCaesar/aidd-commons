## 学习目标与前置知识

学完[口袋状态与置信度](/learn/structure-and-pockets/pocket-states-and-confidence/)
和[指标与不确定性](/learn/evaluation-and-reproducibility/metrics-and-uncertainty/)后，
使用 PXMeter 记录辨别结构比较指标测量的对象、原子对应关系为何必要，以及核查另一
时间窗口内的基准结论需要什么。本课是附带书面练习的阅读课，没有运行工具或其基准。
[英文原版](/learn/structure-and-pockets/structure-metrics-and-benchmarks/)是规范版本。

## 比较约定

PXMeter 将模型结构与参考结构比较。它的命令行和 Python 接口在计算下列指标前
建立全原子对应关系。参考结构、模型结构和对应关系共同定义了比较。与参考结构接近
并不能证明参考结构正确、所评估的界面就是结合界面，或姿态在物理上可行。这四项
指标针对比较的不同部分，不能合并成一项关于生物学有效性的结论。

## 四项指标

| 指标 | 测量对象 | 不能确立的结论 |
| --- | --- | --- |
| LDDT | 无需全局叠合即可比较参考结构与模型结构的局部一致性 | 参考结构正确或配体姿态在物理上可行 |
| DockQ | 界面相互作用的质量 | 所评估的界面就是结合界面 |
| Pocket-aligned RMSD | 在口袋对齐后评估配体姿态质量 | 姿态在物理上可行 |
| PoseBusters validity checks | 生成的分子姿态是否合理 | 模型结构与参考结构接近或已有结合测量 |

这些功能见于 [PXMeter 仓库](https://github.com/bytedance/PXMeter)和
[README](https://raw.githubusercontent.com/bytedance/PXMeter/main/README.md)。
解读分数时必须说明比较对象。任何一项指标单独使用，都不能确立实验性的结合或机制结果。

## 比较前的对应关系

PXMeter 在计算指标之前，先建立参考结构与模型结构之间的全原子对应关系。如果原子
配对没有可靠依据，报告的差异可能反映原子如何配对或结构如何对齐，而非被评估的
预测本身。[评估课程](/learn/evaluation-and-reproducibility/metrics-and-uncertainty/)
要求说明指标汇总了什么。这里还要先确定究竟比较了哪些结构特征。指标的名称无法
纠正配错的结构。

## 基准及其时间窗口

PXMeter README 描述了 RecentPDB 低同源性数据集。其构建过程包括过滤、同源性
扫描、聚类和子集标注。基准流程可以在选定的时间窗口内从头重建评估数据集。因此，
一个窗口内的结果只描述按该窗口构建的集合。要核查比较结果能否延续到另一窗口，
就需重建集合并重新评估。记录没有提供分割名称、样本数、发布清单或被评测模型名单，
因此本课没有模型排行榜。

基准流程、基准数据和评估驱动程序位于源码仓库，不包含在发布到 PyPI 的安装包中。
安装该包可以获得指标，却不能获得基准。若要核查另一个时间窗口，读者需要源码仓库
中的基准流程。

## 推演案例

假设有人报告一个预测结构相对于参考结构得分很好。这个比较支持什么结论，还有
什么没有经过检验？哪一步计算使比较具有可解释性？如果后来有人提出另一个时间
窗口内的排名，读者需要取得什么才能核查？

有依据的结论是，在声明的指标下，预测结构与该参考结构接近。这不能证明参考结构
正确、确认生物学结合界面，或确立姿态在物理上可行。计算指标之前必须建立全原子
对应关系。另一个时间窗口内的排名还需重建评估集，并运行源码仓库中的基准流程。
发布的安装包不包含其数据或评估驱动程序。本案例没有给出实测分数或模型排名。

## 适用范围

本课没有运行 PXMeter，也没有为任何结构评分。记录未列出被评测模型的名单。基准
构建方法支持针对所选时间窗口的结论，本课不提供模型排名。Biotite 捆绑的 Chemical
Component Dictionary 和 RCSB PDB 参考结构使输入涉及其他项目的条款。阅读开放
状态字段不等于执行资产或复现基准。
