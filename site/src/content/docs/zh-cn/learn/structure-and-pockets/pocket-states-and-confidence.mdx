## 学习目标与前置知识

你将把结合口袋定义为一个已声明分子状态的性质，区分置信度输出和配体结合证据，并对一个开放
结构资产能否被复用作出可复现的决定。请先读[结构、口袋与共折叠](/zh-cn/learn/structure-and-pockets/cofolding-frontier/)
和[结构、亲和力与预测量的含义](/zh-cn/learn/structure-and-pockets/structure-affinity-mechanisms/)。本课为浏览器和手算推理教学，
不运行口袋检测、不预测配体，也不确立一个位点具有成药性。

## 口袋由状态和规则定义

把一个表面凹陷称为口袋，隐去了若干选择。一个有用的口袋定义应记录坐标集或模型、生物组装体或
链的选择、相关时的质子化与配体假设、几何规则，以及该调用的目的。不同工作流可调用溶剂可及
体积或以配体为中心的残基邻域，因此可在柔性门控区域分歧而二者均不必错误。

令 `S` 表示已声明的蛋白质或复合物状态，`G` 表示几何口袋规则，`P(S, G)` 表示所得的原子、
残基或体积集合。陈述 `P(S_closed, G) != P(S_open, G)` 是通常的状态依赖性，不是矛盾。
**隐蔽位点假设（cryptic-site hypothesis）**更强：所预期的决策依赖于一个在指定参考状态中不可用
或已显著改变、但在一个或多个替代状态中出现的口袋。它仍需要明确的替代状态来源和恰当实验，
才能成为结合或机制主张。

这种状态语言避免两种常见错误。一个 apo 结构中的口袋并不自动是配体结合复合物所使用的口袋，
一个预测的替代构象也不显示未观察到的配体会将其稳定。坐标、群体、动力学、配体可及性和功能
后果是不同的问题。

## 置信度回答的是输出，不是分子决策

现代结构系统可在坐标旁提供置信度量。例如，AlphaFold 3 论文将 `pLDDT` 描述为预测局部准确性，
将 `PAE` 和 `PDE` 矩阵描述为一个生成结构的预测误差
[Abramson et al.](https://www.nature.com/articles/s41586-024-07487-w)。
这些量可帮助识别一个提出的模型中应谨慎解释的部分。它们不测量实验群体、配体占据、测定反应，
也不测量一个提出口袋可执行的概率。

应在它所命名的层面使用置信度。局部准确性可指导谨慎的侧链标注，成对误差可标记相对放置不确定性。
二者都不能使模型样本成为相互独立的实验结构；若口袋依赖结构域运动，单一全局分数是弱证据。

| 问题                               | 至少应保留的对象                                          | 置信度值不能替代的内容 |
| ---------------------------------- | --------------------------------------------------------- | ---------------------- |
| 这是一个特定的几何口袋吗？         | 状态 `S`、规则 `G`、坐标和残基/体积输出                   | `G` 的定义             |
| 开放状态是否与关闭状态有合理差异？ | 两个坐标集、比对规则、变化摘要                            | 实验性的状态群体       |
| 该位点可否指导下一项假设？         | 靶标构建体、预期决策、置信度与不确定性说明                | 结合者、效力或机制测量 |
| 其他读者能否复用该资产？           | 稳定标识符、来源 URL、组装体/链、方法、获取日期和变换日志 | 未记录的坐标编辑       |

## 开放结构资产是数据，不是插图

只有当读者可以确认检索对象时，开放记录才可复用。RCSB PDB 的程序接口为检索、数据和坐标访问
提供不同服务；这些服务不会抹去条目元数据与本地衍生物之间的区别
[RCSB PDB Web APIs](https://www.rcsb.org/docs/programmatic-access/web-apis-overview)。对于教学图或后续
计算，应保留条目标识符、生物组装体还是不对称单元的选择、链或实体标识符、若提供则实验方法、
适用时的分辨率或验证字段、来源 URL、获取日期和每一项坐标变换。

不要悄然修补缺失原子、重命名残基、丢弃替代位置或合并链，然后把结果称为“PDB 结构”。这种
衍生物可以有用，但必须说明编辑和目的。同样，一个模型预测可能是具有明确许可证或访问路径的
开放资产，但它不能与实验沉积物互换。复用包括其来源与局限，而不只是坐标。

工作流开放性对 code、weights、input schema、output artifact 和 licence 有独立门槛。开放坐标条目
不提供其他项目；没有已声明 inputs、outputs 和许可的公共 code 不能确立一个已主张工作流的复现。

## 已解案例：保留两个状态假设

本案例的全部数值均为**构造的教学数值**。一个团队拥有相同已声明蛋白质构建体的两项坐标资产：
`S_closed` 和 `S_open`。规则 `G` 将连通腔体 `>= 150 Å³` 定义为口袋；`S_closed` 在选定残基集合
附近有 `90 Å³`，`S_open` 有 `160 Å³`。两个资产在一项已声明的局部比对后相差 `2.5 Å`。结构模型在
推定门控附近报告其 `0–100` 标度上的 `pLDDT = 88`，以及门控到结构域的 `PAE = 7.4 Å`；二者都不是
隐蔽位点或结合的概率。归档记录只为 `S_closed` 给出报告的 `1.8 Å` 实验分辨率。

有效的教学决定不是“一个隐蔽口袋已被证明”。团队可以写道：“在 `G` 下，两个已声明坐标资产
产生不同的口袋调用；开放状态几何是一个相对放置仍不确定的假设。”它不应把 `1.8 Å` 字段复制给
`S_open`，也不应把不确定性摘要替换成配体结合主张。构象敏感的后续工作必须询问替代几何是否
对应相关靶标状态。

## 局限与独立练习

口袋调用器对溶剂、探针半径、侧链和连通性的处理不同。预测器可在数据未约束时生成替代方案，
归档标识符本身也不说明匹配的组装体、链、处理步骤或生物条件。应缩窄决策，而非丢弃坐标。

**手算练习（不可运行、非实证）：** 一个构造项目有 `S_A` 和 `S_B`。在同一 `G` 下，`P(S_A, G)`
为 `90 Å³` 腔体，`P(S_B, G)` 为 `210 Å³` 腔体；局部比对位移为 `1.0 Å`。`S_B` 模型输出在其 `0–100`
标度上有 `pLDDT = 91`，但没有实验测量任一状态。写出一条有依据的口袋陈述和一条不可作出的陈述。然后
列出把 `S_B` 作为可复用资产分享前需要的两个元数据字段。

一条有依据的陈述是：“在已声明规则 `G` 下，构造坐标为 `S_A` 和 `S_B` 给出不同的口袋体积；
`S_B` 提供了替代口袋的假设。”不可陈述 `210 Å³` 口袋在某群体中被观察到、结合配体或具有成药性。

以及任何变换的日志。`pLDDT = 91` 是预测局部准确性，不是概率，也不能替代缺失实验。

## 自己读三个已沉积的状态

[EGFR 结构证据实验](/zh-cn/labs/egfr-structure-evidence/)把本课的论证放到同一个激酶的
三份已沉积晶体结构上运行。同一个厄洛替尼配体，在一份结构里 Lys745 到 Glu762 的距离是
3.71 A，在另一份被沉积者称为 inactive 的结构里是 14.41 A。截断值从 4 A 挪到 6 A 时，
结合位点从 15 个残基增加到 25 个；没有任何文件在 ATP 位点之外带有配体，所以它们都不能
定义第二个口袋。
