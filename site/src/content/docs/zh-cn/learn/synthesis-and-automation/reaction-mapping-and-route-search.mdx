## 学习目标与前置知识

你将区分原子映射假设与反应机制，将逆合成提案表示成图，并记录化学选择性和保护基约束，而不把
路线计划变成实验室操作程序。请先读[从反应预测到实验室](/zh-cn/learn/synthesis-and-automation/reaction-to-lab/)。
本课为浏览器和手算推理教学，不含实验配方、试剂列表、操作条件，亦不主张一条路线会成功。

## 原子映射命名对应关系，而非因果性

原子映射为一个反应记录的反应物和产物两侧原子赋予身份标签。若 `A_R` 和 `A_P` 是保留的原子集，
映射可写为 `m: A_R -> A_P`。它帮助模型或读者描述在一项转化中哪些原子被视为守恒。它不是微观
机制的观察，不保证质量平衡，也不证明带标签的路径在烧瓶中发生。对称性、标准化、缺失物种和模糊
反应物角色可允许不止一种可辩护的映射。

反应类别增加更粗的标签，如键编辑类型或官能团变化。一个类别可支持搜索策略，却不规定条件、
范围、选择性、产率、纯化负担或安全性。官方 RXNMapper 仓库描述 attention-guided atom-mapping
系统并链接其相关论文 [RXNMapper](https://github.com/rxn4chemistry/rxnmapper)。其可用性有助于界定
实现边界；它不是对新记录中映射的验证。

| 字段     | 可复现的反应图记录                                     | 它不可被称为     |
| -------- | ------------------------------------------------------ | ---------------- |
| 分子身份 | 标准化结构、立体化学策略与映射版本                     | 没有输入的“反应” |
| 原子映射 | 映射的反应物/产物原子及未映射原子处理                  | 已证明机制       |
| 角色     | substrate、product、reagent/agent 与 solvent-role 策略 | 完整实验条件     |
| 类别     | 已命名的转化词汇与标签来源                             | 执行指令         |
| 结局证据 | 若有则为已声明来源与结局字段                           | 前瞻可行性       |

## 逆合成搜索有向超图

逆合成反转所需的产物侧转化：从目标节点 `T`，提出前体集合 `{P_1, P_2, ...}`。不同于普通边，
一个断键常需多个前体共同参与，因此路线更适合表示为有向超图。每条超边至少应携带其模板或策略
来源、反应类别标签、映射或编辑假设，以及它被提出时的约束。

搜索系统可按学习似然、模板覆盖、库存可得性、长度或其他启发式对多条此类路径排序。这些是搜索
信号，不是实测成功概率。AiZynthFinder 项目描述逆合成规划：搜索递归地把一个分子分解成可购买
前体，策略提出扩展 [AiZynthFinder](https://github.com/MolecularAI/aizynthfinder)。ASKCOS 描述计算机
辅助合成规划并说明较新版本的迁移，这提醒我们记录工具与模型版本，而不是假定系统静态
[ASKCOS](https://github.com/ASKCOS/askcos)。

决策单位是完整路线图，而非单个高排序步骤。对每一个终端前体，记录已声明的可得性来源和日期。
对每一条边，记录它来自先例、模型还是人工规则。当多条替代路线共享模板、训练记录或未测试的
选择性前提时，不可将它们算作独立实验性证据。

## 化学选择性和保护基是状态变量

若多个位点可能转化，路线图需要一项选择性假设：预期哪一个位点、存在哪些竞争位点，以及每个
节点表示哪一种结构状态。保护基不是搜索后添加的脚注；它改变分子图，从而改变哪些断键有意义。
在安全规划记录中，把它抽象表示为如“位点 X 已遮蔽”或“位点 X 未遮蔽”的节点状态，并链接到明确
的 add、retain 或 remove 转化类别。不要从该图推断具体操作程序。

这项约束避免一种误导性捷径：规划器可能仅因为悄然将受保护与未保护形式当成同一节点而找到短
路径。它也迫使一个有用的人类审阅问题：竞争位点假设是否由提出记录支持，还是未知？未知是有效
路线状态。它应触发可行性审阅，而不是被填入编造条件。

## 已解案例：有未解决选择性字段的图

本案例的全部数值均为**构造的教学数值**。一个目标图 `T` 含带标签原子 `{a, b, c, d}`。一项提出的
断键 `e_1` 给出前体 `{P_1(a,b), P_2(c,d)}` 和类别标签 `C_1`。第二映射假设交换两个对称等价原子
标签，却保留相同未标记图。正确记录保留两项映射假设，或声明 tie-breaking 策略；任一映射都不
展示分子机制。

两条提出的路线图随后到达 `T`：

| 路线 | 终端可得性记录   | 边数 | 选择性字段                | 状态               |
| ---- | ---------------- | ---: | ------------------------- | ------------------ |
| R1   | 两个终端均已记录 |  `2` | “竞争位点未解决”          | 暂停，待可行性审阅 |
| R2   | 两个终端均已记录 |  `2` | “节点 N 的保护状态不匹配” | 图不一致           |

R1 并不会仅因短且终端节点已记录而“可行”。它是一项具有未解决字段的抽象路线假设。R2 不会被高
搜索分数挽救：节点状态不匹配阻止已声明边组合成一个连贯图。诚实的交接请化学家检查已声明结构
替代方案和证据，而不提供操作程序。

## 局限与独立练习

历史反应记录可遗漏角色、条件、失败和负面结局。原子映射可能错误或不唯一。搜索分数可反映数据
库覆盖而非新目标的可行性。短路线可将困难集中在一项没有支持的转化。应将这些局限与实现失败
区分开来，并保留“未知”字段。

**手算练习（不可运行、非实证）：** 一张构造路线图有目标 `U`、前体集合 `{V, W}` 和一个类别标签
`C_2`。其映射有一个未映射原子 `z`；第二候选路线没有未映射原子，但终端可得性字段标为“未记录”。
每条路线必须保留什么，以下哪一句不成立：“第一映射证明机制”“第二条需要可得性检查”或“二者
均是图假设”？

<details data-worked-answer>
<summary>参考答案</summary>

应保留身份、标准化图与映射版本、原子映射处理、类别/来源、每条边与终端字段，以及每个不确定性
或失败原因。第一条路线需要为 `z` 声明策略；第二条需要可得性检查。“第一映射证明机制”不成立。
二者均为图假设，直至单独的证据和可行性审阅支持更窄主张。

</details>

## 自己把几类方法比一遍

[断键比较实验](/zh-cn/labs/retro-disconnection/)在一组构造路线集上运行规则、检索与模板三类断键，
并把学习型那一类声明出来而不运行。三者在先例集内部都是满分，出了它则完全分开，
而且成因各不相同。整个路线集始终把实验室可行性保持为未评估，
因为回收到一条被记录的路线，只是关于一次图编辑的陈述。
