## 学习目标

学完本课，你应当能够：

1. 说出归档测定记录中哪些字段被一个单独的效力数值掩盖；
2. 区分等式与界限，并说明两者各自允许得出什么结论；
3. 把对照制度与归一化方程读作固定标尺的两件事；
4. 把记录的重复计数与赋予该计数含义的归档声明一起读；以及
5. 判断一个测定自身的对照记录支持哪些结论、不支持哪些结论。

## 预备知识与范围

先复习[测定对照与剂量反应](/zh-cn/learn/drug-discovery-foundations/assay-controls-dose-response/)。
那一课解释了本课所应用的机制。它命名空白、载体、阴性对照与阳性对照各自的作用，它写下
百分抑制与百分刺激如何由它们计算得到，它展示了如何读取浓度反应曲线而不把它误当作机制
或疗效。

本课不重复那些内容。它打开六个真实的、已归档的 PubChem BioAssay 剂量反应测定并读取它们
自身的记录：终点标签上的读出混合、归档限定符上的关系混合、置信分数分布、每个归档协议
声明的重复结构、每个协议命名的对照制度与参考孔，以及每个协议写下的归一化方程。教学要点
是：一个测定只在自身对照记录支持的范围内才允许得出结论。

配套路线是[归档测定实验](/zh-cn/labs/assay-endpoint-controls/)，它从经过字节校验的缓存中读取
同样的六个测定并打印同样的数字。本课不拟合、不预测、不打分，也没有为本课测量任何读者
学习结果。

## 廉价基线

廉价基线排在任何比较之前，在这里它构成整个读取的前半部分。此时没有拟合任何东西，
也没有查看任何曲线。

读出混合对每一个准入终点值计数。

| 终点标签 | 准入终点值 | 1529 中的比例 |
| -------- | ---------: | ------------: |
| AC50      |        706 |   0.46174     |
| IC50      |        429 |   0.280576    |
| Ki        |        272 |   0.177894    |
| EC50      |         69 |   0.045128    |
| MIC       |         53 |   0.034663    |
| 合计      |      1529 |               |

关系混合对每一个准入行计数一个限定符。

| 关系限定符 | 准入行数 | 1257 中的比例 |
| ---------- | -------: | ------------: |
| 等式       |      832 |   0.661893    |
| 大于界限   |      406 |   0.322991    |
| 小于界限   |        4 |   0.003182    |
| 未声明限定符 |    15 |   0.011933    |
| 合计       |     1257 |               |

这两个混合的分母不同，而差异有启发性。读出混合到达 1529，是因为测定 519 在它的 272 个
准入行上各记录两个终点列，即 IC50 与 Ki。关系混合到达 1257，是因为一个限定符附着在行上
而不是附着在终点值上。两个总数因此相差的正是测定 519 的准入行数。

置信分数在 0.002386634844868735 的准入行上达到最大值 100，在 0.3206046141607001 的准入行上
为 0，中位数为 23，最小值为 0。置信分数是归档记录的一个字段，因此这里把它读作该记录的属性，
而不是底层实验的属性。

这些数字没有一个是效力。它们描述的是档案的形状，而且它们是这次读取中最廉价的证据，
因为它们不需要对任何化合物作任何假设。

## 等式与界限

等式是测量值。界限是删失值，它陈述数值的一侧而不是数值本身。在 1257 个准入行中，
832 个带等式，406 个带大于界限，4 个带小于界限，15 个不带任何限定符。因此记录下来的关系
里几乎有三分之一是界限，而界限陈述的是一侧而不是一个量级。

同一个测定中的两个化合物显示限定符改变了什么。

化合物 1044226 在 0.0023 到 45.0 微摩尔的浓度序列上被测试。它归档的最低响应是 -1.82 百分比，
最高是 -0.07 百分比，因此没有任何被测浓度产生正的归档响应。归档终点是 EC50 45.0 微摩尔，
带大于限定符，它陈述半最大浓度高于 45.0 微摩尔，而不是它等于 45.0 微摩尔。

化合物 1160933 在同一个浓度序列上被测试。它归档的最低响应是 -0.67 百分比，最高是 60.18
百分比。归档终点是 EC50 30.8 微摩尔，带等式限定符，它是一个测量值。

两行来自同一个测定，在同一标尺上，处于同一个对照记录之下。唯一的差别是限定符，
而限定符正是数字与一侧之间的差别。为第一个化合物写“EC50 45.0 微摩尔”，就是把一个删失值
转成了档案从未作出的测量。

## 重复结构

档案记录一个逐行的计数，而协议说明这个计数意味着什么。不带着那份声明读计数，
就是读一个没有单位的整数。

| 测定 | 记录的列 | 该计数是什么 | 归档声明 |
| ---- | -------- | ------------ | -------- |
| 439 | Number of Points | 每条曲线的点数 | 每个化合物的稀释序列以三重复测定 |
| 464 | N DataPoints | 每条曲线的点数 | 765 个化合物中的 750 个以三倍稀释连续稀释十次 |
| 519 | N_POINTS | 每条曲线的点数 | 每个化合物以重复测试，得到 18 个数据点 |
| 548 | Number of Datapoints | 每条曲线的点数 | 每个化合物的稀释以三重复测定 |
| 691 | Number of MIC determinations | 独立测定次数 | 给出可测 MIC 的化合物被复测一次 |
| 1277 | Number of DataPoints | 每条曲线的点数 | 测试化合物以三重复在 10 点、1:3 稀释序列中测定 |

六个测定中有五个记录曲线上的点数，第六个记录独立测定次数，那是另一种重复。测定 691 有
41 行记录 1 次测定、12 行记录 2 次测定，与那份声明相符，即给出可测 MIC 的化合物会被复测
一次。

声明与记录到的计数是两个独立字段，它们在表面上并不总是一致。测定 464 的协议声明以三倍
步长连续稀释十次，而档案为其 706 个准入行中的 679 个记录 30 个数据点，其余行记录 26 到
29 之间。测定 519 的协议声明每个化合物 18 个数据点，而档案为其 272 行中的 121 行记录 18，
为 84 行记录 36，为 17 行记录 90。报告声明的读者与报告计数的读者报告的是两个不同的事实，
两者都必须读。

## 对照记录

对照制度是记录中决定数字含义的部分，因为它是设定标尺的部分。

| 测定 | 对照制度 | 命名的参考孔数 | 归档协议中出现的关键词 |
| ---- | -------- | -------------: | ---------------------- |
| 439 | 单一阳性参考 |            1 | control, positive control |
| 464 | 单一阳性参考 |            1 | control, positive control |
| 519 | 阳性与阴性参考 |            2 | control, positive control, negative control |
| 548 | 阳性与阴性参考 |            2 | control, positive control, negative control |
| 691 | 未声明 |            0 | 无 |
| 1277 | 阳性与阴性参考 |            2 | control, high_control, low_control |

测定 691 值得一条说明。它的归档协议中确实出现了“blank”一词，天真的关键词检索会把它读成
一个已声明的对照。归档协议用这个词指空的表格单元而不是对照孔，所以实验把它报告为歧义词，
并且不用它来决定是否声明了对照。该审计在这个测定中没有找到对照关键词，也没有找到参考孔
关键词。

六个测定中出现三种制度。两个测定命名一个参考而不命名基线，因此绝对百分比没有已声明的
原点，标尺只有顶端被锚定。三个测定同时命名阳性参考与阴性参考，因此标尺两端都被命名。
一个测定什么都没命名，因此它的标尺两端都没有锚定，也不产生任何按效力排序的结论。

## 归一化方程

在协议写下方程的地方，方程可以在它自己的参考孔上运行，并与归档值对照检查。实验要求它
产生的两个数值相差 100 个单位，且较低的那个位于零，方程才算是一个零到一百的响应标尺。
归档的逐浓度数值随后必须落在方程所跨的范围内，按 25.0 点的带宽放宽，并达到至少已声明的
0.95 比例。

档案自己的原文如下。

- 测定 439。“All data reported was normalized on a per-plate basis to wells that contained cells in the presence of 1 micromolar S1P (i.e. 100% activation).”
- 测定 464。“Percent inhibition was calculated from the median of the positive control doxorubicin at 4 micromolar final screening concentration.”
- 测定 519。“%Inhibition = 100 x [1 - (MFI_test - MFI_PC)/(MFI_NC - MFI_PC)], where MFI_PC is the average median fluorescence intensity of positive control wells (unlabeled receptor-blocking peptide) and MFI_NC is the average median fluorescence intensity of negative control wells (buffer).”
- 测定 548。“%inhibition = (test_compound - median_positive_control)/(median_positive_control - median_negative_control)*100, where positive control is Staurosporine and negative control is DMSO only.”
- 测定 1277。“Ratio = (T45 / T0); %Inhibition = [1-((Ratio Test_Compound - Median_Ratio_High_Control)/(Median_Ratio_Low_Control - Median_Ratio_High_Control))]*100, where Low_Control is wells containing DMSO, NPY and isoproterenol and High_Control is wells containing DMSO and isoproterenol.”
- 测定 691。归档协议没有命名任何对照，也没有写下方程。

这五个方程中有四个复现了它们归档数值所在的标尺。测定 519 的方程把阳性参考放在 100、
阴性参考放在 0，它所有的归档值都落在它所描述的范围内。测定 1277 的方程同样如此，落在
范围内的比例为 0.9841269841269841。

测定 548 的方程不是这样。它把阳性参考放在 0，把阴性参考放在 -100，只有
0.7620064034151548 的归档值落在它所描述的范围内，而测定 519 是 1.0。它的归档值从 -5.5 到
111.3 百分比，其中 5 个高于 100，33 个低于 0。协议命名了两个参考并写下了方程，而这个方程
仍然不描述档案自身数值所在的标尺。于是终点与方程具有不同的地位，实验把它们分开报告。

曲线检查还有一条性质值得读。它恰好跳过关系为界限的那些行。在测定 1277 中，它从归档点
重拟合了 28 条曲线，这正是等式行的数量，并跳过 35 行，即 4 个小于界限加上 31 个大于界限。
删失值没有可重算的曲线，因为档案没有说明半最大点在哪里。

## 推导案例

正在用六个已声明测定装配一张模型表。有三行是候选。

| 行 | 测定 | 化合物 | 归档终点 | 限定符 |
| -- | ---- | ------ | -------- | ------ |
| 1 | 548 | 1234059 | IC50 11.1 微摩尔 | 等式 |
| 2 | 1277 | 1099239 | IC50 35.0 微摩尔 | 大于界限 |
| 3 | 691 | 135415497 | MIC 100.0 微摩尔 | 大于界限 |

第 1 行可以写成 IC50 11.1 微摩尔。这个数字是测量值，可以与在测定 548 中测量的另一个
化合物相比较，因为该协议命名了阳性对照和阴性参考，并写下了归一化。不可以做的是用归档
方程来描述标尺，因为那个方程并不复现归档数值所在的标尺。终点被允许，方程不被允许。

第 2 行可以写成 IC50 大于 35.0 微摩尔。档案陈述半最大浓度高于 35.0 微摩尔，却没有陈述
高多少。写成 IC50 35.0 微摩尔就把一个删失值转成了测量值。该行可以与在测定 1277 中测量的
另一个化合物相比较，因为该协议命名了它的两个参考孔 high_control 与 low_control，并写下了
方程。

第 3 行可以写成 MIC 大于 100.0 微摩尔，仅此而已。该测定的响应标尺两端由归档协议从未命名
的对照设定，因此不产生关于响应为 0 百分比或 100 百分比的陈述，也不产生按效力给化合物
排名的结论。它的读出是分类式的，因此完全没有浓度反应曲线。

三行不能共用一个效力列。两个具有不同对照记录的测定不共享标尺，而没有对照记录的测定
根本没有可共享的标尺。第 1 行可以与来自测定 548 的另一行比较，第 2 行可以与来自测定
1277 的另一行比较，第 3 行不能与它自身以外的任何东西比较。在每一种情况下，限定符都随
着数字一起走，因为离开限定符，数字意味着不同的东西。

## 这不能说明什么

六个测定不是档案的样本，所以这里没有任何数字估计 PubChem BioAssay 整体上关系限定符、
置信分数或对照制度如何分布。准入值是已声明准入规则保留下来的结果，改动规则的读者会得到
另一个队列。缺失的对照记录被报告为关于档案的事实，而不是实验在没有对照的情况下完成的
证据，因为档案记录的就是它记录的东西。

这里没有在两个不同测定之间做效力比较，也没有作出任何关于体内、临床或药代动力学后果的
陈述。这里声明的每个测定都是体外或基于细胞的测量，而且它们每一个都是归档记录，而不是本
仓库实施的测量。原始仪器信号也不在档案中，因为归档的 CSV 携带的是存方自己归一化之后的
响应，所以归一化方程是在参考孔上而非在真实平板上运行的。

曲线检查在 5.0 点的固定容差下，把重算出的曲线与档案自己记录的终点值比较。它是对档案
内部一致性和档案自身归一化方程的检查。它不是对底层实验的评估，也无法侦测档案在读数和
记录终点上一致犯下的错误。

## 独立练习

用读数产生的数字回答下面三个问题。

1. 准入行中有多少个带等式，有多少个带界限，丢掉限定符会对大于界限和小于界限分别造成
   什么后果？
2. 六个测定中有三个同时声明了阳性参考与阴性参考。说出它们，说出那个归档方程无法复现
   其归档数值所在标尺的测定，并给出显示这一点的数字。
3. 对归档协议没有命名任何对照、空白或载体的那个测定，写出一句它自身记录允许的陈述，
   以及一句它不允许的陈述。

<details data-worked-answer>
<summary>参考答案</summary>

<p>1257 个准入行各自带一个关系限定符。其中 832 个是等式，406 个是大于界限，4 个是小于界限，15 个没有
15 个没有任何限定符，因此界限几乎占掉准入行的三分之一。大于界限说明真实值大于写出的数字，
所以丢掉限定符
就是把边界当作测量值报告，让化合物显得比档案所述更强。小于界限说明真实值更小，所以丢掉限定符
会让化合物显得比档案所述更弱。建立在这类数字上的排序会同时继承两种错误。</p>

<p>测定 519、548 与 1277 声明了阳性参考与阴性参考。测定 439 与 464 声明了单一阳性参考，
测定 691 什么都没声明。测定 548 是那个归档方程无法复现归档标尺的测定。它的方程把阳性参考
放在 0，把阴性参考放在 -100，只有 0.7620064034151548 的归档值落在该方程所描述的范围内，
而测定 519 是 1.0，测定 1277 是 0.9841269841269841。</p>

<p>测定 691 允许的是关于某个化合物在已声明浓度上的陈述，使用档案自己的措辞，并包含它所报告
阈值的边界。档案把化合物 135415497 记为 INACTIVE，并把它的 MIC 报告为大于 100.0 微摩尔。
它不允许的是按效力给化合物排名、声称任何浓度上的响应为 0 百分比或 100 百分比，以及把它的
阈值与标尺由具名对照确定的测定的阈值相比较。</p>

</details>
