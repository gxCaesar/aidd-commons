## 学习目标

区分生化或靶标结合、细胞表型和报告基因读出；指出归一化中的每个对照；并读出浓度反应曲线。
说明为什么整齐的曲线本身不是靶标结合、机制、机体疗效或临床获益的证据。

## 预备知识与决策边界

先阅读[药物发现语境](/zh-cn/learn/drug-discovery-foundations/discovery-context/)。测定将一个已命名的
生物学对象映射到信号和决策。比较前，声明体系、读出、对照、归一化方向、终点和未被排除的替代解释。
本课是阅读和手工计算课程，不是操作方案。

## 哪一种生物学问题通向读出？

| 测定类型       | 对象与读出                             | 它能够支持的结论           | 它本身不能确立的内容                       |
| -------------- | -------------------------------------- | -------------------------- | ------------------------------------------ |
| 生化或靶标结合 | 明确分子组分；结合或酶反应产物         | 所列条件下靠近靶标的反应   | 细胞进入、代谢、表型、选择性或疗效         |
| 细胞表型       | 完整细胞与已命名的标志物、形态或细胞数 | 该细胞语境中的反应         | 因果分子靶标或对另一语境的迁移             |
| 报告基因       | 报告酶、荧光蛋白或类似构建体           | 已声明逻辑下的报告信号变化 | 通路、靶标或表型已改变，而非报告器或检测器 |

报告器可用于细胞实验，但仍是测量层：化合物可以影响生物学、报告器或光学部分。不能仅因所有量
都被称为“活性”，就把靶标结合测量升级为细胞主张，或把报告信号变化升级为靶标机制。

## 对照同时确定基线和方向

对照标记预期的测定状态。**空白对照** `B` 估计没有相关生物信号时的仪器或试剂背景。**载体对照**
`V` 含有载体、没有测试化合物，设定基线。**阴性对照** `N` 预期不产生该效应；只有已声明时才与
`V` 重合。**阳性对照** `P` 是产生明确效应的参考。在抑制中，`P` 可比 `V` 有更低原始信号：
“阳性”表示预期效应，不是更大的数值。

当高原始信号表示剩余活性，按 `R_b = R - B`、`V_b = V - B` 和 `P_b = P - B` 背景校正。若 `V` 为
0% 抑制、`P` 为 100%，使用 `% inhibition = 100 * (V_b - R_b) / (V_b - P_b)`：`R = V` 时为 0%，
`R = P` 时为 100%。对于刺激，使用 ` % stimulation = 100 * (R_b - V_b) / (P_b - V_b)`。拟合前声明方向
和对照。
100% 标签是测定缩放参考，不证明生物学抑制完整。若 `V_b = P_b`，分母为零、归一化无定义；较小的对照窗口会
放大噪声。
[Data Standardization for Results Management](https://www.ncbi.nlm.nih.gov/books/NBK91993/)
讨论了方向明确的归一化终点及三参数或四参数拟合。

### 技术孔与独立重复回答不同问题

技术孔在一次运行内重复同一样本或制备物；它们量化运行内变异，却是依赖观测。独立重复使用已声明
变异来源上的不同制备物，例如细胞群、靶标批次或样本批次。同一来源在另一日运行可能属于运行间重复。
报告来源、板、运行和聚合规则，而不是只写“n = 6”；六个技术孔不是六个独立制备物。
[Basic Guidelines for Reporting Non-Clinical Data](https://www.ncbi.nlm.nih.gov/books/NBK550206/)
区分技术重复、独立重复和运行间重复的标签。

## 浓度反应曲线将反应定位于一个测定内

对于上升反应，横轴使用 `log10(x in mol/L)`，其中 `x` 是浓度，纵轴使用归一化反应 `y`，例如 % 刺激：

`y(x) = Bottom + (Top - Bottom) / (1 + (EC50 / x)^Hill)`。

对于这里陈述的上升和下降方向，取 `x > 0`、`Hill > 0` 且 `Top > Bottom`。

`Bottom` 与 `Top` 是拟合反应的下、上渐近线。`Hill` 是无量纲陡峭度；`EC50` 是
`(Top + Bottom) / 2` 处的 `x`。若将抑制实验画成下降曲线，应将纵轴定义为
`y = % residual activity = 100 - % inhibition`，再使用
`y(x) = Bottom + (Top - Bottom) / (1 + (x / IC50)^Hill)`。随 `x` 增大，这个 `y` 下降而
`% inhibition` 上升。`IC50` 处，`y` 是拟合中点，`% inhibition` 是 `100 - y`；只有中点为 50% 时，
抑制才为 50%。这是 relative `IC50`（拟合范围的一半）；当拟合渐近线不同于对照定义的 0% 和 100%
端点时，它不一定是 absolute 的 50%-of-control 抑制。下面的构造示例使用关于 50% 对称的端点，因而
隐藏了此区别。不能悄悄固定拟合渐近线或 `Hill`。

`EC50` 和 `IC50` 是这些条件下的曲线位置，不是 `Kd`、`Ki` 或疗效。`Top - Bottom` 是拟合测定范围，
不是机体或临床疗效。`Hill` 描述形状，不是结合化学计量或单一机制。

## 推导案例：先归一化，再解释

本案例全部为**构造的教学内容**；它不报告测定、化合物、靶标或给药。虚构原始信号 `B = 10`、
`V = 110`、`P = 30` 和 `R = 70` 给出 `R_b = 60`、`V_b = 100`、`P_b = 20`，以及
`% inhibition = 100 * (100 - 60) / (100 - 20) = 50%`：测试孔位于这些已声明对照的中点。

虚构下降拟合将 `y` 作为剩余活性，具有 `Top = 98%`、`Bottom = 2%`、`IC50 = 0.40 µM` 和 `Hill = 1.2`。
在 `0.40 µM`，`y = (98 + 2) / 2 = 50%` 剩余活性，抑制为 50%。在虚构的非中点 `x = 0.80 µM`，
`y = 2 + (98 - 2) / (1 + (0.80 / 0.40)^1.2) = 31.1%` 剩余活性，所以 `% inhibition = 68.9%`。
增大 `x` 降低了剩余活性、提高了抑制。范围为 `98 - 2 = 96` 个百分点。这些虚构数值既不是 `Ki` 也不是 `Kd`，
且不证明疗效。

## 干扰、反筛与正交证据

表观信号可以反映生物学、报告酶抑制、光学效应、聚集或其他测量相互作用。反筛测试已命名的替代解释，
例如检测器或报告器干扰；阴性结果不支持该替代解释，却不证明生物学。正交测定保留相关生物学而改变检测。
一致结果支持检测独立性，不单独支持分子机制主张。
[Interferences with Luciferase Reporter Enzymes](https://www.ncbi.nlm.nih.gov/books/NBK374281/)
解释了为何反筛用于剔除干扰，而正交结果本身不证明机制。

## 独立练习

在一个未见的**构造**抑制板上，`B = 8`、`V = 108`、`P = 28`，且 `R = 68`；下降曲线为
`Top = 96%`、`Bottom = 4%`、`IC50 = 0.80 µM` 和 `Hill = 0.9`，其中 `y` 定义为剩余活性。计算归一化抑制，
再计算 `IC50` 处和 `x = 1.60 µM` 处的 `y` 与 `% inhibition`。说明随 `x` 增大哪个量上升，指出 `IC50`
不能确立的一件事，再解释一个在直接报告器反筛中有活性的命中。正交测定会增加什么？

<details data-worked-answer>
<summary>参考答案</summary>

`R_b = 60`、`V_b = 100` 和 `P_b = 20`，所以 `% inhibition = 100 *
(100 - 60) / (100 - 20) = 50%`。`IC50` 处，`y = (96 + 4) / 2 = 50%` 剩余活性，抑制为 50%。在 `1.60 µM`，
`y = 4 + (96 - 4) / (1 + (1.60 / 0.80)^0.9) = 36.1%` 剩余活性，所以抑制为 63.9%。因此，增大 `x` 会降低
`y` 而提高抑制。`IC50` 不能确立 `Kd`、`Ki`、靶标结合或疗效。直接报告器反筛中的活性支持报告器/检测干扰，
而不支持靶标机制主张，却不证明没有生物学。正交测定检验信号在检测改变后是否保留。

</details>
