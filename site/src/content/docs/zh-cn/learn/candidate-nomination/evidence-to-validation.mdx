## 开始之前

先读[候选项提名导论](/zh-cn/learn/candidate-nomination/capstone/)和
[测定对照课程](/zh-cn/learn/drug-discovery-foundations/assay-controls-dose-response/)。
本研究规划练习训练如何选择能够改变主张的观察。它不是可执行实验、湿实验操作规程、
候选项提名或治疗建议，不需要安装、下载数据或 GPU。例题中的化合物、测量和决策全部为编造。

完成后，你应能区分预测、测量、靶标结合和机制，为结果写出竞争解释，并说明后续的阳性、
阴性及无法解释的结果如何改变下一步决策。

## 从决策出发，而不是从模型评分出发

假设模型针对一个与靶点相关的细胞终点，将化合物 B 排在 A 前面。眼前的问题是：
在明确的细胞语境下，两者是否值得进入机制研究，而不是 B 是否已经成为药物候选项。
模型评分只能在其终点和适用范围内帮助安排测量，不能补齐选择性、暴露或安全性证据。

可以先读已有的[跨测定预测失效案例](/zh-cn/learn/evaluation-and-reproducibility/assay-shift-diagnosis/)。
其中的迁移失败没有确定生物学原因，却阻止我们把主测定中的排名当作普遍可靠的活性模型。
本课不使用那些已经暴露的评估标签进行新拟合或模型选择。

把拟议主张写成因果句：“B 在语境 C 中通过靶点 T 改变终点 Y。”这样可以看清三条关系：
B 能到达并结合 T；改变 T 会改变 Y；以及测得的信号在 C 中确实代表 Y。
一个看起来合理的结构预测或终点相关性不能同时确立这三条关系。

## 让不同观察承担不同任务

[SGC 化学工具说明](https://www.thesgc.org/chemical-tools)区分了靶点导向的化学探针和更广泛的
化学工具集合，并强调选择性及合适的对照。因此，已命名探针是一种具有明确证据范围的试剂，
不是对使用它后出现的所有表型的自动验证。

针对本课编造的报告系统案例，考虑三种可以并存的解释：

| 解释                                 | 有助于区分它的观察                                                 | 该观察仍不能确立什么                       |
| ------------------------------------ | ------------------------------------------------------------------ | ------------------------------------------ |
| 与靶点相关的生物学改变了 Y           | 经适当验证的靶标结合读出，加上具有生物学相关性、检测方式独立的终点 | 结合本身不说明 T 介导了表型                |
| B 改变报告系统或检测信号             | 匹配的检测干扰对照                                                 | 有干扰不排除同时存在生物学活性             |
| 贡献信号的活细胞减少，导致总信号下降 | 独立验证且与终点时间匹配的活细胞测量                               | 细胞减少不能确定原因，也不能证明治疗选择性 |

正交测定用不同测量方法考察预期生物学；反筛查考察信号的竞争来源。两者不能互换，
仅仅重复原测定也不等同于其中任何一种。即使正交结果一致，本身也不能确立预期机制。
这些区分依据 [Assay Guidance Manual 的报告系统干扰讨论](https://www.ncbi.nlm.nih.gov/books/NBK374281/)。

所选正交测量应针对当前问题表征过自身灵敏度、动态范围和失败模式。
不敏感的后续测量不能把缺失信号变成“生物学不存在”的证据。同样，对照化合物必须在
所测语境中有解释价值，而不能仅凭目录中的“阴性对照”标签。

## 例题：更大的信号下降是否提供更多信息？

假设一个教学模型：总报告信号 `S = N × r`，其中 `N` 是贡献信号的活细胞数，
`r` 是每个此类细胞的平均报告信号。假定检测线性、背景校正可比、采样时间匹配。
将两列分别按其溶剂对照值归一化。这些假设使下列算术成立，但真实测定不保证满足它们。

| 编造的条件 | 相对总报告信号 | 相对活细胞数 |
| ---------- | -------------: | -----------: |
| 溶剂对照   |            100 |          100 |
| A          |             72 |           90 |
| B          |             44 |           55 |

A 的原始信号下降为 28%，B 为 56%。在所述模型下，相对每细胞信号为
`(S / 100) / (N / 100)`：A 为 `0.72 / 0.90 = 0.80`，B 为
`0.44 / 0.55 = 0.80`。因此，B 更大的总信号下降并不说明更大的每细胞效应。
即使完全没有靶点特异机制，同样的计算也可以成立。

这是针对某个推断的反例，不是推荐的归一化流程。除以有噪声或受处理影响的细胞数，
可能改变估计目标并引入新问题。不能事后用此比值修补失败终点，再将其报告为预先规定的结果。

### 有边界的下一步决策

教学数据使细胞数贡献和每细胞信号变化都值得关注。一种有用的拟议后续工作，是将
经过验证、采用不同检测方式的预期终点测量，与语境匹配的检测干扰对照结合，同时保留
细胞数信息。只重复模型排名不能区分三种解释。如果原始测量系统尚未经过验证，应先
解决这一点；这不是适用于所有项目的通用顺序。

在获得新结果之前，约定不同分支的含义：

- 如果独立终点不变，而干扰对照复现了信号变化，不应再用原报告系统支持靶点介导的
  生物学。还需检查独立测量是否有能力检测拟议效应。
- 如果终点改变，且没有所测试的干扰，也没有相应的活细胞减少，这支持存在生物学反应。
  要支持因果主张，仍需靶标结合证据，以及另一个检验靶点依赖性的干预。
- 如果对照失效，或测量分歧超出其已表征的不确定性，应保留“尚无法解释”的结果。
  它既不是确认命中，也不是无活性的证明。

这些是拟议解释，不是实验观察。效应阈值、精度、样本量、分配和排除规则，需要真实测定的
验证数据与项目特定方案，不能从教学表格中编造。技术孔可以表征测量变化，不能替代
独立的生物学制备。

## 独立练习

第二张编造表格中，A 的报告信号为 60、活细胞数为 75；B 为 72 和 90；C 为 72 和 100。
溶剂对照仍为 100 和 100。在相同教学假设下，计算三者的相对每细胞信号。
你能提名 C 吗？写出一种能够削弱其靶点介导解释的后续观察，并区分
“停止这一解释”与“放弃该化合物”。

A 和 B 都为 0.80，C 为 0.72。C 在本编造例题中的每细胞下降更大，但仍没有证据说明
该下降代表预期生物学、涉及 T、具有选择性或能够获得有用的暴露。因此，这项计算不能提名 C。

例如，一个有效干扰对照复现了 C 的信号变化，同时灵敏度足够的正交终点没有改变，
就会削弱基于报告系统的靶点主张。这不能证明 C 没有生物学活性。
应停止把该信号当作机制证据；是否进一步表征 C，是关于项目问题和资源的另一项决策。
反过来，独立终点的反应也不足以宣布 T 具有因果作用。还应说明缺少哪些结合和靶点依赖性证据。

## 去检查一份真实档案里的反证

上面的论证接受起来比实践起来容易，因为压力永远指向"报告那个成功了的比较"。
本仓库自己已完成的实验两个都留了下来。[反证档案实验](/zh-cn/labs/counterevidence-dossier/)
用一条离线命令清点这些产物中保留的六类反证，
并重算那个"在一个评估上误差最低的模型，在另一个评估上是基线误差数倍"的案例。

## 研究组会交付物

写一页决策备忘录，而不是综合“候选质量”评分。说明候选项、终点与语境；
将测量值和预测分开；指出主要替代解释；描述具有区分力的测量及对照；预先写下会使你
改变方向的结果。让未知的选择性、暴露和安全性保持可见，而不是填入零或有利猜测。
参见 [PK/PD 课程](/zh-cn/learn/admet-pk/exposure-clearance-pkpd/)，理解为何浓度或效力数值
不能替代暴露论证。

作为读者练习，完整答案应将每项拟议观察连接到一个决策，并解释一项仍存在的歧义。
只有测定名称、缺少这些关系的清单是不完整的。这只能评估书面推理；本课尚未收集
学习者结果，也未完成实验验证。
