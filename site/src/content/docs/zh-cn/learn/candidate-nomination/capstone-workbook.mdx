## 你将交付什么

这是书面综合练习，不是可运行实验。先完成[核心路径](/zh-cn/learn/foundations/curriculum-map/)
和各案例链接的专题章节。只需纸笔或文本编辑器及计算器，不需要下载数据、GPU 或实验室。
下文所有实体、测量和阈值均为**教学构造**，不是实际候选推荐。

每个案例都应先写短备忘录，再展开答案。明确决策单位与总体，展示关键计算，指出最强替代解释，并选择一项能改变下一步决策的观测。
区分表格建立了什么、哪些仍未知。“继续表征”或“不提名”可以是好答案，不必选出赢家。
本练习评价推理，不是评价是否认同隐藏排名。

## 案例 1：跨生物语境的靶点证据

准备：[遗传学到靶点证据](/zh-cn/learn/mechanism-targets/genetics-to-target-evidence/)
和[从扰动到靶点验证](/zh-cn/learn/mechanism-targets/perturbation-to-target-validation/)。

虚构项目询问：降低靶点 T 是否值得进入疾病语境验证？
某区域存在遗传关联，但现有材料没有识别效应基因或因果方向。
一次扰动得到如下相对匹配对照的表型差异，越负越符合预期方向：

| 独立供体 | 疾病相关细胞 | 参考语境细胞 |
| -------- | ------------ | ------------ |
| D1       | −4           | −1           |
| D2       | −6           | −2           |
| D3       | −2           | −1           |

单位是任意表型单位。同三个供体贡献两种语境，每个供体值已汇总技术观测。
未提供靶点结合、细胞活力或独立于扰动的检测对照。关联区域内另一个基因 U 尚未测试。

计算疾病语境平均效应，以及“疾病减参考”的配对平均差异。
能否声称人类遗传学验证了抑制 T？提出一个有边界的问题，区分 T 依赖表型与测量效应或非特异细胞状态变化。
交付靶点证据备忘录，保留遗传歧义与独立单位数量少的事实。

<details data-worked-answer>
<summary>案例 1 答案：只有建立连接，证据才真正汇合</summary>

疾病均值为 `(-4−6−2)/3=−4`。
配对差异为 `[-3,−4,−1]`，平均 `−8/3≈−2.67`。
独立单位是三个供体，不是六个独立语境值，也不是技术孔数。
表格支持该构造样本中的语境依赖模式，但没有提供不确定性估计或经过验证的测量桥梁。不要编造 p 值。

区域关联未识别 T，也未证明降低 T 活性具有保护作用，应保留 U 和其他效应解释。
有用的下一问是：采用能够建立 T 依赖性的干预时，经适当验证的独立表型测量是否仍保留该差异，同时考虑活力与检测干扰？
确切测定与样本量需要真实验证数据；备忘录不是实验操作程序。
推进的是待验证问题，不是把 T 宣布为“遗传验证的药物靶点”。

</details>

迁移练习：第四个供体的疾病效应为 +2，参考效应为 0。重算两个均值，并修改备忘录中的一句话。

<details data-worked-answer>
<summary>迁移答案</summary>

疾病均值变为 `(-4−6−2+2)/4=−2.5`；配对均值变为 `(-3−4−1+2)/4=−1.5`。
应说明四个供体之间方向不一致，不要因为第四个供体削弱叙述就将其删除。

</details>

## 案例 2：不能据此宣称可靠迁移的性质模型

准备：[化学系列与适用域](/zh-cn/learn/qsar-properties/chemical-series-and-domains/)、
[不确定性与决策](/zh-cn/learn/qsar-properties/uncertainty-to-decisions/)，以及
已有[测定迁移诊断](/zh-cn/learn/evaluation-and-reproducibility/assay-shift-diagnosis/)。

以下是独立构造例子，不替代已有实验结果。
描述符模型仅使用来源测定的验证数据完成选择。
对四个目标测定化合物，给出其冻结预测与冻结训练均值预测。
全部数值使用同一声明的对数终点，但测定条件不同。训练均值预测每行均为 6.0。

| 化合物 | 目标测定观测 | 描述符预测 |
| ------ | ------------ | ---------- |
| P1     | 5.0          | 5.2        |
| P2     | 6.0          | 5.8        |
| P3     | 7.0          | 6.8        |
| P4     | 8.0          | 6.0        |

计算两者 MAE。若 P4 是其系列唯一代表，且位于模型预先声明的适用域警报之外，能否从主要结果中删除？
写一段复现范围说明，区分重算这些误差与复现拟合、来源数据和迁移过程。

<details data-worked-answer>
<summary>案例 2 答案：完整结果与亚组诊断承担不同角色</summary>

描述符绝对误差为 `[0.2,0.2,0.2,2.0]`，MAE 为 0.65。
训练均值误差为 `[1,0,1,2]`，MAE 为 1.0。
描述符在该教学总体上改善 0.35，但 P4 的误差仍是 2.0。
适用域警报提示限制，不授权根据结局删除数据。声明任务若包含 P4，就应保留。
可单独报告三个化合物的域内亚组，不能替换主要总体。

“从提供的冻结预测重算指标”有依据。“复现训练”需要实际拟合过程和输入，不能仅凭相同 MAE。
四行数据也不能建立普遍迁移可靠性或其不确定性。
有代表性的目标测定评价或独立验证的测定桥梁，解决的问题不同于对已暴露的四行拟合更大模型。

</details>

迁移练习：有记录的来源更正将 P4 改为 9.0，预测不变。重算 MAE，并说明什么改变了。

<details data-worked-answer>
<summary>迁移答案</summary>

描述符 MAE 为 `(0.2+0.2+0.2+3)/4=0.9`；训练均值 MAE 为 `(1+0+1+3)/4=1.25`。
差异仍为 0.35，但两者绝对误差改变。这是评价输入更正，不是新拟合模型。
应记录来源更正，并保留总体身份。

</details>

## 案例 3：结构筛选不把分数当亲和力

准备：[口袋状态与置信度](/zh-cn/learn/structure-and-pockets/pocket-states-and-confidence/)
和[自由能循环与收敛](/zh-cn/learn/physics-based-modeling/free-energy-cycles-and-convergence/)。

两个配体在固定靶点状态筛选中得到如下构造结果：

| 候选 | 对接分数，越低越优 | 姿态检查             | 状态支持         |
| ---- | ------------------ | -------------------- | ---------------- |
| S1   | −9.0               | 严重且未解决的碰撞   | 仅一个预测状态   |
| S2   | −8.0               | 所检查姿态未标出碰撞 | 考虑两个靶点状态 |

该评分不是经实验校准的亲和力尺度，两者都没有实测结合结果。
另有炼金计算把 S1 变为 S2，报告复合物支路变化 +2.0 kcal/mol、溶剂支路 +1.5 kcal/mol。
没有收敛证据或不确定性。约定
`ΔΔGbind=ΔGcomplex−ΔGsolvent`，正值表示模型下 S2 比 S1 更不利。

计算循环差异。它能否解决 S1 的碰撞，或建立 S1 结合更好？
选择下一项计算或测量问题，不要悄悄把对接分数升级为结合自由能。

<details data-worked-answer>
<summary>案例 3 答案：协调排名前先检查假设</summary>

循环差异为 `2.0−1.5=+0.5 kcal/mol`。
在指定模型与符号约定下偏好 S1，但缺少收敛和不确定性，无法判断这个小差异是否被分辨。
该计算不能修复严重姿态问题，也不能证明热力学状态正确。
不同评分函数可能不一致，而两者都不是实测亲和力。

S1 的结构假设需要修订或论证，才能支撑可信能量比较。
S2 已列出的姿态异议较少，不等于证明结合。
有信息量的下一步可以检查所比较状态的物理一致性与采样，或对指定构建体和条件获得有效结合测量。
选择取决于哪项输入假设可以解决；不能从此表提名任何候选。

</details>

迁移练习：溶剂支路改为 +2.5 kcal/mol，其他限制不变。哪些结论改变，哪些不变？

<details data-worked-answer>
<summary>迁移答案</summary>

差异变为 −0.5 kcal/mol，模型偏好反转为 S2。
收敛、不确定性、有效状态定义及实验结合证据的缺失不变。计算符号反转不会消除这些限制。

</details>

## 案例 4：选择可行批次并核算失败

准备：[流模型与约束搜索](/zh-cn/learn/molecular-generation/flows-and-constrained-search/)
和[采集、延迟与停止](/zh-cn/learn/active-learning/acquisition-delays-and-stopping/)。

虚构项目有 4 单位尝试预算，最多两个同时进行的槽位。
目标是即时、可相加的预期确认命中数，而非信息增益。
为此例假定候选概率已校准。合成审查已固定纳入资格，不提供操作配方。

| 候选 | 预期命中概率 | 尝试成本 | 是否合格           |
| ---- | ------------ | -------- | ------------------ |
| A    | 0.80         | 3        | 是                 |
| B    | 0.60         | 2        | 是                 |
| C    | 0.55         | 2        | 是                 |
| D    | 0.95         | 1        | 否，原料约束未解决 |

枚举可行的单个及双候选选择，最大化声明的预期命中数。
随后假设一个选中候选返回有效阴性，另一个测量失败，均消耗全部尝试成本。
报告预算和结果，不把失败当作生物阴性。

<details data-worked-answer>
<summary>案例 4 答案：求解声明的受约束目标</summary>

可行非空选择为 A、B、C 和 B+C。A+B、A+C 成本为 5，超过预算；D 不合格。
对应预期命中数为 0.80、0.60、0.55、1.15，所以 B+C 在成本 4 下最优。
期望可相加不要求结局独立，但对于“至少命中一个的概率”等其他目标，依赖关系就很重要。

实际批次消耗 4 成本单位，得到一个有效阴性和一个测量失败，确认命中为零。
它只有一个可解释活性标签，不是两个阴性。
重试需要声明规则下的预算和资格，不能悄悄增加某个策略的预算。
一次实现较差的批次，本身不推翻期望值计算；校准假设是题目给定的，不是这两个结果建立的。

</details>

迁移练习：预算增加到 5，容量仍为两个。哪个合格选择现在最大化预期命中？

<details data-worked-answer>
<summary>迁移答案</summary>

A+B 成本 5，预期命中 1.40，高于 A+C 的 1.35 和 B+C 的 1.15。
D 仍不合格。资源变化可以改变最优解，无需改变候选概率。

</details>

## 案例 5：存在缺失要求的跨领域提名

准备：[产品概况](/zh-cn/learn/drug-discovery-foundations/product-profile-and-series/)、
[从代谢到安全性](/zh-cn/learn/admet-pk/metabolism-to-safety/)
和[证据到验证](/zh-cn/learn/candidate-nomination/evidence-to-validation/)。

虚构项目规定以下**纯教学阈值**：匹配效力不超过 50 nM，选择性比至少 20，指定暴露/有效浓度比至少 3。
还要求独立审查的安全性材料和可解释功能验证。
这些比值已按项目声明的兼容单位和语境预计算，不是普遍药理标准。

| 候选 | 效力，nM | 选择性比 | 暴露比 | 必需安全性材料 | 功能验证 |
| ---- | -------- | -------- | ------ | -------------- | -------- |
| N1   | 20       | 8        | 4      | 可供审查       | 可解释   |
| N2   | 40       | 30       | 2      | 可供审查       | 可解释   |
| N3   | 45       | 25       | 3.5    | 缺失           | 可解释   |

哪些候选满足数值阈值？是否有候选满足完整提名要求？
写下一步决策备忘录，区分修改候选、补证据缺口与改变产品概况。
解释为什么跨列平均排名不能抹去缺失安全性要求。

<details data-worked-answer>
<summary>案例 5 答案：没有候选满足提供的完整要求</summary>

N1 选择性不达标，N2 暴露不达标，N3 通过三个数值阈值但缺少必需安全性材料。
“可供审查”也不等于审查结论有利。仅凭此表，不能声明任何候选满足完整要求。

N3 可值得补齐指定证据缺口，但信息缺失既不证明安全，也不证明危险。
N1、N2 可引出单独评价的优化问题。为让偏好候选过关而修改阈值，是改变项目要求，不是发现。
有科学依据的概况修订可以合法合理，但应明确决策并独立评价，不能将其包装为原概况下的成功。

平均排名在构造上允许良好效力补偿任何其他列，但这不是题目规定的含必需条件的决策规则。
应保留跨领域取舍与未解决审查，不要压成没有依据的标量。

</details>

迁移练习：N3 的材料补齐，并通过定义的审查。该教学表现在是否意味着临床有效，或有权给人用药？

<details data-worked-answer>
<summary>迁移答案</summary>

若其他证据仍有效、责任决策者接受，它可以满足该虚构项目声明的提名输入。
这不建立临床疗效、监管授权或人体给药许可；那些属于不同证据和权限问题。

</details>

有一个实验在执行本案例的规则。[跨域权衡实验](/zh-cn/labs/crossdomain-tradeoff/)把工作簿自己的
规则跑两遍:在三个教学候选上,算出来的答案就是上面那个答案;在带至少两个实测终点族的
58 个真实 ChEMBL 母体上,这条规则根本提不出来——因为队列里最充裕的族(体外内在清除与
CYP 抑制)并不是这条规则要的输入。那 58 个候选全部在效价输入处被阻断,没有一个完成提名。
这与[终点覆盖实验](/zh-cn/labs/multi-endpoint-tradeoff/)所说的不是同一件事:哪些族存在
的普查不是决策,而决策所需的输入可能缺失,它不需要的族却很多。

## 治理与交接

负责任研究不止于正确计算。
[WHO 生命科学治理框架概览](https://www.who.int/publications/i/item/9789240056107)
将生物风险缓解和双重用途治理描述为贯穿研究生命周期的共同责任。
本教程的边界很具体：案例不授权合成、生物干预、人体研究、受限数据访问或公开发布他人资产。

工具提出序列、返回模拟测定值或报告任务完成，并未独立建立实验观测。
交接时应说明实际执行了什么、存在什么产物或测量，以及支持什么解释。
模拟值仍是模拟值，排队实验仍待完成。
人工审查应处理工具无法建立的科学、安全和权限判断。

若扩展可能增强有害生物能力或涉及受限材料，应暂停该扩展，交由适当机构审查，不把教程转成操作指南。
独立安全的文献推理和普通来源阅读可以继续。
数据复用按[身份、来源与权限](/zh-cn/learn/data-governance/identity-lineage-and-reuse/)检查实际条款，而不是只看仓库公开可见。

## 评价标准与最终作业

提交五份短备忘录和一页综合总结。
总结应指出一个跨案例失效的假设、一项被保留的负面或缺失结果，以及一项比再加一个模型分数更有价值的下一观测。
评价者可对每份备忘录使用下表；它是教学评分规则，不是经过验证的学习效果测量工具：

| 维度       | 0                  | 1                  | 2                          |
| ---------- | ------------------ | ------------------ | -------------------------- |
| 决策与总体 | 未指定或被更改     | 部分说明           | 保留确切单位、总体和决策   |
| 计算       | 缺失或实质错误     | 大致正确但有遗漏   | 数值、方向与单位正确       |
| 解释       | 过度主张           | 泛泛限制           | 明确替代解释与缺失连接     |
| 下一观测   | 重复分数或改变任务 | 相关但不能区分解释 | 在明确结局下可改变指定决策 |

每案例最高 8 分，五案例共 40 分。总和算对不能弥补虚构证据。
在视作完成前，修订所有无依据的经验、因果或安全性主张。此处尚未收集读者分数。

[候选证据链实验](/zh-cn/labs/candidate-evidence-chain/)把一个化合物自己的测量连成一条链，
并报告第一个没有被测量的环节。

[主张链审计](/zh-cn/labs/claim-chain-audit/)检验一份提名备忘里点名的每一条证据链节是否支撑其范围，
并报告它审计的每条链里最弱的一环。

之后开展实测练习时，返回[notebook 使用指南](/zh-cn/labs/notebook-guide/)，选择数据和协议与问题匹配的已有练习。
不要把这些手算案例称为五项新复现实验。
