**分子能量模型预测的是已声明的状态，而不是抽象意义上的“一个分子”。** 本课的状态指一个具名分子体系的原子身份和一组笛卡尔几何坐标。这个边界使输入、划分、基线和结论均可检查。本课不是力场基准，不证明跨体系泛化，也不能替代实验决策。

## 预备知识

先阅读[从对接到 FEP](/zh-cn/learn/physics-based-modeling/docking-to-fep/)、[数据契约](/zh-cn/learn/data-governance/data-contracts/)和[科学机器学习](/zh-cn/learn/machine-learning/scientific-computing/)。你应能区分输入数组与目标、验证集上的选择与评估结果，以及重复测量与独立单位。

## 学习目标

完成本课后，你应能够：

1. 定义一行分子状态、其单位，以及能量基线允许使用的数组；
2. 复现稳定的原始索引选择，而不把有序误当成独立；
3. 构造具有平移和旋转不变性的元素对距离表示，并说明它丢失的信息；
4. 审查仅训练集预处理和跨分子体系共享的验证选择；
5. 区分两个开发体系与两个后续评估体系，不把相关帧当成独立重复。

## 状态组成与观测变量

来源是 [revised MD17（rMD17）Figshare 第 4 版记录](https://doi.org/10.6084/m9.figshare.12672038.v4)，更新于 2026-02-28。它包含具名分子体系的轨迹。一个帧是同一体系的一次重复构型，不是新分子，也不是独立的泛化单位。

| 角色                 | 观测变量                               | 解释                                     |
| -------------------- | -------------------------------------- | ---------------------------------------- |
| 体系身份             | 具名分子                               | 定义独立分子体系的上下文。               |
| 原子组成             | `nuclear_charges`                      | 标识元素类型和可用的元素对通道。         |
| 几何                 | `coords`                               | 单帧的笛卡尔构型。                       |
| 能量目标             | `energies`                             | 基线使用的唯一目标。                     |
| 仅作完整性检查的数组 | `forces`, `old_energies`, `old_forces` | 检查数据结构完整性，绝不作为特征或目标。 |
| 可追溯性             | `old_indices`                          | 保留采样所用的来源轨迹顺序。             |

四体系协议包含乙醇、丙二醛、苯和尿嘧啶。只有乙醇和丙二醛是开发体系。苯和尿嘧啶在 alpha 冻结后完成了配对评估。来源标签公开，因此一次性边界依赖流程约束，而不是标签保密。

## NPZ 数据与单位契约

每个真实开发输入包含 100,000 帧。NPZ 契约要求 `nuclear_charges`、`coords`、`energies`、`forces`、`old_indices`、`old_energies` 和 `old_forces`。坐标单位为 Angstrom，能量为 kcal/mol，力为 kcal/mol/Angstrom。形状必须一致：每个坐标帧对应一个能量和一个力切片，`nuclear_charges` 描述该体系所有帧共享的原子。

模型有意限定为仅预测能量。特征只能使用 `nuclear_charges` 和 `coords`；`forces`、`old_energies`、`old_forces` 不能用作辅助监督、正则项、归一化输入或事后标签。如果流水线读取了禁止的数组，教学比较就已改变，原有结果不再适用。

第 4 版记录为数据集文件和记录元数据声明 CC0。这个证据不会把许可转移给本课、软件、模型或其他独立资产，也不建立训练代码、权重、架构、数据准备或评估代码的访问与开放性结论。

## 原始索引顺序与嵌套依赖

协议对 `old_indices` 做稳定升序排序，再用 `rint(linspace(0, n_frames - 1, 1000)).astype(int64)` 选择 1,000 个秩位置。在这个有序样本中，前 600 帧用于训练，随后 200 帧用于验证，最后 200 帧用于评估，即 600/200/200 划分。该步骤产生确定且可检查的顺序，协议随后拒绝非递增的选中索引。它不会使帧独立，也不会消除时间相关性。

本课不使用来源提供的五对 train/test CSV。来源记录说明其中包含划分索引，但没有说明这些索引代表时间顺序、如何映射到第 4 版 NPZ 行，也没有使其成为独立分子体系单位。因此不能用这些文件悄悄替换已声明的 `old_indices` 流程。

分子动力学帧在时间上相关，并嵌套于分子体系。对于跨体系结论，相关的独立单位是体系，而不是帧、直方图区间、随机种子或重复拟合。当前开发观测只有 n=2 个体系。因此不要合并帧残差来计算置信区间，也不要把两个体系内结果提升为总体推断。

公开摘要只报告汇总后的分区数量以及顺序和间隔诊断，不公开成员数组、来源位置、目标或预测。这种删减避免教学页面变成另一份不受控的证据存储。

## 不变表示及其限制

对每个体系，按字典序枚举无序元素对通道。逐帧计算各通道的原子对距离，将其划入 0 到 10 Angstrom 的 100 个区间及一个溢出区间，再除以该通道固定的原子对数量进行归一化。乙醇有五个通道、505 维；丙二醛有六个通道、606 维。这种差异符合预期，因为两个体系的元素对组成不同。

成对距离使该表示对平移、旋转和同元素原子置换不变。对于固定几何下的标量能量，这些不变性是合适的。但它们不会使表示在区间边界连续，不会带来力的等变性，也不会让表示感知已声明元素对以外的原子身份，或使其适合充当力场表示。溢出区间还把超出范围的所有距离压缩为一个特征。这些是科学选择，不是无关紧要的实现细节。

## 仅训练集拟合与共享 alpha 选择

对照是每个体系的训练能量均值。学习模型在各分子体系内分别拟合：`StandardScaler` 只在训练特征上拟合，目标减去训练能量均值，Ridge 使用冻结的特征矩阵。验证和评估帧绝不用于拟合 scaler、目标中心、特征统计量或系数。

正则化参数只在两个开发体系间选择一次。对每个冻结的 alpha，计算各体系的验证 MAE，再取中位数并选择最优值；完全并列时选择较大的 alpha。这不是两次独立的超参数搜索，而是在查看评估行前应用的一条共享选择规则。

## 体系层面评估与开发边界

分别报告各体系的 MAE、RMSE 和目标范围，再描述两个体系 MAE 的中位数。已复核结果显示，两个开发体系中 Ridge 的误差均低于训练均值对照。这是在该表示与划分下的开发观测，不是 SOTA 结论，不证明该特征是物理势，也不证明它能泛化到苯、尿嘧啶、其他分子、其他轨迹或实验终点。

苯和尿嘧啶的已完成指标现已收录于配套实验。Ridge 在各体系中均优于训练均值对照，但它使用了该体系自己的训练帧拟合，因此不是零样本迁移。两项结果仍是描述性的。原始运行未保留逐帧 Ridge 预测，所以运行后只重算了对照分数和目标范围。不要重新调参，也不要将该限制改写成“全部结果已独立重算”。

## 配套实验与运行命令

[rMD17 体系状态能量基线实验](/zh-cn/labs/rmd17-system-state-energy-baselines/)是本课的配套入口，分别保留开发证据、已完成的评估分数、参考答案和评分标准。

在全新工作区复现时，从仓库根目录开始开发流程：

```bash
uv run python labs/rmd17_system_state/run_lab.py validate-protocol
uv run python labs/rmd17_system_state/run_lab.py download-development
uv run python labs/rmd17_system_state/run_lab.py pretest
```

第一个命令检查冻结契约，第二个只获取两个开发体系，第三个运行开发预检并写出公开汇总。它们都不授权或启动配对锁定评估。已经完成运行的作者工作区拒绝新的预检或评估，应查看已交付摘要。不要用改变输入、分区、alpha 选择或公开摘要边界的捷径替换此流程。

## 练习

1. 列出刚体平移、原子索引置换和新构象分别会改变哪些变量，并说明每种情况下直方图是否应保持不变。
2. 画出从帧到分子体系的依赖图，标出哪些节点可影响预处理、alpha 选择和最终结论。
3. 提出一种可能改善力预测任务的表示修改，解释为什么它定义了不同的教学协议，而不是当前能量结果的公平扩展。
4. 两个 alpha 的验证分数中位数完全相同时，不读取评估指标，直接应用冻结的并列规则。

## 失败门槛与局限

出现以下情况应停止，而不是重新解释结果：

- NPZ 键、形状、单位或有限值检查失败；
- 禁止使用的力或历史标签数组进入特征或目标路径；
- 选中秩、分区数量或全局原始索引顺序偏离冻结契约；
- scaler、目标中心或 Ridge 系数在拟合时接触验证或评估行；
- alpha 选择因体系而异，或在观察评估行后被更改；
- 报告合并帧、给出基于帧的置信区间，或把 n=2 的开发结果称作跨体系泛化。

成对距离直方图是一种有意保持低成本的不变基线。它在区间边界不连续，丢失角度和高阶结构，也不建模力的等变性。时间有序划分有助于审查泄漏，但不能替代分子体系留出研究。
