## 学习目标与前置知识

学完[生物大分子构建体身份与评估目标](/zh-cn/learn/biologics-design/construct-identity-and-objectives/)后，本课讨论一个更具体的问题。你将识别可以留出的独立单元，追踪参差不齐的镜像记录如何形成可测量子集，并判断表格分数能支持什么结论。本课解读已冻结的[亲和力表实验指南](/zh-cn/labs/skempi-affinity/)。实验模式、命令、缓存行为和可复现输出均以指南为准。本课不代替该指南。[英文原版](/learn/biologics-design/affinity-table-independent-unit/)是规范版本。

## 行与独立单元

实验的冻结摘要记录了7085行源记录和348个不同的复合物。一行是一条记录，对于推广到未见复合物的结论，复合物才是独立单元。多行可以共用一个复合物、一个蛋白质对或一个突变。如果逐行计算区间并把这些重复记录视为独立观测，所得区间就会比证据所支持的更窄。仅AB/AG类就有830行，但只有51个复合物。其中最大的五个复合物贡献347行。这些是源表计数，不是独立重复的计数。[实验指南](/zh-cn/labs/skempi-affinity/)。

## 参差不齐记录的按位对齐

[镜像](https://huggingface.co/datasets/LiteFold/SKEMPI2)在每条JSONL记录内保存以分号分隔的主值。各主值的字段数并不相同。冻结读取器按字段位置与表头对齐，并在末尾补空字符串。假定每行等宽，可能在没有报错的情况下将值放入错误字段。读取器也不会重构按逗号拆出的溢出片段。因此，解析后的空字段说明这次镜像读取没有得到该字段，不能证明上游测量缺失。[实验指南](/zh-cn/labs/skempi-affinity/)。

| 主值字段数 | 行数 |
| ---: | ---: |
| 2 | 1973 |
| 5 | 62 |
| 6 | 2506 |
| 11 | 57 |
| 27 | 1141 |
| 29 | 1346 |

冻结摘要还记录了5739行带有溢出片段。字段分布和片段计数来自2026-10-21的同一次观察运行。[实验指南](/zh-cn/labs/skempi-affinity/)。

## 完整测量

本次评估要求两个解析后的亲和力值都为有限的正值。摘要在7085行源记录中计得2486对完整值。TCR/pMHC类有560行，却只有2对完整值。把所有行都算作测量对，会改变分析总体，并把读取器没有核实的部分镜像记录当作测量。源记录计数保留这些行，而分割与指标只使用完整测量对。[实验指南](/zh-cn/labs/skempi-affinity/)。

## 留出评估

在AB/AG类中，摘要记录了719行合格的完整测量对。按行分割的诊断将144行放进测试集，其中142行的复合物也出现在训练集。这个诊断揭示了重叠，不能评估向未见复合物的迁移。冻结评估改为留出整个复合物。训练集包含35个复合物和686行，测试集包含9个复合物和33行。测试复合物均不在训练集内。[实验指南](/zh-cn/labs/skempi-affinity/)。

低成本基线仅使用训练集，在每个蛋白质组内取野生型log10(M)亲和力的中位数。未见组使用训练集总体中位数。观测突变体比较项使用测试行中实测的突变体值，因此不是前瞻预测器。冻结摘要给出以下未舍入误差。逐行MAE对行加权，按复合物平均的MAE则让每个测试复合物拥有相同权重。两者都不是不确定性区间。[实验指南](/zh-cn/labs/skempi-affinity/)。

| 比较项 | 测试行MAE，log10(M) | 复合物平均MAE，log10(M) |
| --- | ---: | ---: |
| 训练组中位数 | 1.427417380072399 | 1.6844078536090268 |
| 观测突变体值 | 1.1318877872000341 | 1.5600351451153442 |

## 数据条款

[SKEMPI上游条款](https://life.bsc.es/pid/skempi2/info/terms)将源数据集标为CC BY 4.0。[LiteFold镜像卡片](https://huggingface.co/datasets/LiteFold/SKEMPI2)却将自身许可字段标为other。源数据由上游条款约束。镜像卡片的不同声明应作为来源差异记录，而不能替代上游条款。复用源数据时应注明上游来源。实验的来源审查记录于2026-10-21。[实验指南](/zh-cn/labs/skempi-affinity/)。

## 推演案例

假设一份报告把830行AB/AG记录都称为独立观测，又把按行分割的结果称为未见复合物上的表现。冻结摘要给出的却是该类51个源复合物和719对完整值。最大的五个复合物贡献347行。按行分割的诊断中，144条测试行有142条与训练集共用复合物。可靠的解读应区分行数、完整测量对数和复合物数。对于所声明的评估，应看9个留出的测试复合物，并让不确定性对应复合物而非重复行。这是对[冻结实验结果](/zh-cn/labs/skempi-affinity/)的解释，并非新实验。

## 独立练习

冻结摘要给出TCR/pMHC类560行、37个复合物、2对完整亲和力值。一项分析把每行都当作测量对，并按行计算区间。请指出分析总体和独立单元各有什么错误，再说明镜像审查无法判定什么。

<details data-worked-answer>
<summary>参考答案</summary>

在冻结读取规则下，只有2行有完整测量对，因此560不能作为测量对总体。对于未见复合物的结论，复合物是独立单元，因此560行不能提供560个独立单元。镜像中解析字段缺失，不代表上游记录一定缺少测量，因为主值字段数不齐，溢出片段也未重构。[实验指南](/zh-cn/labs/skempi-affinity/)。

</details>
