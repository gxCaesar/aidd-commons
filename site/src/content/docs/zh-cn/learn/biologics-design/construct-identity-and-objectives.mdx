## 学习目标与前置知识

完成本课后，你应能填写生物大分子药物的模态、构建体、表达系统和预期功能记录。
你还应能把证据归入下文列出的六个评估目标，并指出用一个目标替代另一个目标的错误结论。

请先读[生物制剂与多模态设计](/zh-cn/learn/biologics-design/multimodal-design/)、
[生物学表示](/zh-cn/learn/representations/biological-representations/)和
[口袋状态、置信度与可复用的结构证据](/zh-cn/learn/structure-and-pockets/pocket-states-and-confidence/)。
这些课程介绍生物对象，以及结构模型与观察结果的区别。

**模式：阅读与推理课，无需运行命令。** 本课的对象是公开说明书描述的已批准药物。
练习的产出是书面记录与解释。表达系统仅作为来源报告的身份字段出现。

## 第 1 部分：模态、构建体、表达系统和功能

**模态**表示治疗对象所属的大类。**构建体**说明记录实际描述的是哪一种分子形式。
靶点名称或疾病名称不能确定构建体。**预期功能**说明希望该对象在明确语境中实现的作用。
它与证明该作用发生的证据是两回事。

这些区别适用于不同模态。蛋白记录保留蛋白名称、结构域覆盖范围和组装形式。
多肽记录保留其化学形式。抗体记录保留其形式和链配对，以区分完整抗体与孤立结构域。
核酸记录保留寡核苷酸类别、化学形式和来源报告的分子靶标。多模态记录保留各组分、
它们的关联方式及各自作用。这些类别可以重叠。抗体也是蛋白，多肽也可以带有非肽组分。
仅命名识别组分，无法确定一个组合对象的身份。

对于下文的反义寡核苷酸示例，应记录 RNA 靶标。其他寡核苷酸也可以靶向蛋白。
[2011 年 FDA MACUGEN 说明书第 12.1 节](https://www.accessdata.fda.gov/Drugsatfda_docs/Label/2011/021756s018lbl.Pdf)
报告，pegaptanib 是聚乙二醇化的修饰寡核苷酸适配体，在体外条件下结合胞外 VEGF165。
VEGF165 是血管内皮生长因子这一蛋白的一种异构体。

用下列字段描述现有公开记录。这些字段表示对象的身份，不是分子设计规格。

| 字段               | 应记录的内容                                             | 防止的错误                             |
| ------------------ | -------------------------------------------------------- | -------------------------------------- |
| 记录身份           | 活性成分、产品名称、来源 URL、来源章节和打开日期         | 把产品名称或靶点名称当作完整分子身份   |
| 模态与构建体       | 分子类别、已命名组分、形式或组装状态，以及相关化学形式   | 把完整药物与一个结构域、前体或载体合并 |
| 表达系统及适用范围 | 来源报告的宿主，以及该陈述适用的组分                     | 把组分的来源与药物发挥作用的组织混淆   |
| 预期功能与语境     | 来源报告的分子靶标、结合伙伴或底物、预期作用和生物学环境 | 把识别等同于希望由它产生的后果         |
| 证据状态           | 来源报告的事实、构造的数值、未验证字段或明确不适用的目标 | 用其他字段中的有利结果填补缺失字段     |

表达宿主不能证明最终对象的折叠或功能。若所选来源没有注明宿主，应记为
`unverified in this source`（本来源中未验证）。仅当字段确实不适用，且这一判断
有明确依据时，才使用 `not applicable`（不适用）。仅凭信息缺失不能判断其不适用。

### 推导案例：修正 TNF 阻断剂记录

一条**构造的**目录记录写道：“对象：TNF 阻断剂。模态：抗体。构建体：人蛋白。
表达系统：人的免疫细胞。功能：TNF 结合。”这条记录合并了 ENBREL 和 HUMIRA。
TNF 指肿瘤坏死因子。任务是依据两份说明书恢复各自的对象身份。

**IgG1** 指免疫球蛋白 G 的第 1 亚类，是一种抗体亚类。**Fc** 指可结晶片段
（fragment crystallizable），即由抗体重链配对的恒定结构域形成的尾部区域。
它与识别抗原的可变区不同。这些术语依据[抗体结构参考资料](https://www.ncbi.nlm.nih.gov/books/NBK27144/)。

**公开记录中的事实。** 下表依据
[ENBREL 说明书](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=a002b40c-097d-47a5-957f-7a7b1807af7f)和
[HUMIRA 说明书](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=a06a9aec-fd5b-4c3e-a81f-eb46bb384100)
的第 11 和 12.1 节填写。这些内容是来源报告的描述，不是构造的测量值。

| 字段                       | ENBREL                                                                        | HUMIRA                                                                         |
| -------------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 活性成分                   | Etanercept                                                                    | Adalimumab                                                                     |
| 模态与构建体               | 以二聚体形式组装的融合蛋白，包含人 p75 TNF 受体的胞外配体结合部分和人 IgG1 Fc | 人 IgG1 单克隆抗体，具有来源于人的重链和轻链可变区                             |
| 表达系统                   | 中国仓鼠卵巢（CHO）哺乳动物细胞                                               | CHO 哺乳动物细胞                                                               |
| 作用机制章节记录的预期作用 | 阻止 TNF-α 和 TNF-β 与细胞表面 TNF 受体结合                                   | 结合 TNF-α 并阻止其与细胞表面 TNF 受体相互作用。说明书指出其不结合或灭活 TNF-β |

修正后必须保留两种独立身份。Etanercept 的受体组分和 Fc 组分都必须保留。
仅因它含有 Fc 就称它为抗体，会丢失识别组分的信息。Adalimumab 则需要记录抗体形式。
这些描述中的“人”不能确定表达宿主。共同的 CHO 字段也不表示两个构建体相同。

最后，用每条记录中的作用及结合伙伴范围，替换含糊的“TNF 结合”。这是对已记录
构建体的解释，不是临床表现比较，也不证明可互换性。说明书的这些描述同样没有提供
任何一个对象的实验坐标。

### 独立练习：多肽与寡核苷酸

依据以下**公开记录中的事实**，为另外两种药物填写相同的身份、构建体、表达系统
和预期功能字段。

在下文的 RNA 记录中，**剪接**指细胞对 RNA 的加工过程，其中称为内含子的片段被移除，
保留的外显子片段连接成成熟信使 RNA（mRNA）。**外显子包含**记录指定外显子是否保留在
该成熟 RNA 中。这些术语依据 [NHGRI 内含子词条](https://www.genome.gov/genetics-glossary/Intron)。

- [VICTOZA 说明书](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=5a9ef4ea-c76a-4d34-a604-27c5b505f5a4)
  中的 **GLP-1** 指胰高血糖素样肽-1（glucagon-like peptide-1）。第 11 和 12.1 节
  将 liraglutide 描述为这种天然信号肽的酰化类似物。其多肽前体的表达系统陈述注明了
  _Saccharomyces cerevisiae_。最终分子包含脂肪酸组分。受体激活在葡萄糖升高时
  促进胰岛素释放，这种分泌随着葡萄糖接近正常水平而减弱。
- [SPINRAZA 说明书第 11 和 12.1 节](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=dd70cd5f-b0fc-4ba4-a5ea-89a34778bd94)
  将 nusinersen 描述为作用于 **SMN2**（运动神经元存活基因 2，survival of motor neuron 2）
  转录本的修饰反义寡核苷酸。SMN2 是一个可以编码运动神经元存活蛋白（**SMN**，survival motor neuron）
  的基因，这一区别见 [MedlinePlus 基因摘要](https://medlineplus.gov/download/genetics/gene/smn2.pdf)。
  该说明书报告，体外测定和脊髓性肌萎缩症转基因动物模型显示，外显子 7 的包含增加，
  全长 SMN 蛋白的生成增加。
  这些章节没有注明 nusinersen 的表达宿主。

一份**构造的**注释把第一种药物称为“胰腺细胞产生的未修饰 GLP-1”，把第二种
称为“在人神经元中表达的 SMN 蛋白”。写出修正后的记录。指出酵母陈述描述的是
哪个组分。解释为何增加的 SMN 蛋白不能确定所给予的构建体或其表达系统。
保留每项功能主张的范围。

| 身份               | Liraglutide、VICTOZA，以及链接的来源章节和打开日期 | Nusinersen、SPINRAZA，以及链接的来源章节和打开日期                     |

## 第 2 部分：区分评估目标

**评估目标**说明评价所要判断的性质。表示和输出必须与该性质相匹配。本课的输入是
身份已明确的药物记录，以及明确标注的证据摘要。输出是针对各个目标、有依据的主张。
本课不拟合模型，也不选择生物候选项。

| 目标       | 问题与适当输出                                                                 | 边界                                                             |
| ---------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------- |
| 序列恢复   | 评估位置中有多少与指定参考完全一致？输出匹配比例，同时保留参考对象和评估区域   | 与参考一致不能证明折叠或活性。未评分位置不在结果范围内           |
| 折叠       | 身份已明确的对象是否在给定语境中采取指定构象？保留实验构象证据或明确标注的预测 | 预测不是折叠的观察结果。与一个已观察构象一致的结论仅适用于该状态 |
| 结构合理性 | 坐标表示是否满足指定几何检查？保留受检模型、覆盖范围和几何误差                 | 几何合格也可能对应错误折叠。合理模型未必是对象实际采取的构象     |
| 结合       | 对象是否在报告条件下与指定伙伴相互作用？保留相互作用证据或带单位的亲和力数值   | 缔合本身不能证明底物转化或下游响应                               |
| 催化       | 对象是否加速指定的底物到产物转化？保留转化或速率证据、归一化方式和语境         | 结合结果不提供催化速率。催化并非每种治疗机制的预期目标           |
| 生物功能   | 指定终点是否在相关生物语境中改变？保留终点、比较、方向和观察单位               | 分子、样本和患者层面的结局是不同终点                             |

对于结合，平衡解离常数 `K_D` 具有浓度单位。在匹配的平衡模型下，较小的值表示
较紧的结合。对于催化，比较所报告的速率之前，需要明确单位，例如物质量除以时间，
还要明确按酶量归一化的方式。两种量都不是生物功能的概率。现有的
[识别课程](/zh-cn/learn/biologics-design/antibody-peptide-design/)更详细地解释了
亲和力和特异性。

折叠和合理性尤其容易混淆。几何合格的图像回答内部是否自洽。分子占据该构象的
证据回答分子的状态。任一结果本身都不提供结合或功能测量。

### 推导案例：dornase alfa 记录支持什么

**公开记录中的事实。** [PULMOZYME 说明书第 11 和 12.1 节](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=d8c78a7e-ff99-48f3-8952-643ec2ea0f86)
将 dornase alfa 描述为人 **DNase I**（脱氧核糖核酸酶 I，deoxyribonuclease I），
一种选择性切割 DNA 的酶，并记录其 CHO 表达系统。说明书报告，
在**临床前体外研究**中，囊性纤维化患者痰液中的 DNA 被水解，痰液黏弹性降低。
黏弹性同时描述黏性和弹性行为。底物转化与痰液性质的改变是不同的观察结果。

现在考虑一份附在该参考记录上的、完全**构造的**计算摘要。它在 `N = 240` 个
评估位置中有 `M = 216` 个完全匹配的位置，在 `T = 200` 项坐标检查中有
`A = 198` 项合格。该摘要、其中全部计数和评估子集都是**构造的**。
它们不是对 dornase alfa 或某个新提议分子的测量。

令 `R = M / N` 表示序列恢复率，`G = A / T` 表示合格几何检查所占的比例。
两者均无量纲，范围从 0 到 1。仅针对各自的参考对象或检查集合，数值越高才越好。
`G` 是教学定义，不是公认的通用结构评分。

分别展开**构造的**算术：

1. 序列恢复有 `240 − 216 = 24` 个评估位置不匹配。
   `R = 216 / 240 = 0.90`，且 `0.90 × 100 = 90%`。
2. 几何检查有 `200 − 198 = 2` 项失败。
   `G = 198 / 200 = 0.99`，且 `0.99 × 100 = 99%`。

两个分母都不是独立患者或药物的数量。序列恢复仅涉及声明的评估位置。
对同一个坐标表示进行多项检查，不会产生独立的分子观察结果。

完整的目标记录并列保留这些不同证据类型，不对它们求平均。对于哪些字段仍未验证的
判断，是本课依据所给字段作出的解释。

| 目标       | 本案例的记录                              | 支持的结论                                     |
| ---------- | ----------------------------------------- | ---------------------------------------------- |
| 序列恢复   | **构造的：** `R = 0.90`                   | 仅说明评估子集上与参考的匹配                   |
| 折叠       | 所给摘要未验证                            | 未提供与已观察构象的比较                       |
| 结构合理性 | **构造的：** `G = 0.99`                   | 这些几何检查中的大多数通过。折叠尚未确立       |
| 结合       | 所选说明书章节没有单独的亲和力估计        | 催化过程中的底物相互作用不能提供实测 `K_D`     |
| 催化       | 来源报告了指定临床前体外环境中的 DNA 水解 | 支持发生转化，但本摘要中没有催化速率数值       |
| 生物功能   | 来源报告了该环境中痰液黏弹性降低          | 样本层面的物理后果，而非这项观察测得的患者结局 |

若主张涉及 DNA 转化，相关目标是催化。若主张涉及痰液性质，相关目标是样本层面的
生物功能。构造的恢复比例和几何合格比例都不能回答这两项主张。反过来，所报告的
酶活性也不能验证构造的坐标表示。将其折叠字段标记为未验证，是在说明该证据包缺少
什么，不是在说已批准药物无法折叠。

### 独立练习：解释抗体记录

回到第 1 部分的 HUMIRA 公开记录。一份关于其参考记录的、完全**构造的**计算摘要
包含 `M = 81`、`N = 90`、`A = 171` 和 `T = 180`，各符号含义与上文相同。
摘要中的每个计数和评估子集都是**构造的**。它没有提供与已观察构象的比较、
亲和力估计或催化速率。说明书仍是已记录结合与受体阻断作用的来源。

1. 计算 `R` 和 `G`，包括不匹配位置数和失败检查数。
2. 填写全部六个目标字段。区分缺少的测量与不属于已记录机制的目标。
3. 一条**构造的**结论写道：“良好几何证明了折叠和对 TNF 的催化破坏。”修正它。
   阻止 TNF 与受体相互作用对应哪个目标？为何仅凭结合评分不能确立该作用？

<details data-worked-answer>
<summary>参考答案</summary>

**构造的**恢复率计算为 `90 − 81 = 9` 个不匹配位置，随后
`R = 81 / 90 = 0.90`，且 `0.90 × 100 = 90%`。**构造的**几何计算为
`180 − 171 = 9` 项失败检查，随后 `G = 171 / 180 = 0.95`，且
`0.95 × 100 = 95%`。

| 目标       | 参考答案                                                              |
| ---------- | --------------------------------------------------------------------- |
| 序列恢复   | **构造的：** 在该评估子集上为 `0.90`。不能由此得出功能结论            |
| 折叠       | 所给摘要未验证。没有给出与已观察构象的比较                            |
| 结构合理性 | **构造的：** 声明检查中有 `0.95` 通过。这不是折叠的证明               |
| 结合       | 来源报告了与 TNF-α 的相互作用。此处没有提供亲和力数值                 |
| 催化       | 不是已记录受体阻断机制的目标。不记录催化破坏主张，也不推定速率为零    |
| 生物功能   | 说明书描述了对 TNF 与受体相互作用的抑制。该分子功能作用不同于结合本身 |

修正后的结论是，构造的表示通过了大多数几何检查。结合与抑制作用在说明书中
分别有依据。这里的受体阻断属于生物功能目标。仅有结合，只能确立缔合，不能说明
受体相互作用受到阻止。几何评分或该缔合都不能提供催化破坏的证据，也不能提供
临床效应量。

</details>

关于这些目标字段之外还需要哪些证据，请继续读
[可开发性与功能验证](/zh-cn/learn/biologics-design/developability-and-validation/)。
那些性质需要各自的记录。

[生物构建体记录审计](/zh-cn/labs/biologic-construct-audit/)把这四项套到六种具名药物的记录上，
并显示其中三个有构建体却没有生产宿主、一个有宿主却没有构建体。
