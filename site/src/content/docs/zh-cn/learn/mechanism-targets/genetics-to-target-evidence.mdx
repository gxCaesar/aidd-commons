## 学习目标

完成本课后，你应能区分 GWAS 位点、精细定位变异和效应基因假设；陈述可信集、共定位结果和
单变异孟德尔随机化（MR）比值背后的假设；并说明这些结果为何能够为、却不能决定靶标方向的判断。

## 预备知识与边界

先阅读[从疾病机制到靶点](/zh-cn/learn/mechanism-targets/disease-to-target/)和
[生物学表示](/zh-cn/learn/representations/biological-representations/)。本课是阅读和推理课程，不实现
GWAS、精细定位、共定位或 MR 工作流；不提供真实遗传数据、临床解释或因果证明。

## 三种不能合并的对象

GWAS 关联表示：在已声明的人群中，一个被测试的标记或区域位点与表型存在统计关联。它本身并不识别
因果 DNA 改变、受影响的基因或药物靶标。lead marker 可能只是对因果改变的标记。

连锁不平衡（LD）表示相邻变异会因共同遗传而相关。精细定位利用关联模式和 LD 在候选变异间分配
支持度。其后验纳入概率（PIP）是在模型条件下候选变异为因果变异的后验；在本课所用的一个因果变异
设定下，可信集收集候选变异，直至其 PIP 总和达到已声明的概率质量，常为 95%。二者都不是基因列表或
功能证书。原始精细定位研究 [Maller et al.](https://pmc.ncbi.nlm.nih.gov/articles/PMC3791416/) 展示了
可信集和“一个已分型因果变异”假设的限制。

效应基因则是进一步的假设：该变异改变了涉及该基因的分子过程，而该过程在相关语境中对表型有贡献。
基因组距离不足以支持这一点；一个位点可包含多个基因、影响远端基因，或携带多个信号。

### 推导案例：PIP 质量不是基因主张

下例是一个**构造的教学示例**。设一个模型假定恰有一个因果变异，且该因果变异包含在五个候选变异中。
其 PIP 为：

| 变异 |  PIP |
| ---- | ---: |
| `v1` | 0.44 |
| `v2` | 0.27 |
| `v3` | 0.16 |
| `v4` | 0.08 |
| `v5` | 0.05 |

其质量为 `0.44 + 0.27 + 0.16 + 0.08 + 0.05 = 1.00`。`v1` 至 `v4` 的和为 `0.95`，因此它们构成
该模型最小的 95% 可信集。这一算术**不**表示 `v1` 在普遍意义上有 44% 的因果概率，不表示四个变异
都是因果的，也不表示最近的基因就是效应基因。它以候选集、LD、关联模型和先验为条件。若因果变异
缺失或插补较差，或存在多个因果变异而模型只允许一个，则这一解释会失效或不完整。

LD 和等位基因频率可在不同祖源群体间不同。因此，在一个人群中得到的 PIP 或可信集不能自动迁移到
另一个人群，或迁移到祖源不同的分子 QTL 数据集。这是推断条件，而不是无关紧要的注释细节。

## 共定位提出的是更窄的问题

共定位比较同一区域两个性状的关联模式。疾病表型与组织特异的表达性状可能与两个不同的因果变异，或
一个共享的变异一致。经典的汇总统计量表述区分这些假设：`H3` 支持不同变异，`H4` 支持共享变异。
[Giambartolomei et al.](https://journals.plos.org/plosgenetics/article?id=10.1371/journal.pgen.1004383) 明确
区分了它们。

对共享变异的高支持度，是在输入数据和模型条件下有关共享关联信号的证据，而不是“已命名基因的表达
介导疾病表型”的证据。同一变异可经另一条路径、不同细胞状态或未测量中介影响两个性状，也不确立
干预方向。原始表述假定等位基因频率和 LD 可比较、因果变异被包含，且每个性状至多有一个关联。
多个信号、不完整覆盖、祖源不匹配或不一致的等位基因/基因组版本定义，需要适当分析，而不是视觉
重叠主张。

## MR 是工具变量论证，而不是靶标裁决

MR 使用遗传变异 `G` 作为暴露 `X` 的工具变量，以估计它与结局 `Y` 的关系。它需要相关性（`G` 与
`X` 关联）、独立性（`G` 不与 `X`--`Y` 混杂因素关联）以及排除限制（在所述混杂因素条件下，`G`
仅通过 `X` 影响 `Y`）。水平多效性可能违反排除限制；弱工具或相关工具会增加不确定性。
[Burgess、Butterworth 和 Thompson](https://onlinelibrary.wiley.com/doi/10.1002/gepi.21758) 陈述了这些
条件和线性连续性状的比值构造。

在取比值之前，等位基因协调至关重要：`beta_GX` 与 `beta_GY` 必须指向同一变异和效应等位基因。
只有在报告的等位基因确定相反时，才可翻转符号。表型定义和效应尺度也必须匹配。链方向含糊或未记录
的效应等位基因，是未解决的输入，而不是猜测方向的理由。

### 推导案例：有明确单位的线性 Wald 比值

第二个**构造的教学示例**只使用连续、线性的表型。对于一个效应等位基因，令
`beta_GX = +0.20 X units per allele`，`beta_GY = -0.06 Y units per allele`。单变异 Wald 比值为
`beta_GY / beta_GX = -0.06 / 0.20 = -0.30 Y units per X unit`。

在已声明的工具变量和线性模型假设下，该比值在这些测量尺度上具有负方向。它不是临床风险、诊断、
治疗效应或剂量。没有置信区间，因为它是算术，而不是对观测数据的分析。

## 从遗传方向到可检验的靶标假设

靶标方向论证应保留对象链：变异/效应等位基因；分子性状/推定效应基因；表型；相关组织或细胞语境；
以及所提议的扰动/读出。推导的 `-0.30 Y units per X unit` 比值表示，在其假设下，较高 `X` 对应较低
`Y`。若较低 `Y` 是已声明的实验目标，这可激发把较高 `X`（而非抑制）作为待检验的假设。`X` 是未指定的
分子性状，并不自动等于蛋白活性；在提出干预前，必须将表达映射到蛋白和功能。这不是临床获益主张。
它仍需要在相关疾病语境中身份、特异性、持续时间、基线和读出均已说明的扰动。
[跨细胞语境的扰动预测](/zh-cn/learn/mechanism-targets/perturbation-context-generalization/) 说明了为何不能
悄然将该语境平均掉。

遗传变异可在发育期和整个生命中发挥作用；扰动则有时点、强度有限，并可能作用于一种分子种类。
反馈、代偿、组织暴露和扰动幅度都可能不同。因此，遗传方向不提供剂量等价性，也不确立在一个模型中
改变一种蛋白会产生相同表型。相互收敛的遗传学、分子证据和语境匹配的扰动，使一个假设更可检验，
而非得到证明。

## 独立练习

一个不同的**构造**位点在相同的“候选集内一个因果变异”假设下被分析。其 PIP 为 `u1 = 0.51`、
`u2 = 0.31`、`u3 = 0.12` 和 `u4 = 0.06`。另有一对构造的汇总统计量：对于连续线性性状和一个
已协调的效应等位基因，`beta_GX = -0.15 X units per allele`，
`beta_GY = +0.045 Y units per allele`。

1. 最小的 90% 可信集是什么？
2. Wald 比值的数值和单位是什么？
3. 说出一个可信集可能失效的推断条件，以及一个该比值不能证明干预方向的理由。

<details data-worked-answer>
<summary>参考答案</summary>

`u1 + u2 = 0.82`，低于 0.90；加入 `u3` 后为 `0.94`。因此，最小 90% 可信集是
`{u1, u2, u3}`。该比值为 `0.045 / -0.15 = -0.30 Y units per X unit`。若因果变异不在候选集中、
LD 与研究人群不匹配，或尽管模型只允许一个变异却有多个因果变异，则可信集条件可能失效。该比值
不能证明干预方向，因为工具变量前提可能因多效性失效，且终生遗传位移不等同于有时点的扰动或剂量。

</details>

## 失效边界与来源路径

不要把位点改称为基因、把可信集改称为因果机制、把共享变异改称为中介，或把 MR 比值改称为药物效应。
在将证据转化为靶标假设前，记录表型、研究人群、变异/基因组版本/效应等位基因定义、候选变异覆盖、
LD 和模型假设、分子语境，以及扰动契约。
