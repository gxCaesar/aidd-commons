## fit 背后的问题

先阅读[从记录到建模表](/zh-cn/learn/data-governance/records-to-model-table/)。本课将特征、目标函数和预测连接起来。你将推导一条拟合直线，区分拟合参数与选择的设置，并追踪每一步允许使用的数据。本例是构造的算术示例，不是分子测定或研究结果。

表示把对象映射成数字，预测器把这些数字映射成输出。训练在已观测的训练样本上选择预测器参数，以降低目标函数。推理在新输入上计算已有映射的输出，通常不更新参数。验证比较候选设置；除非协议明确规定，否则它不是额外的训练损失项。

## 推导最小的有用模型

对一个特征，预测为 `ŷ = b + w x`，其中 `b` 是截距，`w` 是斜率。普通最小二乘最小化残差平方和，Ridge 在此基础上惩罚斜率：

```text
J(b, w) = Σtraining (yᵢ − b − w xᵢ)² + α w²
w = Σ(xᵢ − x̄)(yᵢ − ȳ) / [Σ(xᵢ − x̄)² + α]
b = ȳ − w x̄
```

截距不受惩罚。令截距的导数为零得到第三行，再代入斜率导数，得到第二行。所有求和与均值只使用训练记录。多个特征时，同样的思路使用矩阵运算；[线性模型文档](https://scikit-learn.org/stable/modules/linear_model.html)给出了相应的最小二乘与 Ridge 目标函数。

对于训练点 `(0, 1), (1, 3), (2, 5)`，特征均值为 1，目标均值为 3，中心化乘积和为 4，中心化特征平方和为 2。alpha 为 0 时，`w = 2`、`b = 1`；alpha 为 2 时，`w = 1`、`b = 2`。后者向训练目标均值收缩，不是把所有预测统一乘一个常数。

在 `x = 3` 时，两者分别预测 7 和 5。如果对应验证目标为 6，两者的绝对误差都是 1。预先规定的并列规则可以选择较小 alpha，但不能用新的测试目标打破验证并列。本例不能说明哪种惩罚通常更好。

## 参数不等于超参数

`b` 和 `w` 是通过训练标签学习的参数。alpha 在本课是候选超参数，由验证从预定网格中选择。需要学习的特征缩放器也有参数：只使用训练特征计算均值与尺度，然后原样应用到验证和测试数据。在测试批次上重新计算缩放器，会改变模型的输入映射。

[预处理泄漏指南](https://scikit-learn.org/stable/common_pitfalls.html)提供了实际例子。交叉验证时，每个训练折都需要单独拟合预处理；交叉验证不是先处理整张表的许可。

后续沙箱的一维 Ridge 使用未缩放输入，逻辑回归使用训练集标准化。因此，两种方法中数值相同的惩罚不代表正则化强度相同。必须检查损失是求和还是求均值，以及哪些参数受到惩罚。

## 追踪完整过程

```text
声明任务与分区
  → 在训练记录上拟合每个候选
  → 用固定的候选映射预测验证记录
  → 按预定验证指标和并列规则选择
  → 用选定映射预测测试输入
  → 与测试目标比较并保留误差
```

本课沙箱在选择后不把验证集加入训练重新拟合。其他预先规定的协议可以这样做，但它会产生不同的预测器，不能与这里的流程悄悄混用。

训练目标均值这个常数预测器很重要：它能揭示学习到的关系是否比完全不依赖输入更有用。灵活模型的训练损失更小并不足够。即使关系在训练范围外已经失效，线性模型仍然能够继续外推。

## 如何连接更大的模型

树模型选择由特征决定的分区，并在叶节点内预测；GNN 反复将节点状态与邻居消息结合；Transformer 依据内容对 token 状态进行加权组合。它们改变假设空间和表示学习方式，不改变明确输入、训练目标与选择数据的必要性。[课程蓝图](/zh-cn/learn/foundations/curriculum-map/)将这些机制拆为专题；这堂直线拟合课不等于已经完成 GNN 或 Transformer 教学。

## 独立练习

对 `(0, 2), (1, 4), (2, 6)` 使用 alpha 2 训练。推导斜率与截距，再预测输入 3。如果有人在 `fit` 前把一个验证点加入训练数组，原来的“仅训练集拟合”描述是否仍然成立？不用运行代码，说明改变了什么。

<details data-worked-answer>
<summary>参考答案 — 先拟合，再说明边界</summary>

均值为 1 和 4，中心化求和仍为 4 和 2，因此斜率为 1、截距为 3，在 3 处预测为 6。加入验证点改变了训练目标函数，通常也会改变参数。即使某个特殊点恰好不改变数值解，旧描述仍然不成立。完整答案应区分数据访问规则与偶然的数值相等。
