## 先明确不确定的是哪个量

先读[回归与分类误差](/zh-cn/learn/qsar-properties/regression-classification-errors/)，
需要对数与协方差基础。本课连接终点、似然、损失、先验与检查点选择。
手算数值均为构造，不是模型的实证比较。

不能因为某种损失容易优化，就反过来决定观测终点。精确连续测量、阳性/阴性标签、区间截尾
测量与事件发生时间包含不同信息。预测对象必须对应真正会获得的观测。
例如测定报告“大于 10”，并不是精确测得 10。

## 损失表达了对观测的假设

设 `yᵢ=fθ(xᵢ)+εᵢ`，噪声独立且服从方差固定为 `σ²` 的高斯分布。
除常数外，负对数似然为：

```text
L(θ) = Σᵢ (yᵢ − fθ(xᵢ))² / (2σ²)
```

在此假设下，最大化似然与最小化平方误差选择相同的均值函数。
Laplace 观测模型的中心参数则对应绝对误差损失。若同时预测方差，高斯损失还包含
`log σᵢ`；省掉它，模型就能通过无限放大声称的不确定性来降低残差惩罚。
因此“预测不确定性”改变了拟合对象，不只是给点预测加一圈阴影。

对于类别 `y∈{0,1}` 与预测概率 `p`，Bernoulli 负对数似然为
`−y log p − (1−y) log(1−p)`。自信却错误的预测受到较大惩罚。
分类阈值属于后续决策，不会仅因最小化概率损失而自动确定。
[scikit-learn 线性模型文档](https://scikit-learn.org/stable/modules/linear_model.html)
分别定义最小二乘、Ridge 与 logistic 的目标，不同惩罚约定不能直接互换。

构造残差 `[1,3]`，均方误差为 5，平均绝对误差为 2。记录为阳性且 `p=0.8` 时，
log loss 约 0.2231；只把预测改成 `p=0.2`，则约为 1.6094。
类别加权损失改变拟合优先处理的错误，其输出概率可能仍需针对目标总体校准。
训练权重不是关于总体阳性率的新证据。

## 高斯过程明确表达相似性

高斯过程为潜在函数值赋予联合高斯分布。核 `k(x,x′)` 描述协方差；
半正定并不自动意味着它是有化学意义的相似性。零均值 GP 的训练协方差矩阵为 `K`，
独立观测噪声方差为 `σn²`，查询与训练输入的协方差向量为 `k*`，则：

```text
μ* = k*ᵀ (K + σn² I)⁻¹ y
v* = k(x*,x*) − k*ᵀ (K + σn² I)⁻¹ k*
```

`v*` 描述潜在函数。新的带噪声观测还需加上其观测噪声方差。
实现时应求解线性方程组，而非显式求逆。
[Gaussian Processes for Machine Learning 第 2 章](https://gaussianprocess.org/gpml/chapters/RW2.pdf)
推导这些条件高斯表达式。核超参数可以利用训练证据拟合，但不能借此查看留出答案。

构造一个训练观测 `y=2`、`K=[1]`、`σn²=0.25`，查询先验方差为 1，
查询协方差 `k*=0.5`。则 `μ*=0.5×2/1.25=0.8`，
`v*=1−0.25/1.25=0.8`，新观测方差为 1.05。
若查询协方差为零，均值为零、潜在方差为 1：它回到了**选定的先验**，
不是发现了某个普遍化学基线。

核、均值函数与似然都包含假设。错误表示上的窄后验仍可能很错。
精确稠密 GP 的训练运算量随观测数呈三次增长、存储呈二次增长；稀疏近似改变计算方法。
近似方法与后验方差都不能代替独立校准检查。

## 检查点属于模型配方

拟合产生一系列参数状态。选 epoch、早停位置、正则强度或表示，都是选择行为。
验证数据可以支持选择；如果测试数据参与选择，就不能继续声称测试集未被触及。
学习式预处理也必须放在训练分区内部，见
[官方泄漏示例](https://scikit-learn.org/stable/common_pitfalls.html)。

下列误差为构造，**预先指定按验证 MAE 选择**：

| Epoch | 训练 MAE | 验证 MAE |
| ----- | -------- | -------- |
| 5     | 0.40     | 0.52     |
| 10    | 0.25     | 0.45     |
| 20    | 0.12     | 0.49     |

应选 epoch 10，而不是训练误差最小者。若随后测试结果不理想，不能替换成 epoch 20，
同时保留原本的测试主张。未来研究可以更改配方，再使用新评估数据。
固定模型的置信区间或预测区间，不包含试了许多配方再挑最好报告结果的额外不确定性。

反复查询也可能使小验证集被过拟合。查看结果前固定合理候选族与选择规则；
若评估对象是整个选择过程而非单个冻结模型，应考虑嵌套重采样。
相关分子或重复受试对象在各相关折内仍需正确分组。

## 独立练习

1. 在单观测 GP 例子中，将查询协方差改为 1，其他不变，求均值、潜在方差与新观测方差。
2. 测定报告 `y > 10`，为什么用 10 替代会改变任务？连续观测模型应使用什么概率作为似然？
3. 第四个检查点验证 MAE 为 0.44，但它是在查看原测试误差后才设计出来的。
   对它可以和不可以声称什么？

<details data-worked-answer>
<summary>参考答案——保留观测含义与选择历史</summary>

GP 均值为 `2/1.25=1.6`，潜在方差为 `1−1/1.25=0.2`，新观测方差为 0.45。
本例中，即使查询位于已观测输入处，噪声也使潜在方差不为零。
下界应贡献 `P(Y>10|x)`，而不是 10 处的概率密度；按精确值处理制造了一个不存在的观测。
第四个检查点属于事后动机产生的候选，可以连同历史报告其验证分数，
但在已看过的测试集上再次评分，不是未触及的确认。
