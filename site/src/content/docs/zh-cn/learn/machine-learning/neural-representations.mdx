## 从固定描述符到学习表示

先读[基线拟合](/zh-cn/learn/machine-learning/baseline-training-validation/)
与[分子表示](/zh-cn/learn/representations/small-molecule-representations/)。
需要向量、矩阵乘法及导数概念。本课学习手算消息传递层，把注意力解释为值的加权读出，
并区分不变的标量输出与等变的向量输出。这是手算课，不训练神经网络。

描述符流程先计算 `x = φ(molecule)`，再拟合预测器；神经网络将部分 `φ` 与预测器一起学习。
两者仍需要定义目标，并仅在训练数据上拟合。更灵活的表示不会为缺失的生物语境创造标签。
先判断目标属于整个分子、单个原子，还是与坐标有关的量，再选择如何汇总输入。

## 图消息是局部计算

原子为节点 `i`，键特征为 `eᵢⱼ`，`hᵢᵗ` 是第 `t` 层节点的隐藏向量。消息传递层写为：

```text
mᵢ = 对邻居 j 求和 Mₜ(hᵢᵗ, hⱼᵗ, eᵢⱼ)
hᵢᵗ⁺¹ = Uₜ(hᵢᵗ, mᵢ)
ŷ = R({hᵢᵀ})
```

`M` 产生消息，`U` 更新节点，`R` 读出最终状态。
[MPNN 原始论文公式 1–3](https://proceedings.mlr.press/v70/gilmer17a/gilmer17a.pdf)
区分这些操作。最终集合读出不能依赖任意原子编号。求和与均值都与排列无关，
但保留的大小信息不同；逐原子任务则保留每个节点的输出。

构造一个不代表化学结构的三节点链 `A—B—C`，初始标量状态为 `[1, 2, 4]`，
令 `M(hᵢ,hⱼ,e)=hⱼ`、`U(h,m)=h+m`。所有节点使用**旧状态同步更新**：

| 节点 | 旧状态 | 相邻节点旧状态之和 | 新状态 |
| ---- | ------ | ------------------ | ------ |
| A    | 1      | 2                  | 3      |
| B    | 2      | 1 + 4 = 5          | 7      |
| C    | 4      | 2                  | 6      |

求和读出为 16，均值为 `16/3`。若先更新 A，再立刻把新值 3 用于同一层的 B，
就变成了依赖更新顺序的另一种算法。第二次同步更新给出 `[10, 16, 13]`。
两层后 C 的信息可经 B 到达 A。这说明感受野，不代表分子效力或训练结果。

真实模型通过任务损失学习原子/键编码、非线性变换及读出参数。增加层数还会改变优化过程
与局部信息混合程度。将增益归因于图推理前，先在相同划分下比较描述符与指纹基线。

## 注意力选择混合方式，不提供因果解释

按行排列的 token 特征为 `H`，学习得到的投影给出查询 `Q=HWQ`、键 `K=HWK`
与值 `V=HWV`。缩放点积注意力为：

```text
Attention(Q,K,V) = softmax(QKᵀ / √dₖ + mask) V
```

Softmax 对每个查询允许访问的键归一化；禁止访问的键通过掩码排除。多头注意力计算多个
读出后组合。[Attention Is All You Need 第 3.2 节](https://arxiv.org/html/1706.03762v7)
解释这些机制。位置与结构信息需要另外设计；仅靠一袋相同嵌入，不能确定残基顺序或空间几何。

给一个编造的查询已缩放分数 `[0, ln(3)]`，softmax 权重为 `[1/4, 3/4]`。
若标量值为 `[2, 6]`，读出为 `(1/4)×2 + (3/4)×6 = 5`。
屏蔽第二个键后，读出变为 2。键控制权重，值提供被组合的内容，混淆两者会改变计算。
权重 3/4 既不是结合概率，也不能证明某原子导致活性。组合特征最终预测什么，
取决于下游读出与训练目标。

## 对称性属于输入—输出契约

`xᵢ` 为原子三维坐标，`Q` 为正交旋转，`t` 为平移。标量能量可要求
`E(Qx+t)=E(x)`；力向量则应随之旋转，即 `Fᵢ(Qx+t)=QFᵢ(x)`。
平移改变坐标原点，不改变力。原子重新编号时，逐原子输出也要做相同排列。

考虑 `vᵢ = Σⱼ aᵢⱼ(xᵢ−xⱼ)`，其中标量 `aᵢⱼ` 只依赖距离等旋转/平移不变信息。
每个坐标差都乘以 `Q`，其和也相同，因此得到等变向量。这是直接推导。
[EGNN 论文](https://proceedings.mlr.press/v139/satorras21a/satorras21a.pdf)
利用不变消息与坐标差更新构建对欧氏群等变的网络，包含镜像反射。

“包含反射”值得注意：若只镜像配体，而固定一个手性生物环境，反射未必是该**任务**的对称性。
仅用配体距离的表示，不能编码被省略的蛋白伙伴，也不能仅凭距离区分镜像结构。
给模型名字加上“3D”，不会补回缺失立体化学，也不会把单个构象变成平衡系综。

## 独立练习

1. 将链的存储顺序改为 C、A、B，不改变连接。第一次同步更新后的节点值与求和怎样变化？
2. 注意力分数改为 `[0,0]`，值仍为 `[2,6]`，读出是多少？等权是否表示生物学作用相同？
3. 将向量 `(1,0,0)` 绕 z 轴旋转 90 度。输入同时旋转时，力预测应是什么？
   任意单位下原本为 7 的标量能量应怎样变化？

<details data-worked-answer>
<summary>参考答案——跟踪对象，不跟踪行号</summary>

新存储顺序中的状态为 C: 6、A: 3、B: 7，总和仍为 16；若总和改变，就暴露了编号或顺序依赖。
等分数给出各 1/2 的权重，读出为 4，不产生因果结论。力变为 `(0,1,0)`，
标量能量在约定对称性下仍为 7。这些是变换要求，不是准确率评价。

</details>
