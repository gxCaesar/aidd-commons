## 表连接也是科学决策

先读[来源与实体素养](/zh-cn/learn/foundations/source-and-entity-literacy/)
和[从记录到模型表](/zh-cn/learn/data-governance/records-to-model-table/)。你应已能区分测量与数据库行。
本章学习解决歧义连接、计算排除数量，并写出简短的使用权限说明。下列表格均为构造的教学示例。

常见流程是下载测定表、连接结构，再连接靶点注释。每一步都可能改变科学分析总体。
显示名称通常不是可靠的连接键：别名可能复用，结构可能未注明立体化学，蛋白名称可能对应多个异构体或实验构建体。
选择数据库返回的第一个结果只是掩盖歧义。应先定义所需实体，再连接表。

亲和力任务至少要明确被测材料身份、实际测量的靶点构建体、终点和测量语境。
母体化合物可用于分组，却未必完整描述材料身份。全长蛋白编号可用于注释，却未必标识实际测量的截短构建体。
这些概念应保留在不同列中，不要让一个“统一编号”承担所有用途。

## 完整算例：两个匹配不是两次观测

一个虚构输入包含三次独立测定观测：

| 观测 | 提交的别名 | 记录终点 |
| ---- | ---------- | -------- |
| o1   | A          | 6.0      |
| o2   | B          | 7.0      |
| o3   | C          | 5.0      |

结构查询返回 A→a1、B→b1、B→b2、C→c1。B 的两个匹配是不同的立体化学实体，原记录未说明实际测量哪个。
直接连接会得到四行，但仍只有三次观测。给两个 B 行都赋值 7.0，既虚构了结构特异性标签，也让 o2 获得双倍权重。
均值会从 `(6+7+5)/3=6.0` 变成 `(6+7+7+5)/4=6.25`，变化完全来自连接操作。

若任务要求明确立体化学的结构，可保留 o1 和 o3，把 o2 列为未解决。
保留数据均值为 5.5，它描述的是**两次身份已解决的观测**，不是原总体。
另一种任务可以明确采用更粗粒度的母体实体，保留 o2 一次，同时记录其立体化学不明确。
这属于另一份表示约定，不意味着可以悄悄填入某个异构体。

应记录连接前后的基数。多对一注释连接不应增加观测数。
合法的一对多关系，例如一个化合物有多个实测靶点，应保存在关系表中，或明确把“化合物–靶点对”定义为任务样本。
不要仅为满足模型输入形状而合并或扩展记录。

## 一个小型消歧流程

从来源原生编号和版本或获取日期开始。定义目标比较键，仅进行有科学依据的规范化。
已知换算关系的单位转换保留量的含义；合并 IC50 与 Kd 则改变终点。
同时保留原值与变换值，使读者能解释该操作。

把匹配分为精确匹配、有依据的映射、歧义和缺失。检查影响纳入资格的歧义项，不要自动对所有名字做模糊匹配。
检查一对一、多对一连接是否满足预期基数。最后按原因统计排除数，可以用互斥的首个失败类别，也可以明确标注原因重叠。
不能把重叠类别当作互斥分组求和。

例如 100 行中有 8 行终点无效、6 行身份不明，其中 3 行同时存在两个问题。
排除并集移除 `8+6−3=11` 行，保留 89 行，而不是 86 行。
这个数并不等于独立化合物、供体或测定数量；独立单位须另行统计。
排除后模型分数提高不一定意味着排除错误，但规则应源于任务，而不是因为某些行难预测。

## 读者能使用的科学来源说明

来源说明回答哪些原始记录和变换产生了某个量。
[W3C PROV-O 推荐标准](https://www.w3.org/TR/prov-o/)提供实体、活动和责任主体的词汇。
教程规模的实现可以只是一段可读文字与一张表，不必采用完整本体。

例如：“模型表使用测定来源 S 的 R 版本。保留终点 E 的精确测量，转换声明的单位，按指定规则处理技术重复，并按记录原因排除 11 行。
最终保留 57 个化合物的 89 次观测。”读者便能判断重复处理、终点和总体是否符合自己的问题。
文件摘要值无法回答这些科学问题。

区分来源断言与自己的推导。“数据库 S 将蛋白 P 注释为与疾病 D 相关”不等于“我们的实验建立了 P 的因果治疗靶点地位”。
连接注释时保留证据类型、语境和日期。新版本可能改变映射；即使文件格式不变，更新也改变了分析输入，应该显式说明。

## 能下载不等于有权限

公开下载按钮不能自动解决再分发、商业使用、隐私或第三方权利。
分别检查确切数据、代码和模型资产的许可与条款。
[SPDX 许可概览](https://spdx.dev/learn/areas-of-interest/licensing/)帮助识别许可表达，但不会为未获许可的数据集授予使用权。
[Creative Commons FAQ](https://creativecommons.org/faq/)解释署名与不同 CC 许可之间的区别。
不要假定链接资产都继承外层论文或网站的许可。

记录检查了什么资产、条款在哪里、哪些预期用途受其覆盖，以及哪些问题仍未解决。
再分发不明确时，公开教程可以提供获取和预处理说明，而不复制原始记录。
受限人类数据和不明确权限需要相应机构或权利人的判断。本章讲数据工作流，不提供法律意见。

对于参与者来源数据，复用许可与参与者知情同意范围是不同问题。
仅移除直接身份标识，不足以建立所有连接或发布都获许可。
应保留责任机构批准的范围与未解决访问条件，不要因数据有科学价值就推断有权使用。

## 独立练习

1. 40 次测定观测连接后变成 52 行，因为其中 12 次观测各匹配两个蛋白异构体。实际收集了多少次观测？需要什么信息才能生成异构体特异性标签？
2. 60 行中，7 行单位无效，5 行身份缺失，2 行同时满足两种原因。排除任一问题后剩多少行？
3. 仓库许可覆盖代码，但 README 链接的第三方数据没有明确再分发条款。能否将其放进公开发布包？

<details data-worked-answer>
<summary>答案：保留总体与权限边界</summary>

仍是 40 次观测，不是 52 次。标明实际测量异构体或构建体的原始记录可能解决归属；两个候选注释本身不能。
排除总数为 `7+5−2=10`，剩余 50 行。代码许可不会补上第三方数据的缺失权利。
澄清条款前，不把数据复制进再分发包；在允许的情况下提供来源获取说明。
缺少使用权限不意味着科学数据不存在。
