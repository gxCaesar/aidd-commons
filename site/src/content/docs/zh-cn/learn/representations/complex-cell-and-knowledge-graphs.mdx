## 特征不是实验对象本身

先读[生物表示](/zh-cn/learn/representations/biological-representations/)、
[神经表示](/zh-cn/learn/machine-learning/neural-representations/)和
[实体消歧](/zh-cn/learn/data-governance/identity-lineage-and-reuse/)。
本章手算四类编码，跟踪维度，判断哪些变换应保留预测，并找出编码不能恢复的信息。
数值均为构造示例，不是模型实测输出。

好的表示让相关变化可被使用，同时压制无关变化。这取决于任务。
整体平移孤立复合物不应改变预测结合能，但删除配体相对口袋的朝向会丢失相关信息。
把一个供体的全部细胞压成单一向量可稳定群体摘要，也可能抹去稀有状态。没有一种嵌入适合所有任务。

## 蛋白序列：token、残基与池化特征

长度为 `L` 的蛋白可得到 `L×d` 的上下文残基特征矩阵。
序列级预测可池化成一个 `d` 维向量；残基级预测则必须保留相关位置。
[原始 ESM 仓库](https://github.com/facebookresearch/esm)演示逐残基特征提取及排除特殊 token 的序列平均。
这是一个具体 API 模式，不代表均值池化普遍最优，也不代表已归档仓库是最新模型。

为三残基序列构造以下特征：

```text
残基 1: [1, 0]
残基 2: [0, 2]
残基 3: [2, 1]
padding: [0, 0]
```

使用掩码的残基均值为 `[1,1]`。若对含 padding 的四行直接平均，结果为 `[0.75,0.75]`，使特征依赖批次填充。
起止特殊 token 也应按编码器规定处理，它们不是残基。
若位置 2 是催化位点，均值并未保留该位置的独立标识特征。
任务依赖位置时，应保留逐残基特征，或有依据地使用位点特异池化。

Tokenization 把提交序列映射到模型输入，不会解决生物身份问题。
须检查链边界、未知残基、截断和编号。全长参考序列上的突变，需要先映射到实测构建体，才能选取对应残基嵌入。
全蛋白池化向量不能悄悄代表每个异构体、切割产物或翻译后修饰状态。
预训练嵌入只是特征，高维度不会增加独立训练蛋白的数量。

比对改变的是位置对应关系，不只是序列长度。构造比对 `AC-D` 与 `ACED` 中，第一条序列第 3 个残基 D 对应比对第 4 列，
第 3 列是缺口，不是实测残基。表面点编码按指定几何规则采样可达边界；系综编码则在明确权重假设下表示多个状态。
表面不是序列比对，十个模型生成构象也不是十个实验测得的状态群体。连接特征时应保留这些对象间的映射。

## 复合物图：共价边与空间接触

配体–蛋白图可用原子或残基作节点。共价边表示化学键，空间边表示指定姿态下的邻近关系，二者应保留不同类型。
距离边不等于氢键、有利相互作用或实验支持的结合事件。质子化、几何、溶剂和竞争状态都可能超出邻近关系的信息。

设有两个配体原子 L1、L2，以及两个口袋节点 P1、P2。构造的交叉距离如下，单位为 ångström：

| 距离，Å | P1  | P2  |
| ------- | --- | --- |
| L1      | 3.0 | 6.0 |
| L2      | 4.5 | 5.5 |

定义接触为距离**不超过 5.0 Å**，配体到口袋邻接矩阵为 `[[1,0],[1,0]]`。
阈值改为 6.0 Å 后变为 `[[1,1],[1,1]]`。模型没有发现新相互作用，而是表示规则改变了。
连续径向特征可避免这种硬阈值不连续，但仍需规定距离范围、尺度和邻域约定。

同时旋转配体和蛋白不改变这些距离；仅旋转配体可能改变距离，表示另一个姿态。
只使用成对距离的模型也无法区分整体构型及其完整镜像。手性重要时，这可能不合适，应让特征与对称性假设符合化学任务。
若图中没有水或必需辅因子，图本身就不包含其位置；模型仍可能利用训练相关性进行猜测，但这不是恢复了遗漏对象。

## 细胞状态：带生物语境的矩阵

表达表示常从“细胞×基因”矩阵开始。
[AnnData 文档](https://anndata.readthedocs.io/en/stable/)介绍带注释矩阵容器：观测与变量需要对齐注释，其他表示可单独存放。
容器不会决定一行是否为独立生物重复。

细胞状态预测输入应区分扰动前语境与干预本身：可用时保留细胞类型或状态、供体、条件、扰动身份、剂量和观测时间。
把扰动编码为 token，前提是其含义及可用性明确。给基因随机分配整数，不应暗示基因 20 是基因 10 的两倍。
类别嵌入学习关系；序列或通路特征则引入另一类先验。

构造两个细胞，基因 G 的计数均为 100，总计数分别为 1,000 和 2,000。
按总计数归一化到 10,000 后，G 分别为 1,000 和 500。
记录的 G 计数不变，归一化值却减半。这说明它依赖分母，不证明 G 的绝对生物表达减半。
捕获效率与组成同样影响解释。[Scanpy 归一化文档](https://scanpy.readthedocs.io/en/stable/generated/scanpy.pp.normalize_total.html)
定义该缩放及影响 size factor 的选项。

基因顺序错位同样严重：未重新索引时，`[G1,G2]` 与 `[G2,G1]` 向量不能逐位置比较。
区分原始计数、变换值和学习到的潜在特征。
即使最终预测器没有直接读取测试响应列，使用留出响应拟合特征选择或监督状态编码器，也会暴露评价信息。

若声称泛化到未见供体，两个供体的数千个细胞仍只有两个供体单位。
若声称泛化到未见扰动，就要同时指定留出身份与语境。
对照均值或仅使用语境的预测器，可检查无需干预身份就能预测多少终点，但不是所有生物假设的通用零假设。

## 知识图谱：关系必须带证据

[RDF 1.1](https://www.w3.org/TR/rdf11-concepts/)用主语–谓词–宾语三元组表示陈述。
科学图谱中的谓词必须保留含义。`compound inhibits protein`、`gene associated_with disease` 和 `paper mentions gene`
即使都成为边，也不是同一种关系。

构造一条记录：化合物 C 在语境 X 的测定 A 中抑制蛋白 P，由来源 S 报告。
裸三元组 `(C, inhibits, P)` 丢掉了测定与语境。
显式证据节点或带限定的关系可保留终点、来源、方向、日期和不确定性。
[PROV-O 词汇](https://www.w3.org/TR/prov-o/)可描述推导关系，但图格式本身不会让断言成为事实。

两个网站重复同一篇测定论文，不代表两次独立实验。
若留出边 `(C, inhibits, P)` 的精确逆关系 `(P, inhibited_by, C)` 在训练图中，预测前者可能只是重建捷径，不是发现。
划分前应把逆关系和重复证据分组。还要冻结时间可用性：宣称发现日期之后汇总的图，可能通过后续文献编码答案。

边缺失通常表示未知，不等于实验确认的阴性。
训练链接预测时从缺失关系中采样“负例”是一项建模约定。
应报告此约定，并评价这些容易的例子是否接近真实候选总体。
证据边、实体特征与训练目标应有不同角色，避免无意中把答案作为输入。

## 从已沉积的复合物构建它们

[EGFR 结构证据实验](/zh-cn/labs/egfr-structure-evidence/)从三个已沉积的复合物构建接触、
相互作用与指纹表示。一个 3.5 A 的极性接触只有在已声明的质子化角色之下才可能是氢键；
同一个配体在两种受体状态中只共享 65% 的残基相互作用位。

## 独立练习

1. 两个残基向量为 `[2,0]` 与 `[0,4]`，另有两行 padding。计算正确的掩码均值和错误的直接均值。
2. 距离表使用包含边界的 4.5 Å 阈值时有几条接触？整体平移是否构成新姿态？
3. 一个细胞的 G 计数为 50、总计数 500；另一个为 100、总计数 1,000。归一化到 10,000 后各是多少？相等是否证明绝对表达相等？
4. 测试关联以另一个数据库编号出现在训练中，但实际上是同一实体对。划分前必须先做什么？

<details data-worked-answer>
<summary>答案：检查掩码、语境与信息损失</summary>

掩码均值为 `[1,2]`，直接平均四行为 `[0.5,1]`。
有两条接触，L1–P1 与 L2–P1。整体平移不改变相对姿态。
两个归一化基因值均为 1,000，但相对值相等不能建立绝对表达相等。
划分前须完成实体消歧，并对重复和逆向证据分组；改变标签字符串不会产生独立的新关系。

</details>
