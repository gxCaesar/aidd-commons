## 学习目标与预备知识

完成本课后，你应能把一个 AIDD 主张的决策单位写成四个字段，说出一个报告的指标是哪句话的
证据，并指出一次提议的比较悄悄改变了哪个字段。请先阅读[从 AIDD 流水线开始](/zh-cn/learn/foundations/getting-started/)
和[阅读来源并识别它描述的生物对象](/zh-cn/learn/foundations/source-and-entity-literacy/)。

**模式：阅读既有结果。** 推导案例读取的是本仓库中已经提交的数字，来自一次已完成、已冻结
的评估。没有任何东西被运行、重新训练或重新取样，也不需要任何命令。末尾的可选检查路线会
对相同的已提交文件运行一条离线命令。

## 模型之前的四个字段

在 AI 驱动的药物发现中，一个主张总是关于某个对象、出于某个目的、在某些条件之下，并在
某个单位上泛化。把这四件事写下来，就是决策单位。

| 字段     | 它回答的问题                                                                                               | 保持隐含时会出的错                                                                   |
| -------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 科学对象 | 一行代表什么，预测的对象又是什么？可以是一个母体分子、一种盐型、一个检测孔、一个蛋白构建体或一个患者样本。 | 同一个对象的两行被当成两条证据，或者一个关于盐型的结果被读作关于母体分子的结果。     |
| 预期行动 | 输出将改变哪个决策，在哪些候选之间选择，预算是多少？                                                       | 被优化的指标是决策根本用不到的那个，例如只会合成排名前十的化合物时却去优化平均误差。 |
| 实验语境 | 在哪种检测、终点、单位、纳入规则、目标状态和数据版本下，一个标签才意味着它所意味的东西？                   | 来自不同语境的标签被汇总，仿佛它们测量的是同一个量。                                 |
| 推断单位 | 主张打算在哪个独立单位上泛化？这决定了拟合与评估之间绝不能共享什么，以及 `n` 计的是什么。                  | 随机的按行划分会让同一个单位的近似副本同时出现在两侧，把插值报告成泛化。             |

选择人群属于预期行动这个字段。它是这个行动实际将要作用的候选集合，可以与模型见过的任何
集合都不同。

这些字段并不独立。推断单位由预期行动和语境决定，而不是由怎么划分最容易决定。如果行动是
对尚无人合成过的化学系列中的化合物排序，那么单位就是系列，而一个在拟合和测试之间共享
系列的评估，回答的是另一个问题。

## 推导案例：一个模型，两句话

本仓库保存着一次已完成、已冻结的评估，针对人类 EGFR 激酶的两个 ChEMBL 37 检测。它于
2026-09-08 在本地 Mac CPU 上运行，使用 Python 3.11.15、NumPy 2.4.6、scikit-learn 1.9.0
和 RDKit 2025.09.6。它的锁定摘要以 `labs/chembl_egfr/locked-summary.json` 的形式提交，
本课只读取了它，没有重新运行。

先说明六个术语。**pChEMBL** 是摩尔效力值以 10 为底的负对数，所以 1 nM 的 IC50 得到 9，
100 nM 的得到 7，数值越高表示化合物效力越强。这里的 **Morgan 指纹** 是一个 2,048 位的
二进制向量，标记分子中半径达 2 的环状子结构。**描述符** 表示是来自 RDKit 的 214 个计算
得到的全分子属性，缺失值用训练集中位数填补，每个属性只在训练分子上做缩放。**岭回归**
拟合一个对系数大小施加惩罚的线性模型。每个模型只在训练分子上拟合，其惩罚强度取固定网格中
在验证分子上平均绝对误差最低的那个值。**Bemis–Murcko 骨架** 保留分子的环系统及其间的
连接体，去掉侧链，因此相近的类似物通常共享同一个骨架。**Spearman 秩相关** 比较预测值与
实测值的排序，取值从 −1 到 1，0 表示没有单调关联。

**句子 A。** "对于骨架未在拟合中出现过的化合物，在检测 CHEMBL5736995 中测量，一个
Morgan 指纹岭回归模型预测 pChEMBL 的平均绝对误差低于一个描述符岭回归模型。"

| 字段     | 冻结契约中的值                                                                                                                                                                                                                                                   |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 科学对象 | 标准化后的 ChEMBL 母体分子。966 条被纳入的记录描述了 902 个母体分子，同一母体分子上的重复测量被归约为其中位数。57 个母体分子存在重复测量，其单个母体分子内数值范围的中位数为 0.48 个 pChEMBL 单位，最大为 3.60，因此对某些母体分子而言，中位数掩盖了真实的分歧。 |
| 预期行动 | 为在这个检测中预测来自未见骨架的化合物的 pChEMBL 值选择一种表示方式。                                                                                                                                                                                            |
| 实验语境 | 针对 EGFR（ChEMBL 靶点 CHEMBL203）的检测 CHEMBL5736995，ChEMBL 将其归类为结合检测，其描述记录为一种 TR-FRET 生化激酶检测。只包含精确的纳摩尔 IC50 记录，以 pChEMBL 表示。                                                                                        |
| 推断单位 | 考虑手性的 Bemis–Murcko 骨架。902 个母体分子落入 238 个骨架，按整体、从大到小优先分配为 634 个训练、136 个验证和 132 个锁定评估母体分子。                                                                                                                        |

推断单位同时也说明了这些数字所描述的是哪些化合物。因为整块骨架是按从大到小优先填充的，
634 个训练母体分子落在 53 个骨架中，而 132 个锁定母体分子来自 124 个骨架，其中 116 个
骨架仅由一个母体分子代表。这些计数于 2026-09-11 从本实验的划分成员记录中统计得到。该记录留在本地，因为它列出了
锁定评估的成员，这里只报告计数。
因此，锁定的数字讲的是来自没有人拟合过的小骨架的化合物，而不是一个大系列的典型新类似物。

在这 132 个锁定的母体分子上：

| 模型               | 平均绝对误差（pChEMBL） | Spearman 秩相关 |
| ------------------ | ----------------------: | --------------: |
| 训练集均值（常数） |                   0.479 |          无定义 |
| 描述符岭回归       |                   0.469 |           0.129 |
| Morgan 岭回归      |                   0.418 |           0.505 |

常数预测没有顺序，所以它的秩相关是无定义的，而不是零。把误差比较从存档的数值推演一遍。
Morgan 岭回归比常数基线低 0.061 个 pChEMBL 单位，约为基线误差的 13%，比描述符岭回归低
0.050 个单位，约为该模型误差的 11%。若改为用表中四舍五入后的条目相减，会得到
`0.469 − 0.418 = 0.051`，这正是为什么要先算出差值、再对其四舍五入的原因。

这些数字是句子 A 的证据，但要受制于锁定摘要自己记录的告诫。在这次评估运行之前，一个独立
的教学实验已经接触过与它共享的标签，因此这不是一次未经触碰的确证。没有计算置信区间或
p 值。所选的描述符惩罚项落在其冻结网格的上边缘。

**句子 B。** "一个 Morgan 指纹岭回归模型预测 EGFR 效力。"

按这种句子通常被理解的方式来读，句子 B 是一个关于 EGFR 效力的一般性主张。它保留了对象
和模型，却在不声明的情况下放宽了两个字段。语境变成了任意 EGFR 检测，推断单位变成了任意
EGFR 化合物。主要结果是与它一致的一个实例，而一个实例不能确立一个一般性主张。这次冻结
评估恰好还测量了另一个语境，检测 CHEMBL3705421。它同样是一个 EGFR 酶检测，带有相同的
检测格式标注，但来自不同的文献并使用不同的商业试剂盒。它的 170 个母体分子与主检测没有
共享任何母体分子，落入 23 个骨架。已拟合的模型被原样应用于它。

| 模型               | 在 CHEMBL3705421 上的平均绝对误差 | Spearman 秩相关 |
| ------------------ | --------------------------------: | --------------: |
| 训练集均值（常数） |                             0.898 |          无定义 |
| 描述符岭回归       |                             0.579 |           0.113 |
| Morgan 岭回归      |                             3.132 |          −0.041 |

在句子 A 之下获胜的那种表示，在测试过的另一个语境中，误差是预测常数的
`3.132 / 0.898 ≈ 3.5` 倍，它在那里的秩相关为 −0.041，基本没有关联。句子 A 得到了支持。句子 B 作为
一个关于 EGFR 效力的一般性主张，被测试过的另一个语境所反驳，本仓库中没有任何证据支持比
句子 A 更宽泛的主张。模型在两句话之间没有改变，改变的是决策单位。

## 改变行动，单位随之改变

保留句子 A 的对象和语境，只改变预期行动。在一个**构造的**场景中，一个团队手上有一个在
其训练数据中已有大量化合物的大骨架，必须从中选出接下来要合成的 15 个提议类似物。行动现在
是在一个已知骨架内部对新化合物排序，因此推断单位变成了训练数据中已有系列内的新类似物，而
决策所需要的证据是该骨架内部的排序质量，理想情况下按时间前瞻的方式加以检验。

冻结的数字里没有一个测量了这一点。它们汇总了全部 132 个锁定母体分子，这些分子来自拟合
中未见过的骨架，其中 116 个骨架只含一个母体分子。锁定集中只有八个骨架各含两个母体分子，因此骨架内部
的排序在这里没有被报告，最多也只能在八对分子上检查。正确的理解不是模型在这个决策上失败了，而是这次评估对此什么也没说。写出决策
单位，正是让你在类似物被合成之前就注意到这一点的方式。

## 独立练习

一份**构造的**报告写道："我们的 hERG 分类器在整个产品组合中都很准确，在汇总自三个
hERG 检测的 4,000 条记录上做随机 80/20 划分，AUROC 为 0.86。"hERG 是一种心脏钾离子通道，
阻断它的化合物会被标记为安全风险。AUROC 是随机选取的一个阳性样本得分高于随机选取的一个
阴性样本的概率，因此 0.5 等于随机水平。这个分类器是在这些记录上训练的，而这个团队的
五个在研化学系列都出现在其中。团队打算用它为这五个系列中已提议但尚未合成的类似物降低
优先级。

1. 按报告暗示的方式，以及按预期行动要求的方式，分别写出这四个字段。
2. 哪个字段不匹配，哪个字段缺失？
3. 说出一项与这个预期行动相关的评估。

<details data-worked-answer>
<summary>参考答案</summary>

| 字段     | 报告暗示的方式                                                                         | 行动要求的方式                                           |
| -------- | -------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 科学对象 | 汇总自三个检测的记录。这些记录覆盖多少化合物，以及同一化合物是否不止出现一次，均未说明 | 在决策所用检测中，每个母体化合物一条记录                 |
| 预期行动 | 未说明                                                                                 | 在合成之前，为五个指名系列中的提议类似物降低优先级       |
| 实验语境 | 三个 hERG 检测被汇总。它们是否共享同一终点、决策依赖其中哪一个，均未说明。没有给出阈值 | 决策将使用的检测、终点和活性阈值                         |
| 推断单位 | 随机的一条记录                                                                         | 训练数据中已有的五个系列之一内的新类似物，按时间前瞻检验 |

推断单位不匹配。这个决策要为该模型已经认识的系列中未来出现的类似物打分，因此匹配的评估
应当在这些系列内部留出最近合成的化合物，做一次按时间划分，并按系列报告结果。对记录做
随机划分回答的是一个更容易的问题。除非在划分之前已经按化合物和按系列对记录分组，否则
相近的类似物，以及同一化合物的任何重复记录，都可能同时落在两侧，0.86 于是可能在很大
程度上反映的是已知化合物之间的插值。在信任这个数字之前，先检查其成员归属。一个按系列留出的划分会
回答一个更难的问题，但这只有在将对新系列打分时才重要。

实验语境缺失。报告没有说明这三个检测是否测量同一个终点，也没有说明决策依赖其中哪一个，
而汇总的标签只有在它们一致时才表示同一件事。没有阈值，就没人能说清一次阳性判定意味着
什么。即便是一次匹配良好的按时间划分，也只是关于与提议化合物
相似的化合物的回顾性证据，而不是对它们本身的测量。

</details>

## 本课没有展示什么

这四个字段是必要的，但不是充分的。写出它们不会让骨架在每个任务里都是正确的单位，不会
修补一个选得不好的终点，也不会把一次回顾性评估变成一次前瞻性评估。这个推导案例是针对
一个靶点的两个检测的一次冻结评估。它的第二个检测是单一语境，不是对 EGFR 检测的一次
概览。
