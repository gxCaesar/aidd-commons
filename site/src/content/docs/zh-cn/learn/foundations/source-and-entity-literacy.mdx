## 名词背后隐藏的问题

完成[第一次学习](/zh-cn/learn/foundations/first-session/)后，下一项有用能力是追问
某个来源中的“化合物”“靶点”“样本”或“开放模型”到底指什么。本课区分标识符与实体，
把引用对应到实际主张，并判断何时数据连接仍未解决。无需代码或机器学习基础，记录均为编造例子。

“蛋白 P 结合化合物 A”并不完整。P 可能是基因、标准序列、异构体、工程构建体或解析结构；
A 可能是母体结构、盐、立体异构体、供应商样品或批次。“结合”可能指测定结果、计算分数，
或从另一篇文章引用的说法。这些区别决定记录能否回答同一个问题。

## 不应合并的三类身份

区分存放说法的**来源记录**、说法指向的**物理或生物实体**，以及模型训练评估所用的
**分析单位**。一个来源可以包含同一实体的多次测量，一个通用名称也可能覆盖不同构建体或化学形式。
字符串相等不足以确定这些关系。

蛋白应保留 accession 及相关序列/异构体版本，而不只有显示名称。
[UniProt accession 文档](https://www.uniprot.org/help/accession_numbers)
解释条目标识符及其持久性；accession 指向条目，不代替准确实验构建体。
分子方面，[PubChem 数据库原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4702940/)
区分提交者提供的 substance 记录与标准化 compound 记录。数据库身份本身都不能说明测定如何进行。

构造一个有六行记录的发布文件：

| 记录    | 对象描述               | 测量语境         |
| ------- | ---------------------- | ---------------- |
| r1      | 化合物 A，批次 1       | 测定 X，第 1 天  |
| r2      | 化合物 A，批次 1       | 测定 X，第 2 天  |
| r3      | A 的相反立体异构体     | 测定 X，第 1 天  |
| r4      | A 的盐形式             | 测定 X，第 1 天  |
| r5      | 化合物 A，批次 1       | 测定 Y，不同读出 |
| r1-copy | 与 r1 相同的已提交观测 | 镜像导出         |

六行只描述五次观测，r1-copy 不增加测量。r3 的身份差异可能有意义。
r4 能否与 A 汇总，取决于声明的终点与审查后的标准化，而不是普遍的“去盐规则”。
r5 更换了测定，不能悄悄变成 X 的重复。即便 r1、r2 也可能共享批次效应。
仅凭此表不能认定有五个独立实验单位。

## 让证据对应正在写的句子

区分论文方法、结果、仓库实现、模型卡与许可。论文可以展示实验，却不提供训练数据；
仓库可以提供推理代码，却不提供训练配方。推理例子也不能证明输出在新环境中得到实验验证。
检查来源时应逐句解决主张。

假设一个编造项目页面宣布开放推理代码，而论文模型使用无法获得的数据训练。
合适表述是“推理代码可用，训练数据访问尚未确定”，而不是“该方法完全可复现”。
如果结果表只评估一个蛋白家族，也不能支持“适用于所有靶点类别”的句子。

打开来源后定位实际方法、表格或资产条款，记录版本/日期，并区分来源陈述与你的推断。
若只能阅读摘要，就只引用摘要能确定的内容。搜索摘要是待核查线索，不能代替底层证据。

## 可访问与获准使用是两回事

文件可访问回答“能否取得”，适用条款回答“允许怎样使用”。代码、权重、数据与文字可能
采用不同条款。[SPDX 标识符](https://spdx.dev/learn/areas-of-interest/licensing/)
有助于无歧义地命名许可，但不会自动给所有相邻资产授权。
[Creative Commons FAQ](https://creativecommons.org/faq/)也说明许可未必覆盖超出授权者
权限的其他权利。本课教授检查对象，不对实际部署作法律认定。

对于编造的软件包，假设代码明确采用许可 L，权重采用独立条款 W，数据集链接没有可见条款。
应分别记录三项，不能把 L 复制到数据项。若预期再分发依赖尚不明确的数据权利，
打包前需指出未解决问题；与此同时，仍可以阅读科学方法并使用另一个独立获准的例子。

## 独立练习

论文报告酶构建体测定，数据库却使用母体基因名称。两个镜像复制同一表格。
推理仓库可见，但未找到权重条款。写四句话：最强可支持的生物学主张、未解决的身份连接、
两个镜像代表的独立出版物数量，以及未解决的资产许可。
