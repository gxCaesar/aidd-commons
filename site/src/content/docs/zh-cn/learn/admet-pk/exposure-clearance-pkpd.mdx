## 暴露回答的是什么问题？

先读 [ADMET 评估](/zh-cn/learn/admet-pk/admet-evaluation/)和
[测定对照与剂量反应](/zh-cn/learn/drug-discovery-foundations/assay-controls-dose-response/)。
本课将推导浓度—时间曲线，区分清除率与衰减常数，并解释为什么用单一暴露数值给
化合物排序会失效。以下数值全部为手算而编造，不是患者数据、给药建议或经过验证的
候选项选择规则。

测定浓度描述特定实验体系中存在的物质量。给入的量并不直接说明靶点处的浓度怎样
随时间变化。PK 模型描述这条时间曲线；PD 模型将明确的暴露与明确的反应关联起来。
两类模型都不会自动补齐“该反应对生物体有益”的证据。FDA 的
[暴露—反应指南第 IV–V 节](https://www.fda.gov/media/71277/download)
区分了暴露度量、反应终点及其时间关系。

## 推导一个最小 PK 模型

令 `A(t)` 为单个充分混合室内的量，`V` 为表观分布容积，`C(t) = A(t)/V` 为浓度。
这里的 `V` 是量与浓度之比，不是字面意义的解剖容器。假设 `V` 和清除率 `CL` 为
正常数、消除为一级过程，并在初始量 `A₀` 直接进入该室后不再有输入：

```text
dA/dt = −CL C = −(CL/V) A
k = CL/V
C(t) = (A₀/V) exp(−kt)
t½ = ln(2)/k
AUC₀→∞ = ∫₀∞ C(t) dt = A₀/CL
```

分离变量得到 `dA/A = −k dt`，因此得到指数衰减；对曲线积分得到最后一式。
清除率的单位是体积/时间，而 `k` 的单位是时间的倒数，两者不能直接替换。
[mrgsolve 模型说明](https://mrgsolve.org/user-guide/specification.html)
区分量与浓度，并明确使用 `−(CL/V) × amount` 实现消除项。

若通过另一途径输入总量 `D`，其中比例 `F` 到达体循环，那么在线性、时不变消除且
完整随访的条件下，`AUC₀→∞ = F D/CL`。这个关于积分暴露的关系**不意味着**口服
吸收是瞬时输入。若 `F` 未知，`D/AUC` 只能识别表观清除率 `CL/F`，不能识别 `CL`。
缓慢吸收或多个分布室也会使观测终末斜率不能未经检查就解释为该一室模型的 `CL/V`。

## 手算曲线，以及拟合究竟学习什么

构造化合物 A，取 `A₀ = 40 µmol`、`V = 20 L`、`CL = 2 L/h`。
于是 `C(0) = 2 µmol/L`、`k = 0.1 h⁻¹`、半衰期约 `6.931 h`，AUC 为
`20 µmol·h/L`。经过一个、两个半衰期，浓度分别为 1 和 0.5 µmol/L。
这些数值来自人为指定的方程，不是测量值。

假如这三个数值来自无误差测量，对数浓度斜率便是 `−0.1 h⁻¹`。已知初始体循环量
并结合截距，可以识别 `V`；再用 `k V` 识别 `CL`。存在噪声时，应对观测数据拟合
参数，而不是对同一个已拟合模型产生的数据拟合。一个明确的目标是
`Σᵢ wᵢ[Cobs(tᵢ) − Cmodel(tᵢ; θ)]²`，其中正权重说明误差模型，`θ` 包含待拟合参数。
若改为拟合对数浓度，就改变了残差的权重方式。

灵活曲线能够贴合少数时间点，不意味着参数可以被识别。应保留途径、时间、基质、
测量限和个体身份。同一动物的重复采样构成一条轨迹，不是更多独立动物。
[mrgsolve 的带注释模型](https://mrgsolve.org/user-guide/topics.html#annotated-model-specification)
展示了结构方程、个体差异和观测误差是模型说明中的不同部分。本课没有运行参数估计软件。

## 总暴露不等于游离暴露

将 `fᵤ` 定义为所测血浆基质中的游离比例。结合比例恒定时，
`Cᵤ(t) = fᵤ Ctotal(t)`，且 `AUCu = fᵤ AUCtotal`。蛋白结合可随浓度和语境变化；
血浆游离浓度也不自动等于靶点处浓度。FDA 指南
[第 V.C.1.e 节](https://www.fda.gov/media/71277/download)解释了为什么总浓度与游离
浓度测量可能支持不同的 PK/PD 解读。

为了构造一个边界明确的直接反应例子，假定靶点处浓度等于 `Cᵤ`，反应没有延迟，
两个化合物共享 `EC50,u = 0.2 µmol/L`。定义归一化效应增量：

```text
e(t) = Cᵤ(t) / [EC50,u + Cᵤ(t)]
```

这是将最大增量归一化为 1 的饱和 Emax 关系，不是反应概率，也不是结合常数。
[Pharmpy 直接效应文档](https://pharmpy.github.io/latest/api/pharmpy.modeling.set_direct_effect.html)
使用包含显式基线与幅度的相关 Emax 模型；将该模型的基线设为零，不会得到本课的
归一化增量。若反应有延迟，就需要效应室或周转过程等不同模型，而不是把当前曲线
无解释地水平移动。

给 A 指定 `fᵤ = 0.05`。再构造 B，使初始量与容积相同，但
`CL = 4 L/h`、`fᵤ = 0.20`：

| 量                         | 化合物 A | 化合物 B |
| -------------------------- | -------- | -------- |
| 总 AUC，µmol·h/L           | 20       | 10       |
| 游离 AUC，µmol·h/L         | 1        | 2        |
| 初始游离浓度，µmol/L       | 0.10     | 0.40     |
| 初始归一化效应增量         | 1/3      | 2/3      |
| 6.931 h 时的归一化效应增量 | 0.20     | 1/3      |

此时 A 的总浓度为 1；B 已经过两个半衰期，总浓度为 0.5 µmol/L。分别乘以游离
比例，得到 0.05 和 0.10 µmol/L，再代入方程得到最后一行。因此在这个例子中，
A 的总 AUC 更大，却没有更大的效应。表格比较的是两组完整的假设参数，并**不预测**
化学家改变蛋白结合而又设法保持清除率不变会发生什么。几个时点的效应增量不等于
累计获益，也不说明 B 更安全；两个构造都没有毒性、选择性或组织暴露数据。

## 已工作案例：一种清除率检测能预测另一种吗？

前面几节都只用了一个人为指定的 `CL`。真实化合物并没有唯一的清除率数字：
同一个化合物在不同检测体系下测出的值可以互不相同。
[AZ 清除率体系实验](/zh-cn/labs/az-clearance-system/)读取的是阿斯利康
直接存入的真实 ChEMBL 37 数据集(文献 `CHEMBL3301361`，不是付费期刊论文)，
报告了真实化合物在三种具名体系下的内在清除率：人肝微粒体、人肝细胞、
大鼠肝细胞。于 2026-09-12 计算：

| 比较 | 重叠化合物数 | Spearman rho |
| --- | ---: | ---: |
| 人肝细胞 vs 大鼠肝细胞（物种不同，基质固定） | 106 | 0.4732 |
| 人肝微粒体 vs 人肝细胞（基质不同，物种固定） | 96 | 0.4864 |
| 人肝微粒体 vs 大鼠肝细胞（两者都不同） | 359 | 0.3868 |

三对比较中,任何一对都不能强预测另一对:每个 rho 都明显低于 1。两个肝细胞
检测共用同一单位,那里具名的例子在两个方向上都能相差十倍以上;微粒体检测
报告的是不同的物理量(按每克蛋白计,不是按每个细胞计),所以它与任一肝细胞
检测的分歧是一个真实的同方向信号,而不是字面上的倍数关系。无论如何,固定
基质换物种,或固定物种换基质,都会让数字改变到这种程度——不点名三种体系中
究竟是哪一种,单一的"这个化合物的清除率"这句话就无法与这些真实记录中的
任何一条相互核对。

**独立练习(点名检测体系):** 一张幻灯片写道:"化合物 X 的内在清除率为
18 mL/min/g。"仅使用上面的比较,说出这句话遗留的两个问题,并说明每个问题
的答案若发生变化会带来什么风险。

<details data-worked-answer>
<summary>参考答案</summary>

这句话没有说明是哪个物种测出的(在这个真实数据集里,人和大鼠肝细胞清除率
只呈弱相关,rho ≈ 0.47,所以大鼠的值不能替代人的值),也没有说明是哪种
基质测出的(人肝微粒体与人肝细胞清除率同样只呈弱相关,rho ≈ 0.49,所以
亚细胞组分检测也不能替代全细胞检测)。任何一个答错,都等于把两个真实但
提供不同信息的测量当成了同一个数字——这正是本课结尾部分所警告的那种混同。

## 独立练习

从 A 构造 C，仅将假设容积改为 `40 L`，保留 `A₀ = 40 µmol`、`CL = 2 L/h`、
`fᵤ = 0.05` 和 `EC50,u = 0.2 µmol/L`。计算初始浓度、半衰期、总 AUC 和初始
效应增量。在这里，半衰期更长是否意味着总暴露更大？另有一项口服实验报告
`D/AUC = 4 L/h`，但没有确定 `F`；它能否确定清除率就是 `4 L/h`？

<details data-worked-answer>
<summary>参考答案 — 分开考虑容积、清除率和反应</summary>

C 的初始浓度是 `1 µmol/L`，`k = 0.05 h⁻¹`，所以半衰期约 `13.863 h`。
总 AUC 仍为 `40/2 = 20 µmol·h/L`。初始游离浓度为 `0.05 µmol/L`，所以效应
增量为 `0.05/(0.2 + 0.05) = 0.20`。当初始量与清除率固定，增加容积改变的是
曲线高度和衰减时间，而不是曲线面积。

在给定的线性假设下，口服结果只识别 `CL/F = 4 L/h`。例如，`F = 0.5` 时意味着
`CL = 2 L/h`；`F = 1` 时意味着 `4 L/h`。仅凭该观测无法选择其中之一。
这些计算既不能选择人体剂量，也不能证明靶点处的效应有益。

</details>

## 回到药物发现决策

面对 AIDD 预测，先问标签对应哪个测量量：内在清除率、全身清除率、`CL/F`、
总浓度、游离浓度，还是反应。将它们混成一个“ADMET 分数”，会破坏刚才建立的
解释，[AZ 清除率体系实验](/zh-cn/labs/az-clearance-system/)在真实数据上
展示了同样的混同,而不是靠一个构造例子。物种、制剂、转运、活性代谢物和
毒性在本课中仍是独立证据缺口。继续阅读[AZ 清除率体系实验](/zh-cn/labs/az-clearance-system/)
亲自运行这个物种/基质比较，或阅读[候选项提名](/zh-cn/learn/candidate-nomination/capstone/)
时，应保留这些缺口，而不是将它们转换为有利预测。

FDA 指南与 mrgsolve/Pharmpy 来源于 2026-09-09 打开，支持推导过程，不支持
构造出的 A/B/C 数值。ChEMBL 数字于 2026-09-12 实时抓取，用本实验自己的
`show` 命令即可复现。
