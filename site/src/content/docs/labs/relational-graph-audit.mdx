## Preparation and learning objectives

This laboratory serves `t05-relational-knowledge-graph-representation`. Read [typed relations and evidence](/learn/representations/relational-graph-evidence/) first. You will distinguish a node kind from a relation type, trace an edge to the record that declares it, and test why a shared task or stage cannot establish a missing relation. Familiarity with YAML and directed graphs is useful.

Mode is fresh independent computation over a frozen protocol and the committed catalogue. Use the project Python 3.11 environment and CPU. The commands need no network, download or accelerator. The first three commands write nothing. The exporter overwrites only the small committed summary after all checks pass.

```bash
.venv/bin/python labs/relational_graph_audit/run_lab.py check
.venv/bin/python labs/relational_graph_audit/inspect_relational_graph_audit.py show
.venv/bin/python labs/relational_graph_audit/inspect_relational_graph_audit.py check
.venv/bin/python labs/relational_graph_audit/export_summary.py
.venv/bin/python -m pytest labs/tests/relational_graph_audit -q
```

## Source records and graph contract

The audit reads 228 committed resource records in the local catalogue snapshot recomputed on 2026-10-25. Each record supplies one typed node. A `relations` entry supplies a directed edge from its declaring record to the named target. The loader refuses a missing target, duplicate identifier or undeclared type. An edge is evidenced only when an evidence entry in its declaring record names `relations` in `supports`. The inspector prints the evidence identifiers, and the check refuses an unevidenced edge before export.

The tables report the computation dated 2026-10-25 with Python 3.11.15 and PyYAML 6.0.3. The node table counts each record once. The isolated column counts records that declare no outgoing relation. A target with an incoming edge can therefore appear in that column.

## Candidate pairs and isolated nodes

An unordered pair becomes a candidate when the records share at least 1 task or at least 1 stage and neither declares a relation to the other. The audit finds 10100 such pairs. It does not add them to the 39 declared edges. `model-opendde`, `model-pocket2mol` and `model-targetdiff` each occur in 158 candidate pairs, the largest observed counts. Shared metadata makes a pair worth inspecting, not a prediction that its records should be joined.

The 192 records with no outgoing declaration are listed by kind in the inspector and committed summary. `model-rxnflow` is among them even though `model-cgflow` points to it. This is the protocol's declaration-based isolation measure, not the graph-theoretic claim that the node has degree 0.

## Limits of the material

The graph records what this catalogue declares and what its entries cite. The audit does not independently verify every linked page, decide whether the declared relation is true, or infer causality. A missing declaration is not an experimentally established negative. A candidate pair is not a relation, and a path through resource records is not a biological mechanism.
