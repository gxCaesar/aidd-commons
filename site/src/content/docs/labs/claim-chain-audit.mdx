## Preparation and learning objectives

This laboratory serves `t18-evidence-package-claim-chain`. Read the [candidate-nomination capstone workbook](/learn/candidate-nomination/capstone-workbook/) before running it. You will resolve each named link against its evidence entry, distinguish a written exercise from a runnable task, locate the weakest link and compare the project record with an independent reading. Familiarity with YAML is useful. No model training is required.

## Mode and commands

Mode is a fresh independent computation over a frozen protocol and the repository's own committed comparison records. Use Python 3.11.15 and PyYAML 6.0.3 on a CPU. The commands need no network, download or accelerator. Run them from the repository root. `download`, `show` and `check` write nothing. Export overwrites only this laboratory's compact summary after the checks pass.

```bash
.venv/bin/python labs/claim_chain_audit/run_lab.py download
.venv/bin/python labs/claim_chain_audit/inspect_claim_chain_audit.py show
.venv/bin/python labs/claim_chain_audit/inspect_claim_chain_audit.py check
.venv/bin/python labs/claim_chain_audit/export_summary.py
.venv/bin/python -m pytest labs/tests/claim_chain_audit -q
```

## Weakest links

A chain is as strong as its weakest link. The inspector takes the minimum effective depth, identifies the first topic at that depth and counts links below the strongest state reached in the same chain. All 16 selected links currently resolve to opened evidence. An empty evidence list or evidence whose entries are all other than `opened` makes its link unresolved and prevents a supported-chain report.

## Independent check

Consider a copy of the first chain in which the mechanism topic's evidence entries are no longer `opened`. Predict its weakest link and supported status before running `check` on a constructed test record. The link becomes `unresolved`, the mechanism topic is the weakest link and the chain cannot be reported as supported. Averaging the remaining depths would miss that refusal.

## Limits of the material

A chain establishes that each named link's material exists and says what it says. It does not establish a claim about a compound, a target or a therapy. Its endpoints are only the topics it names. The selected topics do not describe one shared candidate, and the project's own depth label does not verify the scientific correctness of the material behind it. A passing check enforces these boundaries and does not measure reader learning.
