## Preparation and learning objectives

This laboratory serves `t01-evidence-claim-unknown`. Read [Evidence, claims and unresolved fields](/learn/foundations/evidence-claims-and-unknowns/) and [source and entity literacy](/learn/foundations/source-and-entity-literacy/) first. You will distinguish an evidenced depth, an interval, an unsupported depth and a declared unknown. You will also compare the project's stated depth with an independent reading and inspect the conditions attached to its superlative claims. Familiarity with YAML helps, but no modelling experience is required.

## Mode and commands

Mode is a fresh independent computation over a frozen protocol and committed comparison records. Use the project Python 3.11.15 environment with PyYAML 6.0.3 and CPU. The commands need no network, download or accelerator. Run them from the repository root. `check` and `show` write nothing. The exporter overwrites only the compact summary after the checks pass.

```bash
.venv/bin/python labs/claims_evidence_audit/run_lab.py check
.venv/bin/python labs/claims_evidence_audit/inspect_claims_evidence_audit.py show
.venv/bin/python labs/claims_evidence_audit/inspect_claims_evidence_audit.py check
.venv/bin/python labs/claims_evidence_audit/export_summary.py
.venv/bin/python -m pytest labs/tests/claims_evidence_audit -q
```

## Records and state rules

The protocol selects 4 foundations topics across 13 provider records. The loader reads their YAML entries, the taxonomy, the independent reading and the comparison export in place. It checks the export's whole-catalogue inventory of 1209 cells, comprising 591 explicit observations and 618 declared defaults. The selected track contains 52 cells. The inspector prints each cell's recorded depth, evidence identifiers and note, followed by the counts.

| State | Rule | What a reader may do |
| --- | --- | --- |
| `direct-observation` | An explicit depth has resolvable evidence in its provider record. | Report the recorded depth and its reviewed source surface. |
| `bounded-inference` | An explicit `unverified` depth retains evidence but has a lower-upper interval. | Keep the interval open and avoid a point ranking. |
| `unsupported-claim` | An explicit depth lacks evidence, cites an undeclared entry or names a missing local file. | Repair the reference before using the depth. |
| `unresolved-field` | The provider's evidence-free `unverified` default supplies the cell. | Record the missing review without treating it as absence. |

An evidenced `absent` depth is a direct observation about the reviewed material. It does not prove absence beyond that review. The interval state is possible under the frozen rule, although none of these selected cells has it.

## Unsupported depths and independent disagreements

## Limits of the material

An `unresolved-field` cell does not say that the provider does not cover the topic. The project's own depth is a floor it chose to state, not a measurement of how well it teaches. These records are dated reviews of selected source surfaces. The laboratory neither reopens external pages nor measures reader learning. A passing local evidence check cannot turn the recorded superlatives into established claims.
