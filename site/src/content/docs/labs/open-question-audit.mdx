## Preparation and learning objectives

Read [the mechanism and target validation lesson](/learn/mechanism-targets/perturbation-to-target-validation/) first. This laboratory serves `t06-mechanism-hypothesis-counterevidence`. You will classify the state of a question in paired review records, identify a missing measurement, and detect an open question whose record gives no way to settle it. Familiarity with YAML helps. No modelling experience is required.

## Mode and commands

Mode is a fresh independent computation over a frozen protocol and committed repository records. Use the project Python 3.11 environment with PyYAML and CPU. The commands need no network, download, or accelerator. Run from the repository root. The download command verifies the 3 local inputs and writes nothing. The inspector also writes nothing. The exporter overwrites only this laboratory's compact summary after its checks pass.

```bash
.venv/bin/python labs/open_question_audit/run_lab.py download
.venv/bin/python labs/open_question_audit/inspect_open_question_audit.py show
.venv/bin/python labs/open_question_audit/inspect_open_question_audit.py check
.venv/bin/python labs/open_question_audit/export_summary.py
.venv/bin/python -m pytest labs/tests/open_question_audit -q
```

## Question states

The computation reads 93 taxonomy topics. Its rules apply the paired note and reason, then preserve the topic IDs under each state. A measured state refers to the local result that the note describes. It does not settle the underlying science.

| State | Topics | Record rule |
| --- | ---: | --- |
| Open | 28 | The paired explanations leave a question unsettled. |
| Settled by measurement | 53 | The note describes a local laboratory result and what it established. |
| Held by a reading | 12 | The independent reading retained a shallower value and the self record kept it. |
| Lowered by a reading | 0 | A reading lowered a claimed depth and the corrected self value remains in place. |
| Unexamined | 0 | Neither record explains the topic beyond depth and evidence identifiers. |

The inspector prints the full topic list for every state. A historical lowering can remain visible after a later raise. The tool-contract topic, `t16-tool-input-output-contract`, records such a lowering and now names a missing contract enforcement step.

## Open questions and falsifiers

The protocol requires a named discriminating observation or a specified missing measurement before an open question can be described as having a way to settle it. Generic wording such as `more work is needed` does not qualify. The check enforces the distinction and a constructed known-bad case tests it.

The final row is empty in the committed records. In the constructed known-bad case, a note that says only `more work is needed` becomes an unfalsifiable open record. Such wording has not made the question well-posed. It does not mean the topic is merely difficult or that the underlying science lacks possible tests.

## Limits of the material

This audit measures whether the records still carry a falsifying observation or a missing measurement. It does not establish that any question has been answered. Wording is not evidence that a measurement was made. The literal vocabulary can miss a paraphrase or match a phrase that a human would read differently. The state counts therefore describe these dated records under the declared rule, not a ranking of tracks or a measure of reader learning.
