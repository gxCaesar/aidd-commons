## Preparation and learning objectives

This laboratory asks which measurements actually cover a declared compound cohort before anyone compares efficacy, safety or exposure. Read [the decision-unit lesson](/learn/foundations/decision-unit-scope/) and [metabolism to safety](/learn/admet-pk/metabolism-to-safety/) first. You will distinguish an activity row from an independent measurement, keep a unit and a spread beside each reported value, and mark an unmeasured family as missing.

## Fresh independent computation

The mode is a fresh independent computation under a frozen protocol. Use the project's Python 3.11 environment. The first command downloads the ChEMBL 37 snapshot into a separate cache and requires network access. The remaining commands read that cache without network access or an accelerator. They do not change the source data. The export command overwrites the small committed summary only after the contract and arithmetic checks pass.

```bash
.venv/bin/python labs/multi_endpoint_tradeoff/run_lab.py download
.venv/bin/python labs/multi_endpoint_tradeoff/inspect_multi_endpoint_tradeoff.py show
.venv/bin/python labs/multi_endpoint_tradeoff/inspect_multi_endpoint_tradeoff.py check
.venv/bin/python labs/multi_endpoint_tradeoff/export_summary.py
.venv/bin/python -m pytest labs/tests/multi_endpoint_tradeoff -q
```

## Source records and measurement rule

The declared cohort contains 15 ChEMBL seed molecules that resolve to 10 parent molecules. The reader reuses the decision-unit laboratory's ChEMBL 37 cache format, parent resolution and admission rule. A point row must report `AC50`, `EC50`, `IC50`, `Kd` or `Ki` in `nM`, with `=` and the declared curation and quality flags. Bounds such as `>` remain counted as bounds in the sibling census and do not enter the value summaries here. One independent point measurement has a unique parent, assay, document and standard type. Two rows with that same key contribute one median value.

The family map is explicit. `AC50`, `EC50` and `IC50` enter the efficacy-related response-potency proxy. `Kd` and `Ki` enter `other` as affinity measurements. A newly admitted type without a mapping also enters `other`. No admitted standard type identifies toxicity or exposure, so neither family receives a measurement. This is a statement about this protocol's coverage, not about whether these compounds have ever been tested for those outcomes.

## Limits of the material

The 15 seeds were selected to exercise the admission rule and are not a random sample. The lab does not fit a model, estimate performance, combine families, produce a score or rank compounds. It cannot infer safety, clean interaction behavior or bioavailability from an absent measurement. A response-potency type alone does not establish therapeutic efficacy, and a pooled median across assays does not replace the individual experimental contexts. The local snapshot contains source activity records, while the committed summary contains counts and descriptive statistics rather than activity rows.
