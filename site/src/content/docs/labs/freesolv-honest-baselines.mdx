## Before you run

Default mode: read the completed results and aggregate-reading notebook; neither
requires retraining or a new data download. Fresh reproduction belongs in a
separate reader checkout under the documented protocol, not the author's result
directory. Do not retune after reading the test values below. For editable fitting
practice, use the [synthetic student sandbox](/learn/machine-learning/student-modelling-sandbox/).
This entry clarification was added on 2026-09-09; the frozen result is unchanged.

## Status and scope

This completed lab records one final test evaluation from a frozen protocol. It
does not make a SOTA claim. The pinned dataset is FreeSolv `v0.52`; the target
is experimental hydration free energy in kcal/mol from the fourth
semicolon-delimited field. Molecules are keyed by RDKit canonical isomeric
SMILES while retaining the original `mobley_*` source ID for traceability.

The protocol fixed seed `20260904`, 80/10/10 random and Bemis-Murcko scaffold
splits, train-only fitting, Morgan fingerprints (radius 2, 2,048 bits,
chirality enabled), a train mean, Ridge (`alpha=1.0`), and a 500-tree random
forest. The scaffold split is the predeclared primary result; the random split
is an easier contrast.

## Reading the artifact safely

The paired source notebook, `labs/freesolv/freesolv_honest_baselines.ipynb`,
reads `reviewed-results.json`, an aggregate-only public summary derived from
the frozen result. It does not fit models, alter splits, or invoke another test
evaluation. The public reference environment is recorded in
`labs/freesolv/environment.txt`; `pyproject.toml` pins the supported direct
dependencies and `uv` resolves the runtime used for the lab commands.

Empirical interval coverage is marginal coverage, not conditional calibration.
The fixed models and representations are teaching controls, not evidence of an
optimal predictor.
