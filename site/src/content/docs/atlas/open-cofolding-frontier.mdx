## How to read this inventory

The rows below distinguish a product or service from seven independently
auditable assets: inference code, training code, weights, architecture, data
recipe, training data, and evaluation code. `Unverified` means that the
opened primary source used next to that cell did not establish the asset's
availability. It does not mean the asset is absent. A repository page is not
treated as licence evidence; licence claims link to the exact opened licence
or an asset-specific README statement.

This is an evidence inventory, not a predictive-performance ranking. The
[structure and co-folding lesson](/learn/structure-and-pockets/cofolding-frontier/)
explains how to match a structural output to an experimental decision.

The inventory intentionally does not convert `unverified` into `not available`.
For example, a source repository can establish inference code without proving a
complete training recipe or an evaluation protocol. Before reproducing a
published claim, open the cited source again and identify the exact asset,
version, licence scope, and evaluation boundary required by the decision.
