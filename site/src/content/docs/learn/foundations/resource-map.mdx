## What the columns mean

The unit is a learning objective. Its linked chapter may teach several units.
The activity labels describe that chapter, not mastery of every linked objective.
Its resources are the chapter's registered reading: a shared reference does not
establish that every section of that resource supports every linked unit.
Additional track reading is shown separately and is not counted again in the
chapter list. Resource kinds describe objects, not a quality ranking.

For a practical task, look for the endpoint definition, a suitable data source,
an implementable method and a matched evaluation example. A missing resource
kind in an assigned list identifies a curation question, not proof that the
resource does not exist. Open the Atlas entry for access and licence details;
an unknown field is not permission to use an asset.

## Choose a first external tutorial

The starting tasks below are suggested reading exercises, not claims that this
site ran the upstream notebooks. Use each project's current environment and
data instructions; no common runtime or hardware requirement is assumed.

| Your next task                      | Official collection                                                                       | Suggested preparation and first output                                                                                                                                                  |
| ----------------------------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Inspect molecular representations   | [RDKit Cookbook](https://www.rdkit.org/docs/Cookbook.html)                                | Basic Python and SMILES; choose a representation or drawing recipe and explain its input and output.                                                                                    |
| Follow a drug-discovery workflow    | [TeachOpenCADD](https://projects.volkamerlab.org/teachopencadd/talktorials.html)          | Python plus the relevant chemistry lesson; choose one talktorial and identify its data source, operations and interpretation.                                                           |
| Learn molecular ML machinery        | [DeepChem tutorials](https://github.com/deepchem/deepchem/tree/master/examples/tutorials) | Python and train/validation/test concepts; start with introductory dataset, featurizer and model examples. Describe the split before comparing a score.                                 |
| Inspect an ADMET modelling example  | [OpenADMET Demos](https://github.com/OpenADMET/openadmet-demos)                           | Endpoint and assay literacy; trace the CYP3A4 example from curation to training and evaluation. Produce an endpoint-and-split note, not a clinical conclusion.                          |
| Understand free-energy calculations | [OpenFE tutorials](https://docs.openfree.energy/en/latest/tutorials/index.html)           | Read the force-field, sampling and free-energy lessons first. Select a relative or absolute calculation tutorial and list its system, states and sampling assumptions before execution. |
| Build an acquisition loop           | [BoTorch tutorials](https://botorch.org/docs/tutorials)                                   | The official entry assumes Bayesian optimization and PyTorch familiarity and points newcomers to Ax. Trace a full loop's objective, surrogate, acquisition and candidate update.        |
